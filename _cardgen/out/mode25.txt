 * ==============================================================================
 *   模式速览卡   MODE 25   手动角度吸附（写电角度，把转子吸过去并校验）
 *   本卡是本模式唯一事实源；代码内注释与本卡冲突时，以本卡为准
 * ==============================================================================
 *   入口   comm_mode = 25
 *   前置   无；进入后自动先跑校准（BETA 90 度 2s -> ALPHA 0 度 2s 锁零点）
 *   结束   吸附 2s + 校验 0.5s 后自动回刹车 50/50/50 停在 25
 *          等下一次输入；只有过流自动回 mode 0
 *   标记   [!] 易错点   (*) 主判据   [可调] Watch 可写   [只读] 仅观察
 * ------------------------------------------------------------------------------
 *   [可调] Watch 变量 -- 改值即时生效，复位后回宏默认
 * ------------------------------------------------------------------------------
 *       变量                        当前值  单位     含义
 *       --------------------------- ------- -------- ---------------------------
 *   (*) g_foc_angle_input           0       x0.1deg  目标电角度，改值即触发吸附
 *   [!] 同一个值再写一次不会触发（改值检测），要先写别的值再写回来；校准 4s
 *       期间预设的值会在锁零点后立即执行。
 *       g_calang_volt_v             0.4     V        吸附电压（约 4A）
 *   [!] 经验上限 0.55V（约 5.5A）。注意宏 FOC_OC_LIMIT_A 实际是
 *       9.0A，提压时不要只看宏。
 *       g_calang_stable_cnts        8       counts   校验窗静止判据，越小越严
 * ------------------------------------------------------------------------------
 *   [只读] 关键观察变量
 * ------------------------------------------------------------------------------
 *       变量                           含义
 *       ------------------------------ -----------------------------------------
 *   (*) g_calang_err_deg               误差 meas-target；典型 +/-40~50
 *   (*) g_calang_win_moved             校验窗位移 counts，超判据即 FAIL
 *       g_calang_state                 状态机：1 BETA，2 ALPHA，3 刹车，4 吸附
 *       g_calang_running               运行标志（1 = 在 mode 25 里）
 *       g_calang_evt                   事件：1 BETA完，2 锁零点，3 吸稳，4 失败
 *       g_calang_target_deg            快照：目标角 x0.1deg（wrap）
 *       g_calang_meas_deg              快照：校验结束实测电角度 x0.1deg
 *       g_calang_offset                快照：本模式校准锁定的零点 counts
 *       g_calang_du                    U 相占空比 %；吸附时三相互差 120 度
 *       g_calang_dv                    V 相占空比 %
 *       g_calang_dw                    W 相占空比 %；刹车阶段三相同为 50
 *       g_foc_elec_deg                 实时转子电角度 deg，对照吸附结果
 * ------------------------------------------------------------------------------
 *   VOFA 通道 -- 16ch，填充见 Foc_CalAngle_VofaFill
 * ------------------------------------------------------------------------------
 *       通道  含义                   单位     备注
 *       ----- ---------------------- -------- ----------------------------------
 *       ch0   U 相电流               A        吸附包络 / 刹车归零
 *       ch1   V 相电流               A
 *       ch2   W 相电流               A
 *   (*) ch3   id 反馈                A        磁场轴上的吸持电流
 *       ch4   iq 反馈                A        吸稳后应接近 0
 *       ch5   状态                   -        0 空闲/1 BETA/2 ALPHA/3 刹车/4
 *                                             吸附/5 校验/6 OC
 *   (*) ch6   事件                   -        1 BETA完/2 锁零点/3 吸稳/4 失败/5
 *                                             OC
 *       ch7   目标电角度             deg      锁存的目标角（0.1 度分辨率）
 *       ch8   实测电角度             deg      校验结束时的实测值
 *   (*) ch9   误差                   deg      = meas - target，判吸准就看它
 *       ch10  校验窗位移             counts   超判据（默认 8）即 FAIL
 *       ch11  对齐零点               counts   本模式校准锁的零点
 *       ch12  U 相占空比             %        吸附时三相互差 120 度
 *       ch13  V 相占空比             %
 *       ch14  W 相占空比             %        刹车阶段三相同为 50
 *       ch15  实时转子电角度         deg      对照吸附结果
 * ------------------------------------------------------------------------------
 *   判据与坑
 * ------------------------------------------------------------------------------
 *   (*) 吸稳不等于吸准：g_calang_win_moved 判吸稳（RTT 的 HOLD
 *       ok），g_calang_err_deg 判吸准（精度）。
 *   (*) 误差四项：编码器量化 1 count = 0.88 电角度、静摩擦死区、BRAKE
 *       漂进齿槽、校准零点 1~2 度偏移。
 *   [!] 输入是电角度 x0.1deg：0~3599，写 900 = 90.0 度；名字带 deg 但单位是 0.1
 *       度，target/meas/err 同单位。
 *   [!] 跳变超过 180 度（超过 1800）转子走短路径：0 直接写 2700 会倒退到 mech -9
 *       度。恰好 180 度转矩为零，避开。
 *   [!] VOFA+ 通道数必须同步配成 16（本模式自持布局），否则整帧错位。判吸准看
 *       ch9（误差）与 ch10（校验窗位移），不要再靠肉眼估。
 *   [!] 退出只能切 mode 0；只有过流（evt=5）自动回 mode 0，吸稳/失败都停在 mode
 *       25 等下一次输入。
 * ==============================================================================
