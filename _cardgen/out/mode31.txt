 * ==============================================================================
 *   模式速览卡   MODE 31   编码器 PI 电流环（id 恒 0，iq 手动给）
 *   本卡是本模式唯一事实源；代码内注释与本卡冲突时，以本卡为准
 * ==============================================================================
 *   入口   comm_mode = 31（main.c 的 SW3 短按有 bug 恒回 0，请用 Watch 写）
 *   前置   需 mode 30 或 32 已锁偏移，否则启动被拒（ch15 = 1）
 *   结束   comm_mode = 0 停机（状态码保留可回看）；过流自动停（ch15 = 6）
 *   标记   [!] 易错点   (*) 主判据   [可调] Watch 可写   [只读] 仅观察
 * ------------------------------------------------------------------------------
 *   [可调] Watch 变量 -- 改值即时生效，复位后回宏默认
 * ------------------------------------------------------------------------------
 *       变量                        当前值  单位     含义
 *       --------------------------- ------- -------- ---------------------------
 *       g_iqpi_iq_ref_ma            1500    mA       iq 目标；正负号决定转向
 *       g_iqpi_iq_ramp_ma_s         1000    mA/s     iq 斜坡斜率（0 = 直通阶跃）
 *       g_iqpi_pid_iq_cfg.kp        0.27    V/A      q 轴 PI 比例增益
 *       g_iqpi_pid_id_cfg.kp        0.27    V/A      d 轴 PI 比例增益
 *       g_iqpi_pid_iq_cfg.ki        630     V/A/s    q 轴 PI 积分增益
 *       g_iqpi_pid_id_cfg.ki        630     V/A/s    d 轴 PI 积分增益
 *       g_foc_enc_dir               -1      -        编码器电角方向（默认 -1）
 *   (*) 初值来自 FOC31_IQ_REF_MA=1500mA、FOC31_IQ_RAMP_MA_S=1000mA/s：0 ->
 *       1500mA 约 1.5s；运行中改 g_iqpi_iq_ref_ma 立即生效，斜率不变。
 *   [!] kp/ki 初值 FOC31_PI_KP=0.27、FOC31_PI_KI=630 是按 fc 约 1kHz、kp*R/L
 *       零极点对消整定，fc 上限 = PWM/10，不要随意加大；振荡时先降到
 *       0.10/240（foc_31_iqpi.h 注释：与 mode22 一致，已验证）。
 *   [!] id / iq 两组 kp/ki 必须同步改，否则 dq 两轴响应不一致；输出限幅宏
 *       FOC31_PI_UMAX_V=3.5V，改它会让饱和判据阈值 0.98 x 限幅 跟着变。
 * ------------------------------------------------------------------------------
 *   [只读] 关键观察变量
 * ------------------------------------------------------------------------------
 *       变量                           含义
 *       ------------------------------ -----------------------------------------
 *   (*) g_iqpi_iq_ref_ramp_ma          斜坡后实际给定；闭环就吃它（ch11）
 *   (*) g_iqpi_step                    3 闭环；4 饱和；5 堵转；6 过流；7 翻转
 *       g_iqpi_running                 1 = 运行中（停机后 g_iqpi_step 保留）
 *       g_iqpi_theta_rad               Park 用转子电角 (rad)；扣偏移再补 90deg
 *       g_iqpi_win_evals               窗口评估次数（0 = 方向检查没跑过）
 *       g_iqpi_win_moved               最近 500ms 窗编码器位移 counts（带符号）
 *       g_iqpi_cur_dir                 最近窗实测转向 +1/-1，与预期比
 *       g_iqpi_expect_dir              预期转向：由拖动方向与 iq 符号定
 *       g_iqpi_flip_cnt                本次运行 180deg 框架翻转次数
 *       g_iqpi_step_hist               最近 10 条状态变化历史（[0] 最旧）
 *       g_foc_iq_ma                    控制系 q 轴电流反馈 (mA) = ch6 来源
 *   [!] 停机不清 g_iqpi_step：切回 mode 0 后仍可看停机原因（6 = 过流、5 =
 *       堵转）；mode 32 锁定成功会自动调 Foc_IqPi_Start 交接进来。
 * ------------------------------------------------------------------------------
 *   VOFA 通道 -- 16ch，填充见 Foc_IqPi_VofaFill
 * ------------------------------------------------------------------------------
 *       通道  含义                   单位     备注
 *       ----- ---------------------- -------- ----------------------------------
 *       ch0   U 相电流               A
 *       ch1   V 相电流               A
 *       ch2   W 相电流               A
 *       ch3   静止系电流幅值         A
 *       ch4   静止系 ialpha          A
 *       ch5   静止系 ibeta           A
 *   (*) ch6   iq 反馈                A        环反馈；判它追 ch11
 *       ch7   id 反馈                A        参考恒 0，应压到 0 附近
 *       ch8   iq 目标                A        手动给的目标（未过斜坡）
 *       ch9   vd 输出                V
 *       ch10  vq 输出                V        贴 3.5V = 撞限幅（饱和）
 *   (*) ch11  斜坡后 iq 参考         A        闭环真正吃的给定
 *       ch12  使用的转子电角         rad
 *       ch13  U 相占空比             %
 *       ch14  V 相占空比             %
 *   (*) ch15  状态                   -        3 闭环；4 饱和；5 堵转；6 过流
 * ------------------------------------------------------------------------------
 *   判据与坑
 * ------------------------------------------------------------------------------
 *   (*) 判跟踪：ch6（iq 反馈）追 ch11（斜坡后给定），ch7（id）压在 0 附近，ch15
 *       = 3；RTT 每 200ms 一行 [FOC31_MON]，可同步看
 *       st/iq/id/vq/vd/rr/win/ev/cd/ed/rd/flip/pos。
 *   (*) ch15 非 3 的含义：1 无偏移启动被拒（先跑 mode 30 或 32）/ 2
 *       零矢量零偏校准约 210ms（必经，不是卡死）/ 4 电压饱和（|vd| 或 |vq| >=
 *       3.43V = 0.98 x FOC31_PI_UMAX_V）/ 5 疑似堵转 / 6 过流 / 7 检出 180deg
 *       框架误差并已自动翻转。
 *   [!] 180deg 框架误差在 dq 电流上看不出来，只有转向能暴露：每
 *       FOC31_STALL_WIN_MS=500ms 窗的位移符号与 mode 30 拖动方向相反就 +180deg
 *       翻转框架（ch15 = 7，RTT 打 [FOC31_FLIP]）。这是自愈动作，数秒内应回到
 *       3，别急着停机；iq 参考取负时预期方向自动取反。
 *   [!] ch15 = 5 的判据：参考与实测 iq 都 > FOC31_STALL_IQ_MIN_MA=300mA 且窗位移
 *       < FOC31_STALL_MIN_CNTS=204 counts。看到它就先看 ch9/ch10：已顶 3.43V
 *       属饱和连带（电压不够），先降 iq 目标；有余量才怀疑静摩擦不足或框架角错。
 *   [!] VOFA+ 通道数必须同步配成 16，否则整帧错位；改通道数改 Foc_IqPi_VofaFill
 *       末尾的 return。
 * ==============================================================================
