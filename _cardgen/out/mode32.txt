 * ==============================================================================
 *   模式速览卡   MODE 32   自锁偏移 + 自动交接 mode 31（静止吸附对表）
 *   本卡是本模式唯一事实源；代码内注释与本卡冲突时，以本卡为准
 * ==============================================================================
 *   入口   comm_mode = 32
 *   前置   无：自带对齐与复测，不依赖
 *          mode30（会覆盖其锁定值与方向基准）；闭环启动推荐走本链路
 *   结束   锁定成功后自动交接 mode 31；失败或过流自动停机（step=5 / 6）
 *   标记   [!] 易错点   (*) 主判据   [可调] Watch 可写   [只读] 仅观察
 * ------------------------------------------------------------------------------
 *   [可调] Watch 变量 -- 改值即时生效，复位后回宏默认
 * ------------------------------------------------------------------------------
 *       变量                        当前值  单位     含义
 *       --------------------------- ------- -------- ---------------------------
 *       g_lockiq_align_volt_v       0.4     V        对齐电压幅值；0.4V 约 4A
 *                                                    直流
 *   [!] 初值来自宏 FOC_ALIGN_VOLT_V；写 <=0 会被 Start 自动改回 0.4V（防 Watch
 *       改坏卡死）。
 *   [!] 吸附电流 = 电压 / 相电阻，调大电压就是加大堵转电流（0.4V 已约 4A）。
 *   (*) 吸附阶段转子会咔一下被磁力吸到对齐位，有响声属正常，不是故障。
 * ------------------------------------------------------------------------------
 *   [只读] 关键观察变量
 * ------------------------------------------------------------------------------
 *       变量                           含义
 *       ------------------------------ -----------------------------------------
 *   (*) g_lockiq_step                  锁定阶段主判据；枚举含义见判据区
 *       g_lockiq_running               1 = mode32 运行中；交接后自动清 0
 *   (*) g_lockiq_off_deg               已注入 mode31 的偏移，成功必须为 0
 *   (*) g_lockiq_track_err_cnts        VERIFY 复测位移误差 counts，0 附近才好
 *       g_lockiq_win_moved             最近窗口平均位移 counts（判静止依据）
 *       g_lockiq_win_evals             已完成静止窗口评估次数（0 = 没跑到）
 *   [!] g_lockiq_evt_code              事件码：1 锁定 / 2 超时 / 3 跟踪失败
 *       g_lockiq_evt_off_deg           事件快照偏移 deg（RTT 打印同源）
 *   [!] step=5 = 拒绝启动（宁可不起动），看 evt_code
 *       分清是等静止超时还是复测位移不对。
 *   [!] VOFA+ 通道数必须同步配成 16，否则整帧错位。ch12 是 mode31 的
 *       g_iqpi_theta_rad，吸附期间不更新（mode32 自己的磁场角在
 *       g_foc_theta_rad，没进 VOFA）。
 * ------------------------------------------------------------------------------
 *   VOFA 通道 -- 16ch，填充见 Foc_LockIq_VofaFill
 * ------------------------------------------------------------------------------
 *       通道  含义                   单位     备注
 *       ----- ---------------------- -------- ----------------------------------
 *       ch0   U 相电流               A
 *       ch1   V 相电流               A
 *       ch2   W 相电流               A
 *       ch3   静止系电流幅值         A        吸附期间可见
 *       ch4   静止系 ialpha          A
 *       ch5   静止系 ibeta           A
 *       ch6   iq 反馈                A
 *       ch7   id 反馈                A
 *       ch8   iq 目标                A        交接后有效
 *       ch9   vd 输出                V
 *       ch10  vq 输出                V
 *       ch11  斜坡后 iq 参考         A        交接后有效
 *       ch12  转子电角度             rad      交接后有效
 *       ch13  U 相占空比             %
 *       ch14  已注入的偏移           deg      成功应为 0
 *   (*) ch15  状态                   -        锁定阶段主判据
 * ------------------------------------------------------------------------------
 *   判据与坑
 * ------------------------------------------------------------------------------
 *   (*) 主判据：g_lockiq_step 走到 4（已锁定等交接）= 成功；foc_obs 随即打印
 *       [LOCKIQ] locked 并自动调 Foc_IqPi_Start() 交接 mode31，VOFA ch15
 *       同步变为4。
 *   (*) step 序列：1 BETA 磁场90度盲等吸附 500ms -> 2 ALPHA 磁场0度等静止 -> 3
 *       VERIFY 回90度复测位移 -> 4 已锁定等交接。
 *   [!] 三道质量门全过才锁定：连续 2 个 300ms 窗口位移 <= 4 counts
 *       才算静止、相位超时 3s（evt_code=2）、复测位移应约 102 counts（90 度电 =
 *       CPR/(4*极对数)）且误差 <= 12 counts（evt_code=3）。任一门不过 ->
 *       step=5，拒绝启动。
 *   [!] 注入偏移恒为 0：VERIFY 结束时转子被吸停在静止系 90 度，而 mode31
 *       启动清零自身计数后要求 off = 90 度 -
 *       Theta，结果恰为0（与停位无关）。旧版沿用两段式推导注入 90 度，造成 90
 *       度框架差 -> iq 落在真实 d 轴 -> 零转矩堵转 -> 过流。
 *   [!] LOCKED_WAIT_HANDOFF 期间继续输出 90 度磁场吸住转子不放手（这是 off=0
 *       的前提）；交接后若用手拧过转子，再单独进 mode31 无效，必须重跑 mode 32。
 * ==============================================================================
