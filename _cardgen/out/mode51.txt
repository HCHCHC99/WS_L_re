 * ==============================================================================
 *   模式速览卡   MODE 51   定子电阻辨识（静止直流注入 + 多电平最小二乘）
 *   本卡是本模式唯一事实源；代码内注释与本卡冲突时，以本卡为准
 * ==============================================================================
 *   入口   comm_mode = 51（Watch 直接写）
 *   前置   无。不需要 mode 24 校准、不需要编码器零点（矢量固定在静止 alpha 轴）
 *   结束   自动：测完关 PWM、state=DONE；不写 Flash、不改任何配置宏
 *   标记   [!] 易错点   (*) 主判据   [可调] Watch 可写   [只读] 仅观察
 * ------------------------------------------------------------------------------
 *   [可调] Watch 变量 -- 改值即时生效，复位后回宏默认
 * ------------------------------------------------------------------------------
 *       变量                        当前值  单位     含义
 *       --------------------------- ------- -------- ---------------------------
 *       g_rs51_i_max_a              3.0     A        最大注入电流（硬上限 5.0）
 *       g_rs51_i_min_a              1.0     A        最低档目标电流（档位下限）
 *       g_rs51_vdead_prior_v        0.15    V        死区电压先验：探测扣偏置 +
 *                                                    规划档位
 *       g_rs51_v_hard_max_v         1.5     V        单档电压硬上限
 *       g_rs51_points               6       -        档位数 3~10
 *       g_rs51_settle_ms            100     ms       每档稳定等待
 *       g_rs51_avg_ms               100     ms       每档平均窗口
 *       g_rs51_precond_ms           300     ms       预置注入时长（先稳转子）
 *   (*) 上八行为本轮可调项；全程约 1.9s（零偏 200ms + 预置 300ms + 探测 200ms +
 *       6 档 x 200ms）。
 *   [!] g_rs51_vdead_prior_v 很关键：用来从探测电流里扣掉死区偏置再算
 *       R（旧版漏了这步，R 高估 2.2 倍，电流冲到
 *       5.4A）。它同时决定每档电压规划。
 *   [!] 注入会产生力矩趋势：能用夹具夹紧转子最好；靠编码器位移（ch10 与
 *       g_rs51_moved_cnts）判断数据是否可信。
 *   [!] i_max 必须小于 FOC_OC_LIMIT_A(9A)
 *       并留余量；除它之外还有两道护栏：预置档按 0.9
 *       逐次降档、扫描档按实测电流比例下调 v_scale（触发次数看
 *       g_rs51_scale_hits）。
 * ------------------------------------------------------------------------------
 *   [只读] 关键观察变量
 * ------------------------------------------------------------------------------
 *       变量                           含义
 *       ------------------------------ -----------------------------------------
 *   (*) g_rs51_meas_ohm                R_eff（拟合斜率）---- 主结果，ohm
 *   (*) g_rs51_ratio                   R_eff / FOC_MOTOR_RS_OHM ----
 *                                      与商家参数直接对比
 *   (*) g_rs51_vdead_v                 V_dead（拟合截距）= 死区等效电压 (V)
 *   (*) g_rs51_r2                      拟合优度；>= 0.99 才算合格
 *       g_rs51_state                   0 IDLE / 1 零偏窗 / 2 预置 / 3 探测 / 4
 *                                      扫描 / 5 拟合 / 6 DONE / 7 OC
 *       g_rs51_evt                     1 OC / 2 拟合OK / 3 拟合差(R2<0.99) / 4
 *                                      测不到电流
 *       g_rs51_running                 1 = 本轮有效（DONE 后仍为 1，便于回看）
 *       g_rs51_v_now_v                 当前注入电压 (V)
 *       g_rs51_i_now_a                 当前电流矢量幅值 (A)
 *       g_rs51_elapsed_ms              累计注入时间 (ms)
 *       g_rs51_fs_meas_hz              实测 ISR 频率 (Hz)：Timer6 计数测得
 *       g_rs51_pts_done                已完成档位数（RTT 进度打印靠它）
 *   [!] g_rs51_v_scale                 运行时电压缩放；<1 说明护栏降过档
 *   [!] g_rs51_scale_hits              电流护栏触发次数；>0 说明探测值偏大
 *   [!] g_rs51_moved_cnts              全程编码器位移；> 8 counts 判数据可疑
 *       g_rs51_pts_v                   各档电压数组（画 v-i 直线用）
 *       g_rs51_pts_i                   各档电流数组
 * ------------------------------------------------------------------------------
 *   VOFA 通道 -- 12ch，填充见 Foc_RsId_VofaFill
 * ------------------------------------------------------------------------------
 *       通道  含义                   单位     备注
 *       ----- ---------------------- -------- ----------------------------------
 *       ch0   状态码                 -        见状态机表
 *       ch1   注入电压               V        当前档位
 *   (*) ch2   电流矢量幅值           A        应与注入电压同增
 *   (*) ch3   R_eff 估计             ohm      拟合完成后为定值
 *   (*) ch4   V_dead 估计            V        理论约 0.12V
 *       ch5   R 平方                 x1000    >=990 合格
 *       ch6   已完成档位             -        0..points
 *       ch7   U 相电流               A        原始反馈
 *       ch8   V 相电流               A
 *       ch9   W 相电流               A
 *   [!] ch10  编码器位移             counts   > 8 则数据可疑
 *       ch11  累计注入时间           ms       全程约 1400
 * ------------------------------------------------------------------------------
 *   判据与坑
 * ------------------------------------------------------------------------------
 *   (*) 原理：转子静止 => 无 BEMF、稳态无 di/dt => |v| = R_eff x |i| +
 *       V_dead。斜率 = R_eff（环路真正看到的电阻：相阻 + 2xRdson + 采样电阻 +
 *       走线），截距 = 死区+管压降等效电压。
 *   (*) 为什么必须多电平：死区等效电压约 Vbus x Td/Ts = 12V x 500ns / 50us =
 *       0.12V，而 2A 时 R x i 只有 0.2~0.3V ----
 *       单点测量里死区占四成，必然测歪。
 *   (*) 流程：零矢量 200ms 采三相零偏（自己扣，不依赖 mode 24）-> 预置注入
 *       0.3V/300ms 让转子与夹具先稳 -> 探测 0.3V 得 i_probe -> R_guess = (0.3 -
 *       Vdead先验)/i_probe -> 按目标电流 1A..i_max 分 6 档，电压 = i x R_guess +
 *       Vdead先验 -> 逐档 100ms 稳定 + 100ms 平均 -> 最小二乘。
 *   [!] 本模式只输出观测量：不写 Flash、不改
 *       motor_config.h。用途是与商家参数对比、验证辨识思路本身。
 *   [!] R2 < 0.99 或 moved_cnts > 8
 *       时结果不可信：前者多为电流零偏漂了（重跑一次零偏窗）、后者是转子被推动
 *       （夹紧后重测）。
 *   [!] 本模式测到的是 R_eff（含桥臂压降），不是电机本体的 Rs。要分离本体 Rs
 *       需用示波器差分测电机端子线电压（Rs = V_line/(2i)），见
 *       md_record/电机参数辨识方案_Rs_磁链_LdLq.md。
 *   (*) RTT 输出（开关 FOC_RS51_DBG，定义在 foc_51_rs.h；打印点在 foc_obs
 *       事件段，ISR 内不打印，符合 RTT
 *       打印规范）：进入时打一行配置；每完成一档打 pt+v/i；护栏触发时打 current
 *       clamp；结束时打
 *       R(mohm)/Vdead(mV)/R2(x10000)/ratio(x1000)/位移/耗时/clamp 次数/v_scale +
 *       全部原始点，并对 R2<0.99 或位移>8 各追一行 warn。
 *   [!] 2026-09-27 三处实测教训（都已修）：1. 探测算 R
 *       时忘了扣死区偏置，0.3V/1.345A 得 0.222ohm 而真值约
 *       0.1ohm，导致档位电压算高一倍、电流冲到 5.4A（超 i_max 3A）；2.
 *       档位原先按电压等分，最低档 0.166V 里 87% 被死区吃掉、只剩 21mV
 *       有效驱动，是个既无信息又对截距有最大杠杆的病态点（两次实测 R2 都卡在
 *       0.9896、残差逐点相同）；改成按目标电流规划后 R2 升到 0.9983、残差从
 *       +/-32mV 降到 +/-4mV；3. 电流护栏若比瞬时值会被开关纹波误触发（实测误触发
 *       7 次，把后两档电压砍掉 8~13%），改用 EMA 滤波值（FOC51_GUARD_EMA，tau 约
 *       1ms）后纹波衰减百倍、持续过流仍能判出。
 *   (*) 三轮实测（同一台电机、同一套硬件）：R_eff = 99.7 / 98.4 / 97.9
 *       mohm，V_dead = 144.5 / 144.7 / 160.2 mV，R2 = 0.9896 / 0.9896 /
 *       0.9983，moved = 10 / 8 / 2 counts。第三轮（现行算法）的 V_dead 与理论值
 *       (4/3)x(Td/Ts)xVbus = 160.0 mV 吻合到 0.2%，反推死区 501ns（配置
 *       500ns）；R_eff/手册 = 0.98，即商家 0.1ohm 得到验证。
 * ==============================================================================
