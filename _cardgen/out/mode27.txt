 * ==============================================================================
 *   模式速览卡   MODE 27   功角闭环拖动（磁场 = 转子角 + delta，delta
 *                          钉死不失步）
 *   本卡是本模式唯一事实源；代码内注释与本卡冲突时，以本卡为准
 * ==============================================================================
 *   入口   comm_mode = 27
 *   前置   无。进入即自带校准：BETA 90deg 吸 2s -> ALPHA 0deg 吸 2s 锁零点（约
 *          4s 后自动 RUN）
 *   结束   持续运行到手动停机（SW2 短按或写 comm_mode = 0）；仅过流自动回 mode 0
 *   标记   [!] 易错点   (*) 主判据   [可调] Watch 可写   [只读] 仅观察
 * ------------------------------------------------------------------------------
 *   [可调] Watch 变量 -- 改值即时生效，复位后回宏默认
 * ------------------------------------------------------------------------------
 *       变量                        当前值  单位     含义
 *       --------------------------- ------- -------- ---------------------------
 *       g_dcl_volt_v                0.6     V        调速旋钮（0.1V 约 1A）
 *       g_dcl_dlt_init_deg          5       deg      delta 爬坡起点（不复位）
 *       g_dcl_dlt_targ_deg          45      deg      delta 爬坡终点（扫 MTPA）
 *       g_dcl_dlt_tr_ms             2000    ms       过渡时间，0=立即
 *   (*) 实测：delta=90deg、volt=0.6V 时稳态约 460Hz 电频（约 2760rpm），id
 *       转负、iq 降到摩擦级电流。
 *   [!] 功角三参数 Start 不复位（可预设后启动），g_dcl_volt_v 则每次 Start 复位
 *       0.6；运行中改参数 = 按新值重算轨迹并跳变，实验前先设好。
 * ------------------------------------------------------------------------------
 *   [只读] 关键观察变量
 * ------------------------------------------------------------------------------
 *       变量                           含义
 *       ------------------------------ -----------------------------------------
 *   (*) g_dcl_speed_hz                 实测电频（200ms 窗口，带符号）
 *       g_dcl_dlt_now_deg              delta 指令电角（爬坡实时值）
 *       g_dcl_diff_deg                 功角实测；与指令同源，恒等验证
 *       g_dcl_id_ma                    真实转子系 id（磁链分量）
 *       g_dcl_iq_ma                    真实转子系 iq（力矩分量）
 *       g_dcl_iq_pp_ma                 iq 的 5s 窗口峰峰值（猎振判据）
 *       g_dcl_id_pp_ma                 id 的 5s 窗口峰峰值
 *       g_dcl_field_deg                磁场电角 (deg，0~359)
 *       g_dcl_rotor_deg                转子电角 (deg，0~359)
 *       g_dcl_enc_pos                  相对计数镜像（毛刺/限幅排查用）
 *       g_dcl_state                    0IDLE/1BETA/2ALPHA/3RUN/4OC
 *       g_dcl_evt                      事件 1BETA/2LOCKED/3RAMP/4OC
 *       g_dcl_running                  1 = 正在运行（切模式后清零）
 *       g_dcl_offset                   校准锁零点（hw 绝对帧 counts）
 *   [!] diff 由 field-rotor 同源构造，它等于 dlt_now
 *       只证明数学没算错，不是独立测出的真功角；真功角看 id/iq 的矢量角。
 * ------------------------------------------------------------------------------
 *   VOFA 通道 -- 17ch，填充见 Foc_Dcl_VofaFill
 * ------------------------------------------------------------------------------
 *       通道  含义                   单位     备注
 *       ----- ---------------------- -------- ----------------------------------
 *       ch0   U 相电流               A
 *       ch1   V 相电流               A
 *       ch2   W 相电流               A
 *   (*) ch3   实测电频率             Hz       扫 delta 看这个；符号未乘 enc_dir
 *       ch4   delta 指令             deg      爬坡中的当前设定值
 *       ch5   功角实测               deg      应约等于 ch4（同源恒等式）
 *       ch6   iq 力矩分量            A        = I sin(delta)
 *       ch7   id 磁链分量            A        = I cos(delta)，delta 小则变大
 *       ch8   磁场电角度             deg
 *       ch9   转子电角度             deg
 *       ch10  电压幅值               V        = 本模式调速旋钮
 *       ch11  iq 峰峰值              A        5s 窗口刷新，猎振判据
 *       ch12  id 峰峰值              A        5s 窗口刷新
 *       ch13  U 相占空比             %
 *       ch14  V 相占空比             %
 *       ch15  W 相占空比             %
 *       ch16  状态                   -        0IDLE/1BETA/2ALPHA/3RUN/4OC
 * ------------------------------------------------------------------------------
 *   判据与坑
 * ------------------------------------------------------------------------------
 *   (*) 主判据：delta 钉死后转速改由电压决定。扫 g_dcl_dlt_targ_deg
 *       5/30/45/60/75/89，g_dcl_speed_hz 峰值应在 90deg 附近（MTPA 闭环验证）。
 *   (*) 实测：delta=90deg、volt=0.6V 稳态约 460Hz 电频（约 2760rpm），id
 *       转负、iq 降到摩擦级，即电压被 BEMF 吃掉的平衡点。
 *   [!] diff（ch5）= fold(field - rotor) 与
 *       dlt_now（ch4）同源，两者相等只验证数学，不是真功角；要独立判据看 id/iq
 *       矢量角 atan2(iq, id)。
 *   [!] g_dcl_speed_hz 符号取原始计数方向（未乘
 *       g_foc_enc_dir），可能与实际转向相反；判 MTPA 只看幅值趋势。
 *   [!] 高速下半拍滞后使实际 delta 比设定大 w*Ts/2（100~300Hz 约
 *       1~3deg），要准就把 targ 少设 1~2deg；delta 小角度 id 大（铜损约
 *       2W），长跑注意温升。
 * ==============================================================================
