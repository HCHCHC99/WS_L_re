## 一、这个模式在做什么

### 1.1 目标

在**转子静止**的条件下，测出电机的 d 轴电感 Ld 与 q 轴电感 Lq，用于：

1. 判断厂商手册给的 `FOC_MOTOR_LS_UH = 42.3 µH` 是否可信（本机实测结论：可信，见 §七）；
2. 判断这台电机是表贴（SPM，Ld≈Lq）还是凸极（IPM，Lq>Ld），从而判断 MTPA 值不值得做；
3. 给电流环整定提供"工作点上的增量电感"。

### 1.2 符号与单位

| 符号 | 含义 | 单位/取值 |
|---|---|---|
| `L` | 被测轴电感（Ld 或 Lq） | H |
| `R` | 相电阻（环路看到的等效值） | 0.098 Ω（mode 51 实测） |
| `V_dead` | 死区+管压降的等效电压 | V（mode 51 实测三轮 144.5/144.7/160.2 mV） |
| `ψf` | 永磁磁链 | 0.00084 V·s/rad（相峰值） |
| `p` | 极对数 | 10 |
| `f_ISR` | 电流采样/控制中断频率 | 20 kHz（**已用独立时基实测 = 20000 Hz**） |
| `T_s` | 采样周期 | 50 µs |
| `T_plt` | 电压"平台"时长 | 100 µs |
| `Vsq` | 注入方波幅值 | V（自适应，默认探测 0.5 V） |
| `V_bias` | 直流偏置电压 | V（默认 238 mV） |
| `I_bias` | 直流偏置电流（实测） | A |
| `ΔE` | 相邻平台均值之差 | A（本文核心量） |
| `ΔP` | 平台内两点之差 | A（对照量） |
| `ωe` | 电角速度 | rad/s |

### 1.3 为什么非要"静止"

dq 电压方程（见 §三）里有两项只在转动时出现：**反电势 `ωe·ψf`** 与**交叉耦合 `ωe·Lq·iq`、`ωe·Ld·id`**（式 5、6）。转子静止时 `ωe = 0`，这两项**严格为零**，于是 d 轴与 q 轴彻底解耦、方程退化成两个独立的一阶 RL 电路（式 7、8）—— 这就是本模式能在几十 µs 尺度上把电感量出来的根本原因。

## 二、硬件与软件的时序前提（**这一节决定公式怎么推**）

### 2.1 频率关系

本板 PWM 与电流采样是**同一个频率**，由 `motor_config.h` 的一个宏决定：

```
f_PWM = MOTOR_PWM_FREQ_HZ = 20 kHz                          (1)
f_ISR = I_ACTIVE_SAMPLE_RATE_HZ = f_PWM = 20 kHz            (2)
T_s   = 1 / f_ISR = 50 µs                                   (3)
```

注：`I_SAMPLE_MODE = I_SAMPLE_ADC2_PWM_VALLEY`（单边沿）→ 采样率 = PWM 频率；若改成 `PEAK_VALLEY` 就是 2 倍频率，式 (2) 要改。**本机已用独立时基（`tickTimer`）实测 `fs_meas = 20000 Hz` 确认无误**（代码里打印在 probe 行）。

### 2.2 采样在**谷点**、占空比在**峰点**装载 → 一采样延迟

- ADC 触发：TMR4 三角波**谷点**（`I_SAMPLE_ADC2_PWM_VALLEY`）；
- 占空比影子寄存器装载：三角波**峰点**（`TMR4_OC_BUF_COND_PEAK`）；
- 于是"本拍写下去的电压"要到 25 µs 后才生效，而"本拍读到的电流"反映的是**上一拍**写下去的那个平台：

```
第 k 拍采到的电流  ←→  第 k-1 拍写入的平台电压                    (4)
```

式 (4) 不是推出来的，是**用波形抓取实测确认**的：把 64 点原始采样的"平台极性标签"整体移后一个采样，16 个平台的电流斜率方向才全部一致（不移动则一半以上对不上）。这一步曾让第一版把所有数据误判为无效。

### 2.3 平台的划分

电压符号每 `FOC52_HALF_ISRS = 2` 个采样周期翻转一次，所以：

```
T_plt = FOC52_HALF_ISRS × T_s = 2 × 50 µs = 100 µs              (5)
```

即注入方波是 **5 kHz**，每个平台 100 µs，平台内恰好有 **2 个采样点**（相隔 T_s = 50 µs）。d/q 之间用 200 ms 零矢量隔开（`FOC52_GAP_MS`）。

## 三、物理模型

### 3.1 dq 电压方程（一般形式）

```
vd = R·id + Ld·(did/dt) - ωe·Lq·iq                              (6)
vq = R·iq + Lq·(diq/dt) + ωe·Ld·id + ωe·ψf                      (7)
```

### 3.2 锁轴 + 静止后的简化

把电压矢量锁在 d 轴（θ = 转子电角度，来自编码器 + mode 24 零点）或 q 轴（θ + 90°），并保证转子静止：`ωe = 0`，且注入只在被测轴上（另一轴电流 ≈ 0）：

```
d 轴测量：vd = R·id + Ld·(did/dt)                               (8)
q 轴测量：vq = R·iq + Lq·(diq/dt)                               (9)
```

式 (8)(9) 就是本模式全部推理的出发点：**一个一阶 RL 电路**。

### 3.3 注入波形（直流偏置 + 方波）

```
v(t) = V_bias·σ(t) + Vsq·s(t)                                   (10)
```

- `s(t) = ±1`：方波，每 T_plt = 100 µs 翻一次（就是 §2.3 的"平台"）；
- `σ(t) = ±1`：偏置极性，每 `FOC52_BIAS_CYCLES = 16` 个周期（= 3.2 ms）翻一次号，目的是让 q 轴的恒定力矩净冲量抵消（防转子被推着连续转）；
- **为什么要加直流偏置**：让被测轴电流**始终同号**（见 §5.2）。这样死区等效电压在两极性平台上同号，可以在平台均值里精确抵消（见 §5.4 与式 32）。

### 3.4 死区等效电压与直流工作点

死区（含管压降）表现为一个**始终顶着电流方向**的等效电压：

```
v_eff(t) = v(t) - sign(i)·V_dead                                (11)
```

一个完整周期内方波的平均值为零，于是稳态下"平均施加电压 = R × 平均电流"：

```
V_bias - V_dead = R·|I_bias|      →      |I_bias| = (V_bias - V_dead) / R     (12)
```

式 (12) 是 §5.4 反推 V_dead 的依据（本机实测 V_dead = 147~166 mV，与 mode 51 的 160 mV 一致）。

### 3.5 平台内的斜率

把电流写成"直流 + 波动"：`i = I_bias·σ + δ`，代入式 (8)/(9) 并用式 (12) 消掉 `V_bias − V_dead`：

```
di/dt = ( Vsq·s(t) - R·δ ) / L                                  (13)
```

在 `|δ| << |I_bias|` 的区间（本机 |δ| ≈ 0.3~0.6 A，I_bias ≈ 0.8~1.2 A）：

```
|di/dt| ≈ Vsq / L                                               (14)
```

**式 (14) 就是"用纹波斜率反推电感"的全部物理内容**：平台内电流近似线性上升/下降，斜率只由 Vsq 和 L 决定。剩下的问题只有一个：**怎么把这段斜率从采样序列里干净地量出来**。

## 四、采样几何与两种提取算法（本文最关键的一节）

### 4.1 一个平台内有两点

由式 (5)：平台 100 µs、采样 50 µs ⇒ 每个平台恰好 2 个采样点。设第 k 个平台的两个采样为 `s(2k)`、`s(2k+1)`（单位 A）。

### 4.2 算法 A：单点差分（**理论上最直接，实测最脆弱**）

直接用同一平台两点之差：

```
ΔP = s(2k+1) - s(2k)          →      L_pair = Vsq·T_s / |ΔP|     (15)
```

几何上它是最**直接**的估计：只要这两点仍落在同一平台（同一斜坡）内，`|ΔP|` 就精确等于该平台内的电流增量。10 ns 步长仿真（`_cardgen/sim_mode52_env.mjs`）扫遍采样相位的全部取值，`L_pair` 只偏 **+0.6% ~ +7%**（§4.4 表）。

**但它怕"错拍"**：翻转是按 **ISR 调用次数**计的，一旦某次写入晚一点、错过峰点的影子装载，采样点与平台边界的相位就**永久错开一拍**。设某次采样对的时间区间是 `[x, x+T_s]`，若平台边界 B 落在区间内、且 `d = B − x`（0 < d < T_s），则这一对前半段斜率为 +s、后半段为 −s：

```
若区间内无边界： |Δ| = T_s · |di/dt|
若区间内有边界： |Δ| = | 2d - T_s | · |di/dt|        （0 < d < T_s）   (16)
```

- d = 0 或 T_s：配对完全落在同一平台内 → |Δ| = T_s·|di/dt| → **正确**；
- d = T_s/2：配对跨过三角波顶点，两点关于顶点对称 → |Δ| ≈ 0（信息丢失）。

式 (16) 的系数在 **1.0 ~ 0.5** 之间随相位变化（d 在 (0, T_s) 内均匀时均值为 T_s/2），对相位取平均得：

```
E|Δ| ≈ 0.75 × (Vsq·T_s/L)          （系数平均 0.75，范围 0.5~1.0）    (17)
```

本机第一轮实测的系数正是 **0.72**（`|Δ|` 只有理论值的 0.72 倍）—— 与式 (17) 吻合，说明当时的偏差就是相位错拍造成的。

需要说清楚的是：式 (17) 是**相位之间的平均效应**，单次跑里相位是固定的，理论上离散度应该很小。但实测同一轮内的离散度高达 **52%**，说明**相位在跑的过程中会变**（偶发的"错过影子装载"把相位挪了一拍，形成几种相位的混合）—— 于是同一批数据里既有系数 1.0 的对、也有系数 0.5 的对，均值落在 0.72、离散度很大。这正是算法 A 不能用的原因。

另一个独立的脏化来源：平台边界处存在一个**台阶**（§4.5），它让"跨边界那一对"反而比"平台内那一对"更大，于是"取两对里的较大者"这种修法会**专门挑到脏数据**（实测把 L 压低一半：报 20 µH，而正确算法给 34~37 µH）。

### 4.3 算法 B：平台均值法（**最终采用，但它是"间接"估计**）

**先取平台均值**（这一步是全部关键）：

```
m_k = [ s(2k) + s(2k+1) ] / 2                                   (18)
```

**均值去脏**：采样序列里混着约 ±0.5 A 的快速交替干扰（周期≈2 个采样点，接近奈奎斯特，来源见 §八），它在相邻两点上**符号相反**，两点相加即抵消 —— 这是均值法的第一个好处（`pair` 法两点相隔 50 µs，抵不掉）。

**但要注意它测的是什么**：设平台起点为 0、平台长 `T_plt = 2T_s`，组内两点在 `δ` 与 `δ + T_s`（δ ∈ [0, T_s]，δ 由 ADC 谷点采样与占空比峰点装载的相位差决定）：

```
m_k = i( δ + T_s/2 )              （两点都在同一斜坡内时，均值 = 中点电流）
线性三角波模型： ΔE = s·( T_s - 2δ )        s = Vsq/L (A/s)       (19)
```

相邻两个平台的中点**正好相隔 T_plt**，所以 `ΔE` 是"电流在 T_plt 内的真实变化"；但三角波在一个 `T_plt` 内**正好越过一个顶点**，这段"变化"因此不等于整段斜坡 —— 顶点会把两点之间的变化"折回"一部分，式 (19) 里的 `(T_s − 2δ)` 就是这个折扣：

- δ = 0（首点正好落在平台边界/三角波顶点上）：|ΔE| = s·T_s → **只有理想斜坡的一半**；
- δ = T_s/2（两点关于平台中心对称，即采样点落在平台正中）：**|ΔE| → 0，信息完全丢失**。

两个退化点分别对应两套算法，头注释里"不能取 1 拍"说的正是第一种：

- `pair`（式 15）退化于"两点关于**顶点**对称"：取 1 拍时两点相隔 50 µs 而平台边界就在正中，`|ΔP| → 0`；取 2 拍后两点占满整个平台，必然有一点离顶点 25 µs，`|ΔP|` 不再被抵消（仿真里只偏 +0.6%~+7%）；
- `env`（式 21）退化于"两点中点落在**平台中心**"：取 2 拍时若 δ = T_s/2，平台间差归零。

取 2 拍时 `|ΔE| ≤ s·T_s`，理想模型下 `L_env = Vsq·T_plt/|ΔE| ≥ 2L`（`_cardgen/sim_mode52_env.mjs`：δ 从 0 扫到 T_s 时 `L_env/L` 从 **23 倍降到 1.9 倍**，永远取不到真值）。

**再取相邻平台均值之差**：

```
ΔE = m_k - m_(k-1)                                              (20)
```

在**线性斜坡极限**（T_plt << τ = L/R）下，理想 RL 模型给出 `ΔE = Vsq·T_plt/L`，于是：

```
ΔE = Vsq·T_plt / L      →      L = Vsq·T_plt / |ΔE|             (21)
```

式 (21) 就是**本模式最终使用的公式**。但要如实说清它的地位：**理想 RL 模型下式 (21) 给不出正确值**（由式 (19) 的几何，理想模型里 `|ΔE| ≤ s·T_s`，即 `L_env ≥ 2L`，仿真见表）。它在固件上成立，是因为真实采样波形比理想三角波多了一个与平台边界同步的**台阶**（§4.5）：台阶把 `|ΔE|` 从理想模型的 ≤0.46 A 抬到实测 **0.64 ~ 0.87 A**，正好接近"一个完整平台斜坡" `Vsq·T_plt/L` 的量级。

**台阶随注入电压成比例**（不是固定干扰）：同一 `Vsq` 下 d 轴报 42~51 µH、q 轴报 58~73 µH，两轴相差 1.5 倍且与两轴电感之比一致；若台阶是固定干扰，两轴会报**同一个** `env`。证据链见 §4.5。

**结论**：式 (21) 是**经验成立**的间接估计（依赖"台阶 ∝ Vsq/L"这个尚未完全定位的机制）；式 (15) 的 `pair` 才是理论上直接的估计，却怕错拍。两者都打印，互为佐证 —— 这是本模式打印两套 L 的原因。

若要更严格，把方波驱动一阶 RL 的精确解代入：

```
ΔE = 2·(Vsq/R)·tanh( T_plt / (2τ) )       （τ = L/R）           (22)
L  = (Vsq·T_plt/|ΔE|) × [ x / tanh(x) ]，  x = T_plt/(2τ)       (23)
```

本机参数（L ≈ 42 µH、R = 0.098 Ω → τ ≈ 429 µs）下 x ≈ 0.117，`x/tanh(x)` ≈ 1.0045 ⇒ **线性化的误差只有 0.45%**，可以直接用式 (21)。

### 4.4 仿真复核 + 实测对照

**仿真**（`_cardgen/sim_mode52_env.mjs`，理想 RL：L = 42.3 µH、R = 0.098 Ω、V_bias = 0.248 V、Vsq = 0.391 V、死区 0.16 V，扫采样相位 φ）：

| 采样相位 φ | 平台内差 \|ΔP\| | 平台间差 \|ΔE\| | `L_pair` | `L_env` | pair/真值 | env/真值 |
|---|---|---|---|---|---|---|
| 0 µs（两点落在平台正中） | 459 mA | 40 mA | 42.6 µH | 979 µH | **1.006** | 23.1 |
| 10 µs | 449 mA | 222 mA | 43.6 µH | 176 µH | 1.030 | 4.17 |
| 20 µs | 439 mA | 399 mA | 44.6 µH | 98 µH | 1.054 | 2.31 |
| 25 µs（本机硬件相位） | 434 mA | 487 mA | 45.1 µH | 80 µH | 1.066 | 1.90 |

**仿真结论**：① `pair` 对采样相位几乎不敏感（+0.6% ~ +7%），理论上是**可靠**的估计；② `env` 在理想模型里**永远偏高 2 倍以上**，它依赖真实波形里的台阶（§4.3、§4.5）。

**实测对照**（同一批数据，d/q 两轴）：

| 数据 | `env` = 式 (21) | `pair` = 式 (15) | 说明 |
|---|---|---|---|
| d 轴探测（0.5 V） | 42 µH | 61 µH | 台阶在场，pair 偏大 |
| d 轴探测（0.5 V，另一次） | 33 µH | 70 µH | 台阶更大，pair 偏大 1 倍 |
| q 轴探测（0.5 V） | 78 µH | 77 µH | 台阶缺席，两法一致 |
| q 轴正式（391 mV） | 70 µH | 65 µH | 两法差 8% |

**实测结论**：`env` 在 5 轮重复里稳定（Ld 40~51、Lq 58~73），`pair` 时好时坏（曾把 Ld 压到 20 µH）⇒ **只认 `env`，`pair` 只作诊断打印**。理论上更可靠的 `pair` 反而更差，原因就是式 (16)：它怕"错拍"，而 `env` 的两点平均恰好把这种错拍摊平。RTT 里两者都打出来，就是为了让你能自己看到这个差异。

### 4.5 平台边界台阶（**尚未完全定位，但已证明它 ∝ Vsq/L**）

由式 (21) 与式 (15) 可以反推台阶大小。本模式打印的 `env` 就是式 (21) 的 L、`pair` 就是式 (15) 的 L_pair，两者之比为：

```
env/pair = (T_plt/T_s) · |ΔP| / |ΔE| = 2 · |ΔP| / |ΔE|       (24)

纯斜坡（无台阶、相位稳定）时 |ΔE| = 2·|ΔP| ⇒ env/pair = 1
边界处额外台阶占比 = 1 / (env/pair) - 1
```

实测 `env/pair` 落在 **0.47 ~ 1.17**（探测阶段 0.47~0.69，正式测量 1.00~1.17），即 `|ΔE| = 1.7 ~ 4.3 × |ΔP|`；而理想 RL 模型下这个比值**最大也只有约 1.1**（§4.4 仿真：最好相位 487 mA vs 434 mA，最差相位只有 40 mA vs 459 mA）。**超出的这 1.5 ~ 4 倍就是台阶**：它把 `|ΔE|` 从理想模型的 ≤0.49 A 抬到实测 0.64 ~ 1.19 A，正是一个完整平台斜坡 `Vsq·T_plt/L` 的量级，式 (21) 才在数值上成立。

**三条证据说明台阶 ∝ Vsq/L（而不是固定干扰）**：

1. **两轴不同值**：同一 `Vsq`、同一相位下，d 轴 `env` = 42~51 µH、q 轴 = 58~73 µH，比值 1.5 与两轴真实电感之比一致。若台阶是固定干扰，两轴会读到同一个 `env`。
2. **随幅值成比例**：探测阶段用 0.5 V、正式测量用 391 mV，`env` 反推的 L 在两种幅值下一致（33~42 µH 与 45 µH 同量级），说明 `|ΔE|` 随 `Vsq` 等比缩小。
3. **随电流饱和移动**：偏置从 726 mA 漂到 873 mA 时 `env` 单调下降（51 → 40 µH），与"Ld 随电流饱和下降"的物理一致 —— 固定干扰不会跟着偏置电流变。

怀疑的物理来源仍是**电压矢量反转瞬间的开关/二极管瞬态**，以及采样点与开关边沿的相对相位。它不影响式 (21) 的可用性（台阶 ∝ Vsq/L 时它只改变系数，而系数已被 5 轮实测与手册值互校），但如果要把 5~12% 的残余误差再收窄，就得先把它查清。

**怎么进一步定位**（留给后续）：把 `g_ldlq52_wave_en` 置 1 抓一窗波形，对比 `wave_sgn` 与 `wave`：若在极性翻转的那一拍附近能看到一个与 `Vsq` 同号的跳变，即可确认台阶位置；再改变 `g_ldlq52_cycles` 或 `FOC52_HALF_ISRS` 看它是否跟着移动，就能判断它是开关瞬态还是采样相位。

## 五、自适应与护栏（保证公式 (21) 成立的条件）

### 5.1 自适应方波幅值

先用 `FOC52_PROBE_V = 0.5 V` 打 `FOC52_PROBE_CYCLES = 10` 个周期，测得 `ΔE_probe`，再按目标"平台均值差 = di_target/2"重定幅值：

```
Vsq = V_probe × ( 0.5·di_target ) / ΔE_probe                    (25)
Vsq 夹在 [ v_min = 0.3 V, v_max = 3.0 V ]                       (26)
```

（`di_target` 默认 1.0 A 是**峰峰值**，所以目标平台均值差是它的一半。）本体实测：L = 42 µH 时 Vsq ≈ 0.3~0.6 V；若 L 是 260 µH，自适应会把 Vsq 抬到约 2.6 V。

### 5.2 偏置电流的建立与**单极性条件**

```
目标偏置：I_bias_target = max( bias_a , 0.5·di_target × 1.5 + 0.05 )    (27)
偏置电压：V_bias = r_used × I_bias_target + V_dead_prior               (28)
单极性条件：|I_bias| > |ΔE| / 2                                         (29)
```

- 式 (27) 的护栏把默认 `bias_a = 0.7 A` 抬到 **0.8 A**（本机日志 `bias=800 mA` 即是它）；
- 式 (28) 里 `V_dead_prior = 0.16 V` 只是**先验**，落点不准也不影响 L（见下条）；
- 式 (29) 是**方法成立的硬条件**：电流一旦过零，死区等效电压就在平台内变号，式 (13) 的 `V_bias − V_dead` 抵消关系失效；
- 因此代码里还有**偏置自抬**：实测 `|I_bias| < 0.75·|ΔE|` 时把 V_bias 每次抬 0.1 V 重探（上限 1.5 V，电流硬上限 2 A）：

```
若 |I_bias| < 1.5×(|ΔE|/2)  →  V_bias ← V_bias + 0.10 V，重探     (30)
```

### 5.3 合理性闸门

只有探测档反推的电感落在合理区间才继续（防止把异常波形当成小电感、一路把偏置电流推到烧电机 —— 这确实发生过，冲到 3.04 A）：

```
L_probe = Vsq·T_plt / ΔE_probe  ∈ [ 3 µH , 3000 µH ]            (31)
否则 evt = 7 (IMPLAUSIBLE)，停止抬偏置，数据作废                  (32)
```

### 5.4 反推死区电压（副产品）

由式 (12) 直接得：

```
V_dead = V_bias - r_used × |I_bias|                             (33)
```

本机多轮实测 147~166 mV，与 mode 51 的拟合值（144.5/144.7/160.2 mV）一致 ⇒ R 与死区模型自洽。

## 六、结果与判据

### 6.1 主结果

```
Ld = Vsq·T_plt / |ΔE_d| ,   Lq = Vsq·T_plt / |ΔE_q|             (34)
比值     Lq/Ld                                                  (35)
与手册   vs_vendor = Ld / FOC_MOTOR_LS_UH                        (36)
```

### 6.2 转子运动对 Lq 的影响（**q 轴比 d 轴敏感得多**）

转子一动，式 (7) 的反电势项 `ωe·ψf` 就直接叠在 q 轴电压上，而 d 轴式 (8) 里没有这一项：

```
Lq_测量 = Lq × vq / ( vq - ψf·ωe )      →     相对误差 ≈ ψf·ωe / vq     (37)
ψf·ωe = 0.00084 × (2π/60) × 10 × rpm ≈ 0.00088 × rpm  (V)               (38)
```

代入 vq = 0.391 V：

| 转子速度 | 反电势 (38) | Lq 误差 (37) |
|---|---|---|
| 5 rpm | 4 mV | 1% |
| 20 rpm | 18 mV | 4.5% |
| 50 rpm | 44 mV | 11% |
| 100 rpm | 88 mV | 23% |

运动用**编码器路径**判断（净位移会回绕、且来回抖动时净位移≈0，**必须看路径**）：

```
测量窗 = cycles × 2 × T_plt = 32 × 200 µs = 6.4 ms                       (39)
rpm ≈ path / 4096 / 6.4 ms × 60 ≈ path × 2.29                            (40)
判据：path ≤ 8 打 warn；path > 64 判 evt=5 (MOTION)、结果作废             (41)
```

注：由式 (37)(40)，`path = 64` 对应约 146 rpm、Lq 误差约 30% ⇒ **式 (41) 的作废门槛偏松**，实操建议按 `path ≤ 4`（<10 rpm、误差 <2%）采信。

### 6.3 工作点（饱和）对 Ld 的影响

增量电感随电流下降。本机五轮实测拟合约：

```
dLd / dI_bias ≈ -0.075 µH/mA                                    (42)
```

⇒ 偏置电流漂 ±50 mA 就带来 ±3.7 µH（±8%）的 Ld 波动。**这是目前离散度的主因**（见 §七、§八）。

### 6.4 其它判据

```
符号一致性：cons ≥ FOC52_CONS_MIN_PCT = 85%                      (43)
（= 采样对的差值方向与平台极性同号的占比）
```

`g_ldlq52_de_cons_pct`（平台均值差的符号一致性）本机**恒为 0**：说明注入响应相对"我预期的方向"是反的 —— 最可能是 **mode 24 标定的电气零点差 180°**（永磁转子对齐时 ±d 都稳定，是固有二义性）。它不影响 |L|（同一个轴，只是方向反），但**将来做任何 id 注入（MTPA、弱磁）之前必须先定下这个方向**。

### 7.1 五轮重复（2026-09-27，`do_q=1`，转子静止 `path≈0`）

|---|---|---|---|---|---|---|---|
| 1 | 51 | 64 | 1.239 | 1.213 | 726 | 584 | 154 |
| 2 | 45 | 58 | 1.307 | 1.052 | 817 | 674 | 160 |
| 3 | 45 | 73 | 1.623 | 1.070 | 830 | 662 | 160 |
| 4 | 42 | 66 | 1.571 | 0.999 | 873 | 709 | 166 |
| 5 | 40 | 65 | 1.626 | 0.947 | 871 | 748 | 154 |

| 离散度 | ±9% | ±8% | ±13% | | | | |

**注意第 5、6 列**：偏置电流从 726 mA 漂到 873 mA（+20%）而偏置电压固定 238 mV，对应的 ΔE 从 584 单调涨到 748、Ld 从 51 单调降到 40 —— 这就是式 (42) 的饱和效应在起作用。

### 7.2 结论

1. **Ld 中位数 45 µH，手册 42.3 µH，差 +6%** ⇒ 厂商手册可信；此前由 R = 0.15 Ω 反推的"260 µH"**彻底排除**；
2. **Lq > Ld，5/5 成立** ⇒ 这台电机**确有凸极**（IPM 特征）；
3. 比值目前只能定到 **1.3 ~ 1.6**（中位数 1.57），还不能定小数 —— 原因是式 (42) 的工作点漂移尚未治理。

### 7.3 磁阻转矩与 MTPA 收益（用实测参数算）

转矩公式（`Ld < Lq`，磁阻项需 id < 0）：

```
T = 1.5·p·[ ψf·iq + (Ld - Lq)·id·iq ]                            (44)
MTPA 条件（|i| = I 固定时对角度求极值）：cos2θ = [ψf /((Lq-Ld)·I)]·sinθ   (45)
```

| 电流 | MTPA 最优 id | 相对 id = 0 的转矩增益 |
|---|---|---|
| 1 A | −0.024 A | **+0.03%** |
| 5 A | −0.6 A | **+0.7%** |

**结论：ψf 相对 (Lq−Ld)·i 大得多，磁阻转矩可忽略 ⇒ 这台电机做 MTPA 没有意义**（这也解释了 mode 27/41 扫 δ 的结论"id = 0 已最优"）。

## 八、已知局限与未解决问题

| # | 问题 | 影响 | 状态 |
|---|---|---|---|
| 1 | **平台边界台阶**（§4.5） | 式 (21) 的数值系数依赖它（5~12% 残余误差）；`pair` 与 `env` 的差就是它的大小 | **已证明 ∝ Vsq/L**（三条证据见 §4.5），但物理来源未定位（怀疑矢量反转瞬间的开关/二极管瞬态、采样与开关边沿的相对相位） |
| 2 | **偏置电流是开环给的**（式 28 依赖 `V_dead_prior`） | 工作点漂移 → 由式 (42) 带来 Ld ±8% | 建议改为"按实测电流闭环对齐到 `bias_a`"，尚未实施 |
| 3 | **mode 24 零点 180° 二义性**（§6.4） | 不影响 \|L\|；影响 id 注入方向 | 可用"给一个小 id 看电流正负"一次定下来 |
| 4 | **q 轴恒定力矩**（≈0.009 N·m @0.7 A，每 3.2 ms 翻向） | 转子动则 Lq 偏大（式 37） | 建议夹紧；或把 `di_target` 降到 0.4 A 使力矩降到 1/2.3 |
| 5 | 与手册的 +6%（Ld） | 可能是工作点/测试条件不同（饱和），也可能是手册给的是别的定义 | 扫 `bias_a` 得到 Ld(I) 曲线即可判断 |
| 6 | 采样序列里约 ±0.5 A 的快速交替干扰 | `pair`（两点相隔 50 µs）被它污染 | 来源未知（近奈奎斯特、疑似与 10 kHz 附近的谐振/采样相位有关）；`env` 的两点平均恰好抵消它 |
| 7 | **理论上 `pair` 才是直接估计，`env` 依赖台阶** | 若哪天台阶消失，`env` 会偏高 2 倍以上（§4.4） | 两者都已打印，随时可交叉验证；根治办法是把台阶查清后回到 `pair` |
