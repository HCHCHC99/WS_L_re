> 记录日期：2026-09-23

## 一、现象

mode 40（编码器 FOC 速度/电流双闭环）运行时电机有**嘈杂噪声**，**目标转速 = 0、转子静止时依然存在**。

理论上应完全安静：目标 0 → `iq_ref = 0` → id/iq 反馈 ≈ 0 → 电流 PI 输出 ≈ 0 → SVPWM 输入 0 → 占空比精确 50/50/50 → 线电压为 0 → 无电流。

**但它不安静。**

---

## 二、定位过程（VOFA 实测，目标 0 静止）

### 2.1 第一步：区分"参考在动"还是"反馈在动"

| 通道 | 变量 | 实测范围 | 判读 |
|---|---|---|---|
| ch7 | `g_speed40_iq_ref_ma`（**参考**） | ±0.02 A | ≈ 0 → **速度环没在要求任何东西** |
| ch5 | `g_foc_iq_ma`（**反馈**） | **+1.21 / −0.8 A** | ⚠️ **真实电流在振荡** |
| ch8 | `g_speed40_vd` | ±0.3 V | d 轴也在纠正 |
| ch9 | `g_speed40_vq` | ±0.5 V，**不规则** | q 轴纠正更猛 |

**关键推论**：参考是 0，反馈却达到 ±1A 量级——说明**电流环在"忠实执行"一条振荡的指令，而这条指令是它自己根据带纹波的反馈算出来的**。

> 若反馈只是被污染的假信号，PI 会去"追"它但电机里不会真流过电流。现在 ch5 真的在 ±1A 摆动 → **电流物理上存在**。

### 2.2 第二步：量级核算，确认是开关纹波

用 `L = 42.3 µH`、`f_sw = 10 kHz`、`V_bus = 12 V`：

```
ΔI_pp = V·D·(1−D)/(L·f_sw)
  D=50%: 0 A                   ← 零矢量，无纹波
  D=45%: 12×0.45×0.55/(42.3µ×10k) = 7.0 A
  D=25%: 5.3 A
```

ch5 观测峰峰 ~2A，正对应"占空比只偏离 50% 一点点"时的纹波量级 → **量级自洽**。

### 2.3 第三步：确认是"环路放大"而非"环境噪声"

**决定性实验：把电流环 kp 从 0.5 降到 0.1**

| kp | 噪声 |
|---|---|
| 0.5（原值） | 明显嘈杂 |
| **0.1** | **大幅下降** |
| 0.05 | 与 0.1 **无差别** |

**kp 降低使噪声大降 → 证明环路增益在因果链上**（若是外部干扰灌进来，改 kp 不会有效果）。
**0.1 与 0.05 无差别 → 证明已压到底噪**（环路够不着的部分）。

## 三、机理：开关纹波正反馈极限环

```
占空比微偏 50%
    ↓
产生开关纹波电流（±1A 量级）
    ↓
【无抗混叠的电流反馈】把它原样采进来
    ↓
电流 PI 把它当成"真实误差"去纠正
    ↓   P 项 = kp × 纹波  ← kp 直接决定这条路增益
占空比被进一步推偏
    ↓
纹波更大 → 回到第一步
    ↓
【正反馈闭合 → 不规则极限环】
```

### 为什么"不规则"而不是单一频率

纹波是开关周期性的，但采样点相对纹波的相位随占空比漂移，折叠出来的差拍成分频谱很杂，加上 PI 增益在带内的频率响应，合起来就不是单一频率。

### 三个必要条件的缺一不可

| 条件 | 现状 |
|---|---|
| 有无抗混叠的电流反馈 | ✅ [I.c:518-520](ws_L_v.inmop_curloop_re/HC32F460_DDL_Rev3.3.0/projects/ev_hc32f460_lqfp100_v2/ws/I.c#L518-L520) mA 换算后**直接进 PI**；[I.c:525-554](ws_L_v.inmop_curloop_re/HC32F460_DDL_Rev3.3.0/projects/ev_hc32f460_lqfp100_v2/ws/I.c#L525-L554) 那个 Biquad 注释写着 "display only"，**不进控制环** |
| 低阻低感电机放大效应 | R=0.1Ω、L=42.3µH → **几毫伏线电压失衡 = 几十毫安电流**，占空比一个量化台阶就是几十毫安级 |
| 环路带宽够高去追纹波 | 原 kp=0.5 → `ωc = kp/L = 1.88 kHz`，远高于纹波的可观测差拍成分 |

## 四、处置：降电流环 kp

### 4.1 参数改动

| 宏 | 原值 | 现值 | 位置 |
|---|---|---|---|
| `SPEED40_PI_KP` | 0.5 V/A | **0.1 V/A** | `foc_speed40.h:90` |
| `SPEED40_PI_KI` | 300 V/(A·s) | 300（未动） | `foc_speed40.h:91` |
| `SPEED40_SPD_KP_MA_PER_RPM` | 1.8 → 4.0 → **2.0** | **2.0** mA/rpm | `foc_speed40.h:109` |
| `SPEED40_SPD_KI_MA_PER_RPM_S` | 0.2 → **0.45** | 0.45 | `foc_speed40.h:110` |

⚠️ `SPEED40_PI_KP` 同时作用于 **id 环与 iq 环**（`foc_speed40.c:71-72, 86-87`），两个轴同步变化。

### 4.2 为什么"降 kp"能治

**kp 直接是那条正反馈路径的增益**（`P 项 = kp × 纹波`）。kp 降 5 倍，正反馈增益降 5 倍，极限环幅度随之大幅下降。

**这不是"滤波"**——它没有引入任何相位滞后，只是把环路对纹波的响应能力削弱了。

### 4.3 代价（必须记住）

```
电流环带宽：ωc = kp/L = 0.1/42.3µH = 376 rad/s ≈ 60 Hz
```

| 项 | 评价 |
|---|---|
| 与速度环（kp=2.0 → 约 36 Hz）分离度 | **1.7 倍** ⚠️ 低于串级经验要求 5~10 倍 |
| 结论 | **0.1 是串级结构下限，不要再降** |

**副作用（预期但可接受）**：电流环变慢 → 转矩响应变慢。因为速度环只有 36 Hz，暂时不影响。

### 4.4 一个副产物

kp=0.1 时电流环阻尼比：

```
ζ = (R + kp)/(2√(ki·L)) = 0.2/(2×0.1127) ≈ 0.89
```

**接近临界阻尼**（ζ=1 对应 kp≈0.108），比原来的过阻尼（ζ=2.66）更"刚好"。

## 七、残余噪声：现象与假设

### 7.1 现状

kp=0.1 后噪声已大幅下降，**但仍有一点点**。

### 7.2 为什么确定它是"环路够不着"的部分

kp=0.1 与 kp=0.05 **噪声无差别** → 继续削弱环路增益毫无收益 → 剩下的与本环路增益无关。

### 7.3 候选来源

| 候选 | 机理 | 是否受 kp 影响 |
|---|---|---|
| **10 kHz PWM 开关本身** | 三相半桥在 50/50/50 下仍硬开关，共模电压 12V 幅度、10 kHz 跳变，通过绕组-定子寄生电容耦合 → 磁致伸缩 | ❌ 不受 |
| 零矢量下的残余纹波 | 占空比只要不精确等于 50/50/50 就有线电压与纹波电流 | ❌ 基本不受 |
| 电流环残余动作 | kp=0.1 下环路仍在小幅追纹波 | ⚠️ 部分受 |

### 7.4 待做的判别实验

**实验 A：`check_noisy_mode = 2`**（`main.c:62`，只关 PWM 输出、保留 ADC 与计数器）

| 结果 | 结论 |
|---|---|
| 噪声消失 | 就是 PWM 开关本身（候选 1） |
| 噪声仍在 | 是纹波/信号链/其他 |

**实验 B：听音色**
- 尖锐 10 kHz 单音 → 候选 1 主导
- 粗糙"沙沙/嗡嗡" → 候选 2 主导

## 八、下一步：改 PWM 频率的施工清单（未执行）

### 8.1 假设

10 kHz 恰好落在**人耳最敏感的高频段**（听觉范围 20Hz~20kHz，10kHz 处灵敏度很高）。提到 20 kHz 可移出可听范围。

### 8.2 附带收益（理论）

纹波与开关频率成反比：

```
ΔI_pp = V·D·(1−D)/(L·f_sw)   →   f_sw 翻倍 ⇒ 纹波减半
```

**同时减小纹波源 + 移出可听频段**，两个机制都指向噪声下降。

### 8.3 ⚠️ 施工清单：改 `MOTOR_PWM_FREQ_HZ` 会波及什么

`MOTOR_PWM_FREQ_HZ`（`motor_config.h:14`）**不只是载波频率**——它通过 `I.h:98-105` 的 `I_ACTIVE_SAMPLE_RATE_HZ = MOTOR_PWM_FREQ_HZ` 同时决定了**电流采样率与 FOC ISR 频率**。

| # | 影响项 | 10 kHz | 20 kHz | 是否需要改代码 |
|---|---|---|---|---|
| 1 | **ISR 执行时间预算** | 50 µs | **25 µs** | ❌ 但**必须先实测当前耗时**，超出即死 |
| 2 | 电流环频率 | 10 kHz | 20 kHz | 自动（宏推导） |
| 3 | 速度环抽稀 | 5ms/50 拍 | 5ms/100 拍 | 自动（`SPEED40_SPD_WIN_TICKS` 由宏推导） |
| 4 | 电流环带宽裕度 | kp/L=60Hz | 不变 | **但采样率翻倍 ⇒ 相位裕度改善**，kp 可上调 |
| 5 | 死区占周期比例 | 0.5% | **1.0%** | ❌ 无需改，但死区畸变加重 |
| 6 | 显示 Biquad 实际 fc | 40 Hz | **80 Hz** | ❌ 无需改，仅显示曲线变化 |
| 7 | `I.c` 校准样本数注释 | "~10000 次" | 变 20000 | ❌ 仅注释 |
| 8 | mode 45 SMO 的 `g_smo_lpf_alpha` | 0.39 | **需改 0.24** | ⚠️ `foc_smo.c:35` 注释已说明 |
| 9 | mode 45 PLL 的 `g_pll_wout_lpf_alpha` | 0.0125 | 需重算 | ⚠️ `foc_pll.c:26` |
| 10 | BEMF 梳状滤波（首零点 fs/8） | — | 自动跟随 | ❌ `Bemf.c:213` 已参数化 |

**只跑 mode 40 的话，真正要动手的是第 1 项（验证 ISR 耗时）；第 8、9 项只在跑 mode 45 时才要紧。**

### 8.4 实验 C（改频率前必做）：量 ISR 耗时

在 `Foc_Isr()` 入口与出口各翻转一个**空闲 GPIO**，示波器量高电平宽度：

```c
/* foc.c 的 Foc_Isr() 内，临时加（Pin 需自行选一个未被占用的） */
GPIO_SET(<PORT>, <PIN>);      /* 入口 */
... 原有 ISR 主体 ...
GPIO_RESET(<PORT>, <PIN>);    /* 出口 */
```
（宏定义见 `Adp/Gpio_io.h:9-11`：`GPIO_SET` / `GPIO_RESET` / `GPIO_TOGGLE`）

| 实测值 | 结论 |
|---|---|
| < 25 µs | 可以安全改到 20 kHz |
| 25 ~ 50 µs | 只能小幅提高（如 12~15 kHz），或先优化 ISR |
| > 50 µs | **当前 10 kHz 下已经在超时边缘，先优化 ISR** |

⚠️ 测的是**最坏路径**：mode 40 的 ISR 只在 `g_speed40_running` 时走 `Foc_Speed40_Step()`，
所以必须**在 mode 40 运行中**测量，不要在 mode 0 下测。

### 8.5 风险提示

- **有可能变差**：更快的开关边沿 + 更高的 dV/dt，可能激发高频寄生谐振；死区占比翻倍
- **可能只是改变了音色**而非消除：20 kHz 基频听不到，但 2、3 次谐波（40/60 kHz）虽不可听，高频段仍可能通过差拍产生可听成分
- **建议先做实验 A/B**，若确认是 10 kHz 开关本身，再动频率；否则改频率可能白费

## 九、不要动的东西（避免复发）

| 项 | 原因 |
|---|---|
| **不要把电流环 kp 调回 0.5** | 除非先加了传感器 RC（见下） |
| **不要指望改速度环 kp/ki 能治静止噪声** | 噪声机理在电流环内部，速度环输出已被拉到 ≈0 |
| **不要用数字低通治"与 PWM 同步"的干扰** | `fs = f_sw = 10 kHz` ⇒ 开关基频及谐波采样后全部折到 DC，而数字滤波器对 DC 增益恒为 1。**原理上无效**，只有采样前的模拟 RC 能治 |
| 加数字滤波前先降 kp 验证 | 环路已在振荡时，加滤波的相位滞后会让它更糟 |

## 十、彻底解决的方向（未执行）

### 方案 A：传感器输出加模拟 RC（推荐）

```
每个传感器输出 → ADC 引脚：串联 1 kΩ + 对地 100 nF
fc = 1/(2π×1k×100n) ≈ 1.6 kHz
10 kHz 处衰减 −16 dB
```

**关键优势：它在环路之外**——不像数字滤波那样消耗相位裕度。
切断纹波后，**电流环 kp 可调回 0.3~0.5**，串级分离度也随之恢复。

### 方案 B：提高 PWM 频率

见第八节施工清单。移出可听频段 + 纹波减半，但受 ISR 时间预算约束。

### 方案 C：改善传感器供电去耦

用户实测采样时 MCU VCC 在 3.0~3.5V 抖动，且传感器 VCC 与 MCU VCC **未做电源隔离**。
⚠️ 但注意：ADC 参考就是 VDDA（`Adc.h:68`），传感器输出也以自身 VCC 为基准，**同源时比例式测量会把这个抖动大部分抵消**——这一因果链**尚未验证**，详见 `mode40噪声问题_参数交接表.md` 第六节缺口①。
