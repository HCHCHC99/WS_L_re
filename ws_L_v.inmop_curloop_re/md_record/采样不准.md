# 三相电流采样不准问题记录

日期：2026-09-17

## 现象

三相电流采样抖动较大。

电机不转时，电流波形的峰峰值也可能达到约：

```text
1A
```

该问题会影响：

```text
电流环调试；
速度环外环调试；
过流保护阈值判断；
VOFA 波形观察。
```

## 当前采样配置

电流采样引脚：

```text
PA5 / ADC2_CH1 / IU
PA6 / ADC2_CH2 / IV
PA7 / ADC2_CH3 / IW
```

当前默认采样模式：

```c
I_SAMPLE_MODE = I_SAMPLE_ADC2_PWM_VALLEY
```

该模式下 ADC2 由 Timer4_3 三角波谷值触发，每个 PWM 周期采样一次三相电流。

`VALLEY` 模式当前没有显式调用：

```c
ADC_SetSampleTime(...)
```

因此 ADC2 采样时间保持默认的 11 个 ADCLK 周期。

## 可能原因

### 1. ADC 采样保持时间偏短

如果电流传感器输出端阻抗较高，或者前端没有充分去耦，采样保持电容充电时间不足，会导致 ADC 读数抖动。

可尝试增加采样时间：

```c
ADC_SetSampleTime(CM_ADC2, ADC_CH1, 64);
ADC_SetSampleTime(CM_ADC2, ADC_CH2, 64);
ADC_SetSampleTime(CM_ADC2, ADC_CH3, 64);
```

单位是 ADCLK 周期。三个通道顺序采样后仍远小于 100µs PWM 周期。

### 2. 开关噪声耦合到电流传感器输出

PWM 开关瞬间会产生较高的 dv/dt 和 di/dt，可能通过以下途径耦合到电流采样：

```text
地弹；
电源噪声；
PCB 走线；
传感器输出线；
ADC 采样保持电容。
```

即使使用电流传感器而不是低侧差分采样，也不能完全避免开关噪声。

### 3. 电流传感器输出带宽过高或过低

如果传感器带宽很高，会直接看到开关纹波；如果传感器或前端 RC 滤波不足，则会看到毛刺。

如果传感器带宽过低，又会引入相位延迟，影响电流环稳定性。

### 4. 参考地或电源不稳

电流传感器通常输出以某个参考电压为中心的模拟信号。如果传感器地、MCU AGND、功率地之间有压降或噪声，ADC 读数会抖动。

检查：

```text
传感器供电；
ADC 参考电压；
AGND 与功率地连接方式；
传感器输出线是否靠近 PWM 功率线。
```

### 5. VOFA 显示混叠

VOFA 主循环发送帧的频率低于实际电流采样频率。当前电流采样可能为 10kHz 或 20kHz，但 VOFA 显示帧率远低于此，因此看到的波形可能已经混叠。

不要只根据 VOFA 波形判断真实 ADC 采样质量。

## 排查方案

### 方案 1：增加 ADC 采样时间

在 `VALLEY` 模式下加入：

```c
ADC_SetSampleTime(CM_ADC2, ADC_CH1, 64);
ADC_SetSampleTime(CM_ADC2, ADC_CH2, 64);
ADC_SetSampleTime(CM_ADC2, ADC_CH3, 64);
```

然后观察三相电流峰峰值是否下降。

### 方案 2：区分真实电流纹波和测量噪声

电机不转时，关闭 PWM 输出，观察：

```c
g_i_iu_ma
g_i_iv_ma
g_i_iw_ma
g_i_uvw_ma
```

如果 PWM 关闭后噪声明显减小，说明主要是开关耦合。

如果 PWM 关闭后仍然有约 1A 峰峰值，重点检查电流传感器供电、参考地和模拟前端。

### 方案 3：用示波器直接看传感器输出

用示波器探头分别测 PA5/PA6/PA7 对应的电流传感器输出。

示波器触发 PWM 开关沿，观察：

```text
是否存在开关尖峰；
尖峰幅度是否达到 1A 当量；
尖峰是否在 ADC 采样点附近；
三相是否同时出现。
```

### 方案 4：检查三相和值

理想情况下：

```text
iu + iv + iw ≈ 0
```

当前程序里有：

```c
g_i_uvw_ma
g_i_uvw_raw
```

如果三相和值抖动很大，说明采样不同步、相序映射错误、传感器噪声或共地问题较明显。

### 方案 5：记录一段真实 ADC 采样数据

可以在 RAM 中开一个缓冲区，在 ADC 完成中断里连续保存：

```c
g_i_iu_raw
g_i_iv_raw
g_i_iw_raw
```

保存足够长度后一次性通过 RTT 或 VOFA 上传。这样可以避免 VOFA 主循环发送造成的欠采样。

### 方案 6：增加过采样或平均值

在确认采样点可靠后，可以对电流反馈做适当的平均或低通。

但注意：

```text
不要把大延迟滤波器直接放进电流环控制路径；
否则会降低电流环相位裕度。
```

可以先只用于观测，确认噪声来源后再决定是否用于控制。

## 当前建议

优先按以下顺序排查：

```text
1. 增加ADC采样时间；
2. 用示波器看传感器输出；
3. 检查PWM关闭/开启时噪声差异；
4. 检查g_i_uvw_ma是否异常；
5. 记录真实ADC采样缓冲数据；
6. 最后再决定是否加入DMA或硬件滤波。
```
