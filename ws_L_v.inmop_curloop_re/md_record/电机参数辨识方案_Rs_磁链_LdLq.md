# 电机参数辨识方案：Rs / 磁链 ψf / Ld / Lq

对象：3505-KV650 云台电机（外转子，pp=10），HC32F460 + 6288T-MNS，12 V 母线，4096 CPR 编码器
约束：**没有外力拖动装置**（不能反拖匀速）；手头**只有双通道示波器、只能测电压**；BEMF 分压通道存在但未吃透（列为备用）

---

## 一、先明确"能不能测"

ψf、L、R 三者的可观测性完全不同，这决定了工序：

| 目标量 | 观测途径 | 能否静止测 | 需要运动 |
|---|---|---|---|
| **R** | 直流注入的 `v/i` 稳态关系 | ✅ 完全可以 | 否 |
| **Ld / Lq** | 电压阶跃/方波下的 `di/dt` | ✅ 可以（转子夹紧） | 否 |
| **ψf** | ① 反电动势 `e = ωe·ψf` ② 力矩 `T = 1.5·p·ψf·iq` | ②可以（吊重法） | ①要转、②不用转 |

**结论**：三个量全都能在"只有电机 + 自己的驱动器 + 编码器"的条件下测出来，不需要外力拖动。
关键认知：**测反电动势不需要恒定转速**——只要每个采样点同时拿到"当时的反电动势"和"当时的电角速度"，
用斜率法/回归即可。恒定转速是"模拟电压表 + 转速表"时代的要求；你有编码器，瞬时 ωe 随时可读。

---

## 二、安全与接线（先看这段，再看方法）

⚠ **示波器地夹子的铁律**：地夹子与示波器外壳/大地相通。
**绝对不要把地夹子夹到任何相线、桥臂中点、或电机端子上**——一旦逆变器工作，等于把那一点通过大地短路，
轻则跳保护，重则炸桥。母线负极（或控制地）是唯一可以夹的公共参考点。

⚠ 台式电源若输出浮地，把示波器地夹到母线负极是常规做法；若电源负极已接大地，则形成接地环路，
会出现噪声甚至烧探头，此时应改用隔离/差分探头。

**推荐接线方式（双通道差分测法）**：
```
CH1 探针 → 待测点 A          CH1 地夹 → 公共参考（母线负极）
CH2 探针 → 待测点 B          CH2 地夹 → 同一个公共参考
数学运算 MATH = CH1 − CH2  →  就是 A−B 的电压
```
两个地夹必须在**同一点**，靠 MATH 相减得到差分电压，这是没有差分探头时唯一安全的测法。

**串一个取样电阻测电流**（你只有电压档，这是把电流变成电压的标准做法）：
在**一相**串入 `0.1 Ω / 1% / ≥2 W` 的无感电阻（电机相线 → 电阻 → 桥臂输出），
示波器用上面那套差分接法测它两端 → **1 A = 0.1 V**，与相电压同屏显示（CH1 相电压、CH2 取样电压），
`di/dt` 直接看得见。

**BEMF 分压通道（备用方案）能吃透的话很值**：它的作用就是把"相线对母线负极"的电压按比例降到你 ADC/示波器能接的范围。
用它之前必须先**标定分压比**：
1. 锁死转子，用固定 duty 输出一个可算出的电压（例如 mode 26 给 `freq=0`、`volt=0.4 V` → SVPWM 出的相电压已知）；
2. 读该通道 ADC 或示波器读数 → 比例系数 k = V实际 / V读数；
3. 注意它测的是**相电压（对中性点还是对母线负极）还是线电压**——这决定后面要不要乘 √3。
（这个 √3 的坑你们已经踩过一次：motor_config.h 里 FLUX_VS 与 KV 的差异就是它。）

## 三、工序总表（按依赖顺序，不要跳步）

| 步 | 测什么 | 用什么 | 预计耗时 | 产出的数 |
|---|---|---|---|---|
| 0 | **L 的快速初判** | 现有 mode 29/41 阶跃计时器 | 20 min | L 的数量级（42 µH 还是 260 µH） |
| 1 | **Rs（环路 R_eff）** | 多电平直流注入 + 线性拟合 | 40 min | R_eff + 死区电压 |
| 1b | **Rs（真定子电阻）** | 示波器直接测相-相端子 | 30 min | R_phase（与 R_eff 对比得出桥臂压降） |
| 2 | **Ld** | d 轴方波/阶跃（转子夹紧） | 40 min | Ld |
| 3 | **Lq** | q 轴方波/阶跃（转子夹紧） | 40 min | Lq |
| 4 | **ψf** | 自驱动多转速稳态电压方程（斜率法） | 40 min | ψf + 复核 R |
| 5 | **ψf（独立验证）** | 静止吊重法（Kt） | 1 h（要夹具） | ψf（与 4 独立） |
| 6 | 备用 | 惰行 + BEMF 通道/示波器测线电压 | 1 h | ψf（第三种途径） |

**测量纪律**：同一批数据尽量在**同一温度**下测完（铜阻温度系数 +0.39 %/K，绕组温升 30 K 就是 12 % 误差）。
每步开始前记一次环境温度与电机外壳温度，注入电流不要长时间保持（Rs 用短脉冲，占空比 < 10 %）。

## 四、第 0 步：用现有固件 20 分钟判出 L 的数量级（零成本，先做）

你的 mode 29/41 里有一个**内建的阶跃计时器**（`g_drun29_iq_step_t90_us`），它在 ISR 里计时，
分辨率 50 µs，**不受 VOFA 90 fps 帧率限制**——这正是测快速上升沿的正确工具。

**原理**：电流环闭环（PI 零极点对消）后，被控对象近似一阶，闭环时间常数 `τcl = L / kp`。
所以：

```
把 g_drun29_step_frac_pct 设成 63.2  →  测到的时间就是 τcl 本身
L = kp × τcl              （kp = g_drun29_pid_iq_cfg.kp）
```

**步骤**：
1. mode 24 校准 → mode 0 捏死转子（BEMF=0，纯 R+L 对象）→ mode 29；
2. Watch 设 `g_drun29_dlt_targ_deg = 90`（纯 q 轴）、`g_drun29_i_ref_ma = 500`、
   `g_drun29_i_ramp_ma_s = 0`（直通阶跃）、`g_drun29_step_frac_pct = 63.2`、`kp = 0.5`、`ki` 保持 300；
3. 进模式，读 `g_drun29_iq_step_t90_us`（这名字沿用旧名，实际阈值就是你设的 63.2 %）；
4. 算 `L = 0.5 × t63.2`。

**预期结果（一眼分辨）**：

| 若 L = | τcl = L/kp | 测到的时间 |
|---|---|---|
| 42.3 µH | 84.6 µs | **≈ 85 µs** |
| 260 µH | 520 µs | **≈ 520 µs** |

**判据与坑**：
- 测到 85 µs 左右 → L 接近厂家值；测到 500 µs 左右 → L 偏大 6 倍，`FOC28_PI_KI` 注释那套说法成立；
- 计时从"|参考| ≥ 100 mA 那一拍"起算，所以必须让参考是**真实阶跃**（`i_ramp_ma_s = 0`）；
- 只对**闭环一阶**成立：要求反馈用的是原始 iq（是的）、PI 零点接近 R/L、无额外滤波（iq 显示滤波不进 PI，没问题）；
- 一定要在 **i_valid = 1（PI）** 下测；纯 P 时稳态到不了 63.2 %（P-only 稳态落差公式）。
- **立刻的交叉验证**：同屏看 PWM 电流纹波。固定 50/50/50 零矢量时
  `Δi_pp = Vbus / (4·L·fsw)`：L=42.3 µH → **3.55 A**，L=260 µH → **0.58 A**。
  如果你之前测到的纹波是 ±1.2 A（2.4 A p-p），反推 **L ≈ 62 µH** —— 与"厂家值偏小"一致。

## 五、第 1 步：Rs（环路电阻 R_eff + 死区电压）

**要测两个东西，一次做完**：斜率 = R_eff，截距 = 死区等效电压。

**为什么必须多电平**：死区造成的平均电压误差 ≈ `Vbus·Td/Ts = 12 × 500 ns / 50 µs = 0.12 V`。
2 A 时 `R·i` 只有 0.2~0.3 V，单点测量里死区占了 40 % —— 无法接受。

**接线与工况**：
- 转子**夹紧**（防转动 → 无 BEMF、无电感动态）；
- 磁场固定在 **d 轴**（d 轴注入不产生力矩，转子最稳）。两种做法：
  - 用 mode 26 开环 VF，把 `g_olf_freq_targ_hz = 0`：它自带的 BETA/ALPHA 校准会把转子吸到 0°
    （即 d 轴），之后频率 0 就一直保持这个方向 → **等于一台直流注入源**，`g_olf_volt_v` 就是注入电压；
  - 或者用一个专门的辨识 mode（见第十节）。
- 逐档加电压：`0.10 / 0.20 / 0.30 / 0.40 / 0.60 V`（对应约 0.7 / 1.4 / 2 / 2.7 / 4 A）。

**每档记录**（用 Watch 或 VOFA 读稳态值，等 200 ms 让电流稳定）：
| 注入 vd (V) | 稳态 id (A) | 备注 |
|---|---|---|
| 0.10 | | |
| 0.20 | | |
| … | | |

**数据处理**（最小二乘拟合 `v = R·i + Vdead`）：
```
R_eff  = 斜率
Vdead  = 截距     （≈ 0.12 V，符号随电流方向翻转 → 正反各做一组，取 |Vdead|）
R² > 0.99 才算合格
```

**判据**：
- 预期 `R_eff ≈ 0.15 Ω`（含两颗 MOS 的 Rdson + 采样电阻 + 走线），比厂家 0.1 Ω 大 50 %；
- 若拟合出的截距远大于 0.15 V → 检查电流零偏是否漂了（先跑 mode 24 的零偏窗）；
- 同一档位重复 3 次，离散度应 < 3 %。

**1b 用示波器测"真定子电阻"（可选但推荐）**：
固件读到的电压是**指令值**，不含死区与管压降。要分离出"电机本体"的 Rs，必须直接测电机端子：
- 接线：CH1 探针 → 电机 U 端子，CH2 探针 → 电机 V 端子，**两个地夹都夹在母线负极**，看 `MATH = CH1−CH2`
  → 这就是**线电压** U−V；此时电流流经 U、V 两相 → `V_line = i × 2Rs` → **Rs = V_line / (2·i)**；
- 因为是直流，探头带宽、耦合（用 DC 耦合）都无所谓，读数很稳；
- 与 1a 相减：`R_eff − Rs_scope ≈ 桥臂与采样的等效电阻`，这个差值本身就是有价值的数据（解释了为什么环路要用 0.15 而不是 0.1）。

## 六、第 2 / 3 步：Ld 与 Lq

**统一前提**：转子**夹紧**（用台钳/手捏/或用无齿夹具），这样 q 轴注入也不会有转动 → 无 BEMF、无运动污染。
即使不夹紧，只要**脉冲短于 2 ms**，转子也来不及动（Kt=0.0126 N·m/A，0.5 A 的力矩在 2 ms 内产生的 ωe 只有几 rad/s，
反电动势 < 10 mV，可忽略）——但仍建议夹紧，省得齿槽和摩擦来捣乱。

**d/q 轴怎么放**：用 mode 24 锁好的编码器零点做基准。
- **d 轴**：让磁场角 = 转子电角（`δ = 0`，即纯 d 轴）；
- **q 轴**：让磁场角 = 转子电角 + 90°（`δ = 90°`）。
mode 29 的 `g_drun29_dlt_targ_deg` 就是干这个的：**设 0 → 纯 d，设 90 → 纯 q**。

### 2a 闭环阶跃法（复用第 0 步的工具，最省事）

第 0 步已经证明可以用 `L = kp × t63.2`。现在把它分别用在两个轴上：

| 轴 | 设置 | 读 | 得到 |
|---|---|---|---|
| Ld | `dlt_targ_deg = 0`，i_ref=500mA，frac=63.2 | `g_drun29_id_step_t90_us` | `Ld = kp × t` |
| Lq | `dlt_targ_deg = 90` | `g_drun29_iq_step_t90_us` | `Lq = kp × t` |

（mode 29 对 id 和 iq **各有一个独立的阶跃计时器**，所以一次进模式就能同时拿到两个轴。）
**建议再用第二个 kp 复核**：把 kp 从 0.5 改到 0.25，若 t 翻倍 → 说明测的确实是 L/kp 而不是别的延迟；若 t 不变 → 那些时间被固定延迟（采样、死区、滤波）主导，数据不可用。

### 2b 方波小信号纹波法（精度最高，推荐做交叉验证）

在 d 轴（或 q 轴）上加**方波电压**，用电流纹波幅值反推 L：

```
L = v × (T/2) / Δi_pp          （忽略 R，因为 T/2 ≪ τe 时 R 项可略；
                                更准的形式：Δi_pp 由 di/dt = (v − R·i)/L 积分得到）
```

**参数选择（针对你的硬件）**：
- 20 kHz ISR ⇒ 每 50 µs 可以改变一次电压 → 方波半周期取 `T/2 = 50 µs`（即 10 kHz 方波）时，
  你的电流采样**每半个周期采到一次峰值/谷值**，正好是纹波峰峰值；
- 电压幅值取 0.5~1.0 V：L=42 µH 时 Δi = 0.5×50µs/42µH = **0.6 A**（电流安全、信噪比好）；
  L=260 µH 时 Δi = 0.1 A（偏小，把电压提到 1.0~2.0 V 即可）；
- 建议扫三个幅值（0.5 / 1.0 / 2.0 V），若 L 随幅值下降 → 说明在**饱和区**，要取小信号值。

**数据处理**：`L = v·(T/2)/Δi_pp`，三个幅值取一致的那个值；离散度 < 5 % 算合格。

### 2c 交叉检查：用现有的 PWM 纹波反推（零成本）

零矢量（50/50/50）下，`Δi_pp = Vbus/(4·L·fsw)`：

| L | 预期 Δi_pp @12 V, 20 kHz |
|---|---|
| 42.3 µH | 3.55 A |
| 62 µH | 2.4 A |
| 260 µH | 0.58 A |

你之前测到电流反馈在 ±1.2 A 抖动（2.4 A p-p）→ 反推 **L ≈ 62 µH**。
⚠ 这只是估算：电流传感器的带宽、采样时刻（谷点采样只采到"某一时刻"而不是峰谷）、
以及 Biquad/滑动平均都会削掉纹波幅值 → **实测纹波偏小 ⇒ 反推 L 偏大**，所以它只能定数量级、不能定值。

### Ld / Lq 的判据

- 3505 是**表贴式（SPM）**概率大 → 预期 `Ld ≈ Lq`（差 < 10 %）；若 `Lq/Ld > 1.2`，说明是内嵌式（IPM），
  那么 MTPA 才有意义（你现在 mode 27/41 扫 δ 的实验正好与此呼应）；
- 三个方法（2a / 2b / 2c）结果应落在同一数量级；若 2a 与 2b 差 2 倍以上，优先信 2b（直接测 di/dt），
  并检查 2a 的固定延迟占比（见 2a 的 kp 复核法）。

## 七、第 4 步：ψf（稳态电压方程斜率法，自己驱动即可）

**原理**（稳态、id≈0、diq/dt≈0）：
```
vq = R·iq + ωe·ψf          ωe = rpm/60 × 2π × p   (p = 10)
```
**做法**（用 mode 40，它没有前馈，最干净）：
1. mode 24 校准 → mode 40；
2. 目标转速依次取 **1000 / 2000 / 3000 rpm**，每档等到稳态（`g_speed40_speed_filt_rpm` 平直、ch13 = ch14）；
3. 每档记录三个数：`g_speed40_vq`（ch9）、`g_speed40_iq_ma`（ch5）、`g_speed40_speed_filt_rpm`（ch17）。

**数据处理**：
```
ψf = Δvq / Δωe        ← 同一 iq 的两点差分，R·iq 项直接抵消
或：拟合 vq = R·iq + ψf·ωe（两点以上最小二乘）→ 斜率 = ψf，截距 = R·iq
```

**为什么斜率法可靠**：
- 死区电压误差是**常量偏置**（≈0.12 V，只与电流符号有关）→ 只污染截距、**不污染斜率**；
- R 的误差同样只影响截距；
- 唯一的系统误差是"vq 是指令值而非实际值"（含过调制/死区），但在 1000~3000 rpm 区间 vq 只有 0.9~2.6 V，
  离 UMAX 6.2 V 很远，不会饱和。

**预期数值（用来判断数据对不对）**：

| 转速 | ωe | 若 ψf = 0.84 mWb，e = ωe·ψf | 加上 R·iq（iq≈0.2 A）后的 vq |
|---|---|---|---|
| 1000 rpm | 1047 rad/s | 0.88 V | ≈ 0.90 V |
| 2000 rpm | 2094 rad/s | 1.76 V | ≈ 1.78 V |
| 3000 rpm | 3142 rad/s | 2.64 V | ≈ 2.66 V |

斜率应为 **0.84 mV/(rad/s)**，即每 1000 rpm 上升 0.88 V。若实测斜率是 0.73 mV/(rad/s)（对应 ψf≈0.00073），
就与 mode 45 那组 SMO 数据（ch10 中值 1.15 V ÷ ch13 1.32 V = 0.87）吻合了 —— 两者互为印证。

**坑**：
- 进模式前确认 `FOC_CUR_SIGN = -1` 等符号约定，否则斜率会反号（用两点法先看符号是否为正）；
- 必须在**稳态**取值：速度环 5 ms 周期 + 滤波 α=0.25，阶跃后至少等 1 s；
- 别用 ch15（显示强滤波，τ≈100 ms）判稳态，用 ch17；
- 若用 mode 45 做，**必须先 `g_smo45_auto_ramp = 0`**，否则它会自己写目标；mode 45 的 ch14 是 PI 反馈转速。

## 八、第 5 步：ψf 独立验证（静止吊重法，完全不用转）

第二个物理途径：力矩。`T = 1.5·p·ψf·iq`，所以
```
Kt = m·g·r / i        →        ψf = m·g·r / (1.5·p·i)
```
用厂家值算：`Kt = 1.5 × 10 × 0.00084 = 0.0126 N·m/A`（与 motor_config 里 0.2 N·m ÷ 17 A = 0.01176 自洽）。

**夹具**：轴上装一个小杠杆（3~5 cm，3D 打印件或一根硬塑料/木条 + 螺钉夹紧），末端挂砝码。

**电流量级**：`r = 5 cm`、`m = 20 g` → `T = 0.0098 N·m` → 只需 **0.78 A**（你的电流分辨力 ≈0.16 A，够）。

**步骤**：
1. mode 24 校准 → mode 29（或 31/40 任一能给恒定 iq 的模式），`δ = 90°`（纯 q）；
2. 慢慢加 `i_ref`，直到杠杆**刚好离开限位/刚好抬起**，记下电流 i₁；
3. **反向**做一次（q 轴电流反向，杠杆向下压），记 i₂；
4. 取平均消掉摩擦与齿槽：`i = (i₁ + i₂)/2`；
5. 换 3~4 个不同电角度重复，再平均（齿槽转矩随角度周期变化）；
6. `ψf = m·g·r / (1.5 × p × i)`。

**判据与坑**：
- 与第 4 步的电压法结果相差应 < 10 %；若差很多，先怀疑杠杆长度/砝码质量标定；
- 摩擦与齿槽是主要误差源 → **必须双向平均**；
- 悬挂点要尽量轻，杠杆自重产生的力矩要算进去（或先测"空杠杆抬起所需电流"作为零点）。

## 九、第 6 步（备用）：惰行 + BEMF 通道 / 示波器测线电压

如果你想把 BEMF 分压通道吃透，这是它的最佳用途：

1. **先标定分压比**（见第二节）：固定 duty 输出已知电压 → 读数 → k = V实际/V读数；
2. mode 40 或 45 驱动到 2000~3000 rpm，然后**关掉 PWM**（切 `comm_mode = 0`，或让桥臂全下管导通），
   让转子自由惰行；
3. 惰行期间用 BEMF 通道记录相电压、用编码器记录转速（VOFA 同步采）；
4. **不需要匀速**：对每一对采样点算 `ψ = e_amplitude / ωe`，取中位数；或做 `e 对 ωe` 的过原点回归，斜率即 ψf；
5. 注意读的是**相电压还是线电压**：读线电压时要 `ψf = e_ll / (√3·ωe)`——**这里最容易差 √3 倍**。

**用示波器做同样的事**（它是电压表，正好合适）：
- CH1−CH2 差分接电机 U、V 端子（地夹都在母线负极），DC 耦合，
- 惰行时屏上是**正弦线电压**，用游标读峰峰值 → `e_ll_pk`，
- 同时看编码器/VOFA 记下同一时刻的转速 → `ψf = e_ll_pk / (√3·ωe)`；
- 惰行降速不影响：**多读几个时刻的点，斜率法**。
- ⚠ 惰行时桥臂虽已关断，但**地夹仍不可夹相线**（电机惰行会发电，相线仍有电位）。

## 十、需要固件支持的部分（可选，但会让整套流程从"几小时"变"几分钟"）

上面 0/1/2/3 步都能用现有模式凑出来，但比较手工。建议加一个**辨识 mode（如 mode 50）**，
把"注入—采样—拟合"自动化，结果直接上 VOFA/Watch：

| 阶段 | 做什么 | 输出 |
|---|---|---|
| P1 零偏 | 零矢量，采 4000 点平均三相零偏 | 三相零偏 mA |
| P2 Rs | d 轴注入 5 档电压，每档稳态均值 | `Rs_eff`、`Vdead`（固件内做最小二乘） |
| P3 对齐 | BETA/ALPHA 吸到 d 轴（复用 mode 20 逻辑） | 基准角 |
| P4 Ld | d 轴方波（半周期 = 1 个 ISR 周期）| `Ld_uH` = v·T/2/Δi_pp |
| P5 Lq | 磁场转 90°，重复 P4 | `Lq_uH` |
| P6 报告 | 把 4 个数放到 Watch/VOFA，`state/evt` 报进度 | 5 个观测量 |

关键实现点：P2/P4 必须**绕过电流 PI**（直接给固定电压矢量），否则 PI 会把电压调回来、掩盖被测对象。
参考现成代码：mode 20 的固定矢量输出（`Foc_Svpwm` + `TMR4_PWM_SetDuty3Phase`）可以直接搬。

## 十二、坑清单（踩过的和容易踩的）

1. **地夹子夹相线** → 短路事故，见第二节。
2. **死区电压当成了 R·i** → 单点测 Rs 必错，必须多电平拟合。
3. **√3 混用**：相峰值 / 线-线 RMS 是两套定义（你们的 FLUX_VS vs KV 已经踩过）。
4. **在非稳态取值** → 速度环 + 滤波要等够时间；判稳态只看 `speed_filt_rpm`。
5. **温度漂移**：铜阻 +0.39 %/K，注入电流要短脉冲、整批数据同一温度。
6. **饱和**：Ld/Lq 随电流下降（铁芯饱和）→ 三个幅值扫一遍，取小信号值，并注明测试电流。
7. **夹紧不等于不动**：齿槽会让转子在力矩下微动几 counts → q 轴测量用短脉冲（<2 ms）。
8. **转子位置错了轴**：d/q 分不清 → 用 mode 24 的零点 + `δ=0/90` 明确指定；测完互相验证（Ld≈Lq 才是 SPM）。
9. **示波器带宽**：测 PWM 纹波要点是探头与接地弹簧（不要用长地线夹），否则看到的是振铃不是纹波。
10. **忘记 `g_smo45_auto_ramp`**：用 mode 45 测 ψf 时它会自动改目标，必须置 0。
