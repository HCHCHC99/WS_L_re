## 一、这个模式在做什么

### 1.1 目标与定位

mode 51 在**转子静止**的前提下，向**静止 α 轴**注入一组直流电压，测量每一档的稳态电流，用最小二乘拟合

```
|v| = R_eff · |i| + V_dead                                      (1)
```

一次拿到两个量：

| 输出 | 含义 | 谁在用 |
|---|---|---|
| **R_eff**（斜率） | 环路真正看到的电阻：电机相阻 + 桥臂导通电阻 + 采样电阻 + 走线 | 电流环 PI 整定；mode 52 的 `g_ldlq52_r_used_ohm`；mode 53 的 `vq − R·iq` 修正 |
| **V_dead**（截距） | 死区 + 管压降的等效电压 | mode 52 的 `FOC52_VDEAD_PRIOR_V` 与反推校验 |

**定位**：这个模式的目的是**验证参数辨识的思路与方法本身**，不是生产标定。因此它

- 只输出观测量（Watch / VOFA），**不写 Flash、不改任何配置宏**；
- 同时给出 `R_eff / FOC_MOTOR_RS_OHM`（手册值）的比值，便于直接与商家参数对比；
- 把数据质量指标（R²、位移、零偏窗）与结果**同等看待** —— 这是"验证方法论"的关键。

**前置要求：无。** 不需要 mode 24 校准、不需要编码器零点 —— 因为注入方向固定在静止 α 轴，完全不涉及 d/q 的定义（式 8）。

### 1.2 符号与单位

| 符号 | 含义 | 单位 | 本机取值 |
|---|---|---|---|
| `V` / `v_k` | 注入电压（指令值，α 轴） | V | 0.26 ~ 0.45 |
| `i_k` | 第 k 档稳态电流矢量幅值 | A | 1.0 ~ 2.65 |
| `R_eff` | 拟合斜率 = 环路等效电阻 | Ω | 实测 0.098 |
| `V_dead` | 拟合截距 = 死区等效电压 | V | 实测 0.160 |
| `T_s` | PWM / ISR / 采样周期 | µs | 50（20 kHz） |
| `T_d` | 死区时间 | ns | 配置 500 |
| `V_bus` | 母线电压 | V | 12.0 |
| `ρ` | 电机本体的每相电阻 | Ω | 手册 0.1（**定义待确认，见 §6.4**） |
| `r` | 桥臂串在每相上的等效电阻（Rdson + 采样 + 走线） | Ω | 未知，靠示波器法（§8）分离 |
| `R²` | 拟合优度 | - | 合格线 0.99 |

### 1.3 为什么一次单点测量不够

由式 (1)，单点测量得到的"表观电阻"是

```
R_app = v / i = R_eff + V_dead / i                               (2)
```

死区等效电压约 160 mV（§3.3），而 2 A 时 `R_eff·i` 只有 0.196 V —— **偏置占了四成**：

```
R_app(2 A) = 0.098 + 0.160/2 = 0.178 Ω      →  高估 82%          (3)
```

电流越小越离谱：1 A 时 `R_app = 0.258 Ω`（高估 163 %）。所以**必须多电平拟合**：用多个电流点把"斜率"和"截距"分开 —— 截距就是死区电压，斜率才是电阻。这是本模式存在的全部理由。

## 二、时序与注入几何

### 2.1 频率关系

PWM、ADC、电流环、本模式的 ISR 全部由 `MOTOR_PWM_FREQ_HZ` 决定（1:1）：

```
f_pwm = f_isr = 20 kHz      →      T_s = 1/f_isr = 50 µs         (4)
```

每档的采样点数由毫秒换算（`RS51_MS_TO_TICKS`）：

```
N_settle = settle_ms · f_isr / 1000 = 2000   （100 ms 稳定）      (5)
N_avg    = avg_ms    · f_isr / 1000 = 2000   （100 ms 平均）      (6)

零偏窗：N_zero = FOC51_ZERO_SAMPLES = 4000   （200 ms）
全程预算 = 200 + 300 + 200 + n·200 = 1900 ms（n = 6 档）          (7)
```

`N_avg = 2000` 是**偶数**这件事不是巧合而是必要条件：见式 (29)。

### 2.2 注入方向与三相电流分布

输出电压矢量固定在静止 α 轴（`Rs51_OutputAlpha`）：

```
v_α = V ,  v_β = 0                                               (8)
```

对星形绕组、幅值不变 Clarke 变换，`i_β = 0` 意味着 V、W 两相电流相等而 U 相相反：

```
i_U = i ,  i_V = i_W = -i/2            （"+ − −" 符号组合）       (9)

电流矢量幅值（模式实际统计的量）：
|i| = sqrt(i_α² + i_β²) = |i_U|                                  (10)
```

式 (9) 的三个符号固定不变，是后面"死区电压落在截距而不是斜率"（§3.4）的根据。

### 2.3 零偏窗：自己扣零偏，不依赖 mode 24

状态机第 1 步就是 200 ms 的**零矢量**（`Rs51_OutputAlpha(0)`），累加 4000 个原始三相电流取平均：

```
zero_x = (1/N_zero) · Σ i_x[n]        x = U, V, W                 (11)
```

之后所有电流都先扣掉它再做 Clarke（`Rs51_Clarke`）：

```
i_x = ( i16Ix_mA - zero_x ) · 0.001 · g_foc_cur_sign             (12)
```

为什么要重测零偏而不是复用 mode 24：本模式**允许单独上电跑**，且电流采样零偏会随温度漂 —— 一个 20 mA 的零偏落在 1 A 档上就是 2% 的电流误差，会让拟合出现曲率（R² 掉到 0.99 以下，这正是判据里"R² 差先查零偏"的由来）。

### 2.4 预置注入：先让机械状态稳下来

零偏窗之后不是直接探测，而是先给 300 ms 固定 0.3 V（`FOC51_STEP_PRECOND`）。三个作用：

1. **把转子吸到 α 轴**：α 轴电流对转子的力矩是 `T ∝ -sin θ_r`（θ_r = 转子 d 轴与 α 轴的夹角），θ_r = 0 处是稳定平衡点；吸住之后 sin θ_r → 0，力矩自己消失 —— 这就是实测位移从 10 counts 掉到 2 counts 的原因；
2. **让夹具/联轴器的蠕动先释放掉**（开机头 0.5 s 的读数是会骗人的：实测探测档读数偏低 15%、旧版扫描第 0 档电流偏高 2.5 倍，都指向机械还在动）；
3. 顺便把线圈的电流建立过程走完（τ = L/R ≈ 430 µs，对 300 ms 是瞬态）。

预置期间同样有电流护栏（式 39），超限就 0.9 倍递减。

## 三、物理模型

### 3.1 静止 + 稳态 ⇒ 只剩电阻

α 轴电压方程（幅值不变 Clarke 约定）：

```
v_α = R_eff · i_α + L · di_α/dt + e_α                            (13)
```

本模式的工况把后两项都消掉：

```
转子静止  →  e_α = 0（无 BEMF）
稳定后    →  di_α/dt = 0（电流是直流）
```

于是式 (13) 退化成式 (1) 的纯电阻形式。**这就是"静止直流注入"的全部物理内容**：不需要知道 L、不需要知道 ψf、不需要编码器零点，只要保证"转子不动 + 电流稳定"。

### 3.2 R_eff 到底包含什么（**这里容易算错**）

把桥臂的导通电阻 `R_dson`、采样电阻 `R_shunt`、走线 `R_wire` 都串在"每相"上，记每相总电阻为 `ρ + r`（r = 该相桥臂的附加电阻），星点 N 浮空，则

```
V_U - V_N = (ρ + r)·i_U        （三相各一条）
V_N = (V_U + V_V + V_W)/3      （星点由三式相加得到）
```

代入幅值不变 Clarke 变换（`i_α = (2/3)(i_U - i_V/2 - i_W/2)`）化简可得：

```
i_α = v_α / (ρ + r)        ⇒      R_eff = ρ + r                 (14)
```

即**一个桥臂**的附加电阻，不是两个：

```
R_eff = R_phase + R_dson + R_shunt + R_wire                      (15)
```

**为什么不是"2×"**：在 α 轴上电流"从一个桥臂进、另两个桥臂各出一半"，但从式 (14) 的推导看，α 轴等效电路里每相只串一个附加电阻 —— "两个桥臂串联"是**线电压**（端子对端子）视角下的结论，不是 Clarke 视角下的。历史文档 `md_record/电流环PI理论计算.md` 里的 `R_eff = R_电机 + 2×(Rdson+采样+走线) ≈ 0.15 Ω` 就是按线电压视角推的，它正是被本模式实测（0.098 Ω）否掉的那条推断。**以本模式实测为准。**

与示波器线电压法的对应关系（模式外手工做，§8）：

```
线电压法：V_line = i·2ρ  ⇒  Rs_scope = V_line/(2i) = ρ
两者相减：R_eff - Rs_scope = r      （桥臂 + 采样 + 走线的等效值）  (16)
```

### 3.3 死区等效电压 V_dead：为什么是 160 mV 而不是 120 mV

**单相**的死区电压：死区期间上下管都关断，相电流经二极管续流，把桥臂输出钳到相反的电源轨，于是每相的平均输出电压被顶偏

```
E = (T_d / T_s) · V_bus = (500 ns / 50 µs) × 12 V = 120 mV       (17)
```

方向与相电流**相反**（电流为正时输出被压低）。

**三相合成才是模式看到的量**。三个误差电压按 Clarke 变换合成：

```
e_U = -E·sign(i_U) = -E ,  e_V = e_W = +E      （三相符号 + − −，式 9）

e_α = (2/3)·[ e_U - e_V/2 - e_W/2 ] = (2/3)·[ -E - E/2 - E/2 ] = -(4/3)·E     (18)
e_β = 0                                        （e_V = e_W，β 分量归零）
```

所以 α 轴上看到的是单相值的 **4/3 倍**，且**方向与电流相反**（压低有效电压）：

```
V_dead(理论) = (4/3) · (T_d/T_s) · V_bus = (4/3) × 120 mV = 160.0 mV          (19)
```

**实测 160.2 mV，与式 (19) 差 0.2%**；反推死区时间

```
T_d(反推) = V_dead · T_s / ( (4/3)·V_bus ) = 0.1602 × 50 µs / 16 = 500.6 ns   (20)
```

配置值 500 ns —— **吻合**。式 (19)(20) 一次同时验证了三件事：模型（4/3 合成）、死区配置、以及"指令电压 ≠ 实际电压"这个前提。

> 二阶项：续流二极管压降 `V_f` 理论上会把 `E` 修正成 `(T_d/T_s)(V_bus ∓ V_f)`，量级 ±7 mV；实测只偏 +0.2 mV，说明在本工况下这个修正被两次边沿插入的符号部分抵消（或 DDL 配置的 500 ns 已经是每周期总量）。**结论：一阶式 (19) 够用，本文不再细究。**
>
> 另一个方向的自洽检查：若按"每边各插一次 T_d"算，理论值是 320 mV，实测 160 mV 会差一倍 —— 实测站在"每周期合计 T_d"这一侧。

### 3.4 为什么 V_dead 落在截距、R_dson 落在斜率

- **死区项**幅值固定、符号只跟电流方向有关。本模式三相电流符号恒为 `+ − −`（式 9），所以它是一个**不随电流大小变化的常量偏置** ⇒ 进截距；
- **桥臂导通电阻/采样电阻**与电流成正比 ⇒ 进斜率。

这就是"多电平拟合能同时拿到 R_eff 和 V_dead"的根本原因，也是单点测量必然测歪的原因（式 2）。

**副产品**：`g_rs51_vdead_v` 拿到的是一个**独立于电流大小的死区电压测量**，它被 mode 52 直接拿去当先验（`FOC52_VDEAD_PRIOR_V = 0.16`），也是 mode 52 打印的 `vdead=148~166 mV` 的参照值。

## 四、档位规划与最小二乘（本模式的核心算法）

### 4.1 探测档：先把 R 的量级估出来

探测档用固定 0.3 V（`FOC51_PROBE_V`）测一次稳态电流，然后 —— **关键修正在这里** —— 必须扣掉死区先验再算电阻：

```
R_guess = ( V_probe - V_dead_prior ) / i_probe                   (21)
R_guess 夹在 [0.02, 2.0] Ω
```

**不扣会怎样（2026-09-27 实测事故）**：

```
旧写法：R_guess = 0.3 V / 1.345 A = 0.223 Ω      （真值 0.098 Ω，高估 2.3 倍）
后果  ：档位电压按 0.223 规划 ⇒ 电流冲到 5.4 A（i_max 只有 3 A）  (22)
```

电流大了以后还叠加热与饱和，数据全废。**这条是"指令电压 ≠ 实际电压"最贵的一次教训。**

### 4.2 档位按"目标电流"规划，而不是按电压等分

第 k 档（k = 0…n−1）的目标电流在 `i_min ~ i_max` 之间线性分布：

```
i_target,k = i_min + ( i_max - i_min ) · k / (n - 1)             (23)
```

再由 `R_guess` 反算需要的电压（带上运行时缩放与硬上限）：

```
v_k = ( i_target,k · R_guess + V_dead_prior ) · v_scale
v_k 夹在 [ 0, g_rs51_v_hard_max_v = 1.5 V ]                      (24)
```

**为什么不能在电压上等分**（旧版做法）：把 0.3 V 六等分，最低档 0.166 V 里有 145 mV 是死区，**87% 的电压被吃掉**，只剩 21 mV 有效驱动：

```
有效驱动 = v_k - V_dead
旧版最低档：(0.166 - 0.145) / 0.166 = 13% 有效    →  只剩 21 mV   (25)
```

这一档既没有信息量、又对截距有**最大杠杆**（它是最左端那个点），于是它把斜率和截距一起拖歪。实测后果：R² 卡在 0.9896、残差逐点相同（±32 mV）。改成按目标电流规划后：

```
同一台电机：R² 0.9896 → 0.9983 ，残差 ±32 mV → ±4 mV             (26)
```

### 4.3 每档：稳定 100 ms + 平均 100 ms

```
稳定期：settle_ms = 100 ms（等电流建立 + 机械稳态）
平均期：avg_ms    = 100 ms → N_avg = 2000 点取算术平均
```

第 k 档的电流取平均窗内的算术平均：

```
i_k = (1/N_avg) · Σ i[n]                                         (27)
```

**为什么平均窗长度取偶数是必须的**：采样序列里混着约 ±0.5 A 的、周期≈2 个采样点的快速交替干扰（近奈奎斯特，来源见 `mode52参数LdLq辨识讲解.md` §八）。它在相邻两点上符号相反，**偶数个点求和即精确抵消**：

```
N_avg 为偶数  ⇒  Σ(-1)^n = 0  ⇒  交替干扰的贡献 = 0              (28)
```

于是每档电流的重复性主要取决于真实漂移（零偏漂、温度），而不是这个干扰。

### 4.4 最小二乘与 R²

对 n 个点 `(i_k, v_k)` 做一次线性最小二乘（`Rs51_Fit`）：

```
r = ( n·Σ(i_k v_k) - Σi_k · Σv_k ) / ( n·Σi_k² - (Σi_k)² )       (29)
V_dead = ( Σv_k - r · Σi_k ) / n                                 (30)
```

拟合优度用标准定义（残差平方和 / 总平方和）：

```
SS_tot = Σv_k² - (Σv_k)² / n
SS_res = Σ( v_k - (r·i_k + V_dead) )²
R²     = 1 - SS_res / SS_tot                                     (31)
```

判据：**R² ≥ 0.99 才算合格**（`FOC51_EVT_FIT_OK`），否则置 `FIT_POOR` 并在 RTT 追一行 warn。分母 `n·Σi² − (Σi)²` 太小（各档电流几乎一样）时直接放弃拟合 —— 这时"直线"没有定义。

### 4.5 斜率的标准误差：为什么三轮离散只有 1.8%

线性最小二乘斜率的标准误差（残差标准差 `σ_v`、电流点的展布 `i_k`）：

```
σ_R = σ_v / sqrt( Σ(i_k - ī)² )                                  (32)
```

代入第三轮实测：`σ_v ≈ 4 mV`（残差 ±4 mV）、n = 6、电流均匀分布 1.0~2.65 A ⇒ `σ_i = 1.65/√12 = 0.48 A`

```
Σ(i_k - ī)² = n·σ_i² = 6 × 0.23 = 1.38
σ_R = 4 mV / 1.17 = 3.4 mΩ        （相对 98 mΩ = 3.5%）           (33)
```

也就是说**单轮的标准误差约 ±3.5%**。实测三轮 `R_eff = 99.7 / 98.4 / 97.9 mΩ`，极差只有 1.8%（比 1σ 还小）—— 说明逐轮之间没有量级更大的系统项在游走，三次数值的差异就是随机残差量级。

**提高精度的两条路**（都由式 32 直接读出）：① 把电流展布拉大（`i_max` 3 A → 5 A，`σ_i` 约翻倍、`σ_R` 降 30%）；② 降低残差 `σ_v`（更长平均窗、更稳的零偏、夹紧转子）。

## 五、护栏与安全

### 5.1 参数钳位（`Foc_RsId_Start`，Watch 改坏也不至于打太高）

| 参数 | 允许范围 | 越界处理 |
|---|---|---|
| `g_rs51_i_max_a` | 0.5 ~ 5.0 A（`FOC51_I_HARD_MAX_A`） | 夹到边界并回写 Watch |
| `g_rs51_points` | 3 ~ 10（`FOC51_MAX_POINTS`） | 夹到边界 |
| `g_rs51_settle_ms` | ≥ 20 ms | 夹到 20 |
| `g_rs51_i_min_a` | 0.1 ~ i_max | 夹到 `i_max × 0.5` |
| `g_rs51_vdead_prior_v` | 0 ~ 0.6 V | 夹到边界 |

另外 `i_max` 必须远小于过流门限 `FOC_OC_LIMIT_A = 9 A`，默认 3 A 留了 3 倍余量。

### 5.2 电流护栏：必须比"滤波值"，不能比瞬时值

护栏用的是 EMA（一阶低通）滤波后的电流：

```
g ← g + α·( i_now - g ) ,     α = FOC51_GUARD_EMA = 0.05
时间常数 τ ≈ T_s / α = 50 µs / 0.05 = 1 ms                        (34)
```

触发条件与动作（只在**稳定期**、且已过 20 ms 时判）：

```
若 g > i_max · FOC51_OC_SCALE (= 3.0 × 1.15 = 3.45 A)：
    v_scale ← v_scale · 3.45 / g      （下限 0.05）
    scale_hits++ ，清零滤波器，本档重测                            (35)
```

**为什么不能比瞬时值**：瞬时电流里含开关纹波与采样噪声，实测在均值 3.09 A 时纹波尖峰就能顶到 3.45 A ⇒ 误触发 **7 次**、把后两档电压砍掉 8~13%，拟合点被削平、R² 变差。改成 EMA 后：

```
EMA 在奈奎斯特频率（本工况 20 kHz 纹波正好接近它）的增益：
|H| = α / (2 - α) = 0.05 / 1.95 = 0.026      →  衰减约 39 倍       (36)
```

而真正的持续过流仍在几个 ms 内判出（τ ≈ 1 ms）。

> 注：速览卡里写的是"纹波衰减百倍"，按式 (36) 严格算应是 **39 倍（−32 dB）**。这不影响结论（瞬时值误触发已消除），此处按实测口径修正。

### 5.3 预置档降档与过流保护

```
预置档：若 g > i_max × 1.15  ⇒  v_probe ← 0.9 × v_probe（下限 0.05 V）   (37)
过流  ：Foc_Core_OverCurrent(pData) 为真 ⇒ state = FAULT_OC(7)，
        evt = OC，Foc_Core_FaultStop(1) 立即关 PWM                        (38)
```

探测档还有一条"没电流"的退路：`i_probe < 0.15 A` 时先把电压翻倍再探一次，仍测不到就置 `EVT_NO_CURRENT(4)` 并收尾（提示查接线/相序）。

状态机全表：

| 值 | 状态 | 动作 |
|---|---|---|
| 0 | IDLE | PWM 关 |
| 1 | ZERO | 零矢量 4000 点（200 ms）求三相零偏 |
| 2 | PRECOND | 预置注入 0.3 V / 300 ms（稳转子与夹具） |
| 3 | PROBE | 同电压测 `i_probe` → `R_guess`（式 21） |
| 4 | SCAN | n 档：稳定 100 ms + 平均 100 ms（式 23~27） |
| 5 | FIT | 最小二乘（式 29~31）+ 读编码器位移 |
| 6 | DONE | 关 PWM；`running` **保持 1**，VOFA 停在本模式布局便于回看 |
| 7 | FAULT_OC | 过流停机（`running` 也保持 1，便于看故障电流） |

**时间预算**（式 7）：约 1.9 s；峰值 3 A 时铜损约 1 W 量级、全程约 2 J，绕组几乎不热（这也是为什么不需要考虑温升）。

## 六、结果与判据

### 6.1 三个主结果

```
R_eff  = r        （式 29 的斜率）        → g_rs51_meas_ohm
V_dead = V_dead   （式 30 的截距）        → g_rs51_vdead_v
ratio  = R_eff / FOC_MOTOR_RS_OHM         → g_rs51_ratio          (39)
```

`ratio` 是"验证思路"这个定位的直接产物：它把实测值与手册值放在同一个数轴上。

### 6.2 合格判据

| 判据 | 门限 | 不合格时先查什么 |
|---|---|---|
| R² | ≥ 0.99 | 电流零偏漂了（重跑零偏窗）／低档位有效驱动不足（式 25） |
| 位移 `moved_cnts` | \|·\| ≤ 8 counts | 转子被推动 → 夹紧后重测（式 40） |
| V_dead | 0.05 ~ 0.20 V | 明显偏大 → 电流零偏；为负 → 检查 `FOC_CUR_SIGN` 一致性 |
| ratio | ≈ 0.9 ~ 1.1 | 见 §6.4 的定义问题 |
| V_dead 与理论 160 mV | 差 < 10% | 死区配置、母线电压实测值 |

### 6.3 位移判据的定量含义

8 counts 是编码器计数（`ENCODER_CPR = 4096`），换成机械角与电角度：

```
机械角 = 8 / 4096 圈 = 0.70°
电角度 = 0.70° × pp(10) = 7.0°                                    (40)
```

对整个测量窗（约 1.2 s）而言，8 counts 对应的平均转速是 `0.098 rpm`，其反电势只有

```
ω_e = 0.098 rpm × 2π/60 × 10 = 0.102 rad/s
e = ψf · ω_e = 0.00084 Vs × 0.102 = 86 µV      （相对 260 mV 可忽略）  (41)
```

⇒ **位移判据拦的不是"BEMF 污染"（太小），而是"机械还在动"这件事本身**：一旦转子在动，说明它正在被力矩推着走，此时电流里会混进运动引起的反电势与角度变化，档与档之间不再是同一个工况。所以夹紧转子（或依赖 §2.4 的预置吸附）是数据质量的关键。

### 6.4 与手册值的对比：一个必须澄清的定义问题

实测 98 mΩ、手册 100 mΩ，`ratio = 0.98` —— 数值上"验证了手册"，但**分解关系必须澄清**：由式 (15)，

```
R_eff = ρ + r   ⇒   若 ρ(每相) = 0.1 Ω ，则 r = -0.002 Ω  ← 不可能（负值）  (42)
```

因为桥臂上一定有正的导通电阻与采样电阻，所以二者之一成立：

- **(a) 手册的 0.1 Ω 是"线电阻 / 端子电阻"**（即 `2ρ = 0.1` ⇒ 每相 ρ = 0.05），此时 `r = 0.098 − 0.05 = 48 mΩ` —— 对一级低压驱动（6288T 的 Rdson + 采样电阻 + 走线）是**合理量级**；
- **(b) 手册的 0.1 Ω 是每相值**，那么实测 98 mΩ 就**低于**纯相阻，只能解释为电流采样的增益偏高约 20%（或手册值本身不准）。

**用示波器差分测线电压（§8 第一步）即可一次判定**：`Rs_scope = V_line/(2i)`，与 `R_eff − Rs_scope = r` 一起看就知道是 (a) 还是 (b)。在澄清之前，文档里说"商家 0.1 Ω 得到验证"应理解为"**环路看到的电阻**是 98 mΩ、与手册值同量级"，而不是"每相相阻 = 0.1 Ω 且桥臂电阻为零"。

> 对电流环整定没有影响：PI 要用的就是**环路看到的** R_eff = 0.098 Ω（这也是 mode 52 里 `g_ldlq52_r_used_ohm = 0.098` 的取值来源）。

### 6.5 与 mode 40 电流环的自洽性

mode 40 的电流环 PI（`FOC40_PI_KP = 0.1`、`FOC40_PI_KI = 300`）隐含一个"零点抵消"关系：

```
ki / kp = R_eff / L        ⇒      L_implied = R_eff · kp / ki
                                       = 0.098 × 0.1 / 300 = 32.7 µH   (43)
```

与 mode 52 实测的 `Ld ≈ 45 µH / Lq ≈ 65 µH` 同量级（差 1.4~2 倍），说明**零点没有严格抵消**（更好的 ki 约在 232 附近，见总方案文档）。这条不是 mode 51 的结论，但它是 R_eff 的第一个下游用途，写在这里以便对照。

## 七、实测数据

### 7.1 三轮（同一台电机、同一套硬件，2026-09-27）

| 轮次 | 点数范围 | 算法状态 | R_eff | V_dead | R² | 位移 | 备注 |
|---|---|---|---|---|---|---|---|
| 1 | 0.5 ~ 5.4 A | 电压等分 + 探测未扣先验 | 99.7 mΩ | 144.5 mV | 0.9896 | 10 | 电流冲到 5.4 A，超 `i_max` |
| 2 | 0.5 ~ 5.4 A | 同上（复现） | 98.4 mΩ | 144.7 mV | 0.9896 | 8 | 残差逐点相同 |
| **3** | **1.0 ~ 2.65 A** | **现行**（扣先验 + 按电流规划 + EMA 护栏 + 预置） | **97.9 mΩ** | **160.2 mV** | **0.9983** | **2** | 本文的口径 |

**结论**：`R_eff = 0.098 Ω`；`V_dead = 160.2 mV` 与式 (19) 的理论值 160.0 mV 吻合到 **0.2%**，反推死区 500.6 ns（配置 500 ns）。
⇒ 历史推断"环路电阻 0.15 Ω"作废，连带"L = 260 µH"的推理也失去支撑（已由 mode 52 用实测 `Lq > Ld`、`vs_vendor ≈ 1.05` 独立否定）。

### 7.2 第 1、2 轮 V_dead 偏低 15 mV 的原因（可以用杠杆解释）

第 1、2 轮的截距是 144.5 / 144.7 mV，比第 3 轮低 15.7 mV；同时斜率是 99.7 / 98.4 mΩ，比第 3 轮高 1.8 / 0.5 mΩ。两组数一起动，正是**病态最低档**（式 25：只剩 21 mV 有效驱动、却对截距有最大杠杆）的典型特征：那个点被噪声/偏置一推，拟合线就绕中心旋转 —— 斜率与截距**反向**变化。第 3 轮把最低档从"电压等分的最低档"改成按电流规划的 1.0 A（有效驱动 ≈98 mV，是死区的 0.6 倍）之后，杠杆被拉平，两个量同时收敛。

**这条经验可以推广**：拟合的"最左端那个点"，其有效驱动（`v − V_dead`）**不应小于死区电压本身**，否则该点的信噪比塌陷、而杠杆最大。现行规划（`i_min = 1.0 A` ⇒ 有效驱动 98 mV）刚好在边界上，若要把 R² 再往上推，可以把 `g_rs51_i_min_a` 提到 1.3~1.5 A：

```
有效驱动 / 死区 = (i·R_eff) / V_dead ：i = 1.0 A → 0.61 倍
                                        i = 1.5 A → 0.92 倍      (44)
```

代价是电流展布变小（式 32 的 Σ(i−ī)² 变小、σ_R 变大），**两点需要权衡**：更稳的低端点 vs 更大的展布。

### 7.3 三处实测教训（都已修，写在这里备查）

1. **探测档忘了扣死区先验**（式 22）：`0.3 V/1.345 A = 0.223 Ω` 而真值约 0.1 Ω ⇒ 档位电压算高一倍 ⇒ 电流冲到 5.4 A。修法：式 (21)。
2. **档位原先按电压等分**（式 25）：最低档 87% 的电压被死区吃掉，是"既无信息又对截距有最大杠杆"的病态点（两轮 R² 都卡在 0.9896、残差逐点相同）。改成按目标电流规划后 R² 升到 0.9983、残差 ±32 mV → ±4 mV。
3. **电流护栏比瞬时值会被开关纹波误触发**（式 36）：实测误触发 7 次、把后两档电压砍掉 8~13%。改用 EMA 滤波值（τ ≈ 1 ms）后纹波衰减 39 倍，持续过流仍能判出。

## 八、已知局限与未解决问题

| # | 问题 | 影响 | 状态／建议 |
|---|---|---|---|
| 1 | **手册 0.1 Ω 的定义未确认**（§6.4） | `ratio = 0.98` 的解释有两种，影响"桥臂电阻 = 48 mΩ 还是电流增益偏高 20%"的判断 | 用示波器线电压法（式 16）一次判定 |
| 2 | **模式内测不到"电机本体 Rs"** | 固件只有指令电压，含死区与管压降 | 模式外手工：CH1/CH2 差分测线电压 ⇒ `Rs = V_line/(2i)`；与 R_eff 相减即得桥臂等效电阻 |
| 3 | **位移是净位移，不是路径** | 转子"动过去又动回来"不会被发现 | 建议照 mode 52 的做法加路径累加（`s_path += |Δcnt|`） |
| 4 | **电流护栏只覆盖稳定期**（§5.2） | 平均窗内若电流缓慢上爬，只有 9 A 硬件过流兜底 | 可把护栏判据也加到平均期（代价：需要处理"砍档后已采样的点"） |
| 5 | **只有单向电流**（三相符号恒 `+ − −`） | 无法用"反向注入取平均"消掉零点误差与二极管不对称 | 方案里已有"正反各做一组，取 \|V_dead\| 平均"（尚未实现） |
| 6 | **HS/LS 导通电阻不对称** | 式 (15) 把 r 当常数；实际 U 相走 HS、V/W 相走 LS | 二阶项，量级 < 10 mΩ；要分离就得做反向注入 |
| 7 | **温度漂移** | 铜电阻温度系数 +0.393 %/K，10 K 温升就是 4% | 本模式只有 1.9 s、约 2 J，自身发热可忽略；但"刚跑完 mode 52/53 再测"会偏高，建议冷态首测 |
| 8 | **未做重复性统计** | 三轮是三次不同算法，不是同一算法的三次重复 | 现行版本连跑 3~5 次，用式 (33) 对照实测离散度 |
