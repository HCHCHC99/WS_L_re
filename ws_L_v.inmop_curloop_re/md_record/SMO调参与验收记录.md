## 〇、一句话结论

**SMO 好坏的关键不是"波形好不好看"，而是四个直流判据是否恒定：幅值比、q/d 投影、总误差、相位差滤波值。**
匀速下这四条是平直的线、数值落在理论预期内、随转速按规律缩放 —— SMO 就是对的。
波形因串口带宽必然混叠，肉眼看到的"正弦形状"永远不可信，也**不需要**可信。

## 一、SMO 结构与最终参数（定版）

结构（每轴，静止 αβ 系，10kHz ISR 半隐式离散）：

```
预测：  î_p = î_k + (Ts/L)·(v − R·î_k)          ← v = 前后两拍指令平均
滑模：  z = k·sat((î − i)/φ)                     ← 层内对 î_{k+1} 解析求解（无条件稳定）
输出：  e_hat = EMA(z)                           ← 滑模面上 z ≈ e
```

### 参数定版表

| 参数 | 值 | 定版理由 |
|---|---|---|
| `g_smo_model_r_ohm` | 0.1 Ω | 手册相电阻（环路真实 R_eff≈0.15 含管子/采样电阻，模型用 0.1 即可，跌落公式里体现） |
| `g_smo_model_l_h` | 42.3 µH | 手册相电感 |
| `g_smo_model_psi_wb` | 0.00084 Wb | 与 KV/VBUS/最高转速三方交叉验证过，可信 |
| `g_smo_k_v` | **4.6 V（固定）** | = 2×e_peak@2600rpm（用户选定固定 k 方案）；硬条件 k>e_peak → 可用验证窗 ≈1300~3400rpm |
| `g_smo_obs_gain` | **1.45** | k/φ；半隐式格式无稳定上限，越大跌落越小；实测 1.45 下跌落与理论吻合 |
| `g_smo_lpf_alpha` | **0.39** | fc≈1kHz @10kHz ISR；2600rpm 时 LPF 滞后 23°（已计入相位预算） |
| `g_smo_diag_theta_err_filt_alpha` | 0.1 | 相位差显示滤波，纯读数用 |

### 两个关键设计决定（为什么是这样）

1. **半隐式而非显式 Euler**：采样重构后 FOC_ISR_HZ=10kHz（Ts=100µs），显式格式要求
   k/φ < 2L/Ts−R ≈ 0.75，默认 1.45 会自激；半隐式（层内解析解）无上限。
2. **固定 k 而非速度调度**（用户选定）：k=4.6V 对应 2600rpm 整定点；低速档
   （<1300rpm）切换纹波淹没小信号属预期，不是缺陷。

## 二、三大判据 —— SMO 好坏到底看什么

### 判据 1：幅值 —— |e_hat| = ω·ψf × 0.91

理论幅值 `e_expect = |ω_e|·ψf`（ω 来自编码器测速）。实测应比理论低一个**已知跌落**：

```
跌落 = R_model/(k/φ) + LPF 损失 ≈ 6.9% + 1.5% → e_hat ≈ 0.91 × ωψf
```

**这个跌落是 SMO 模型的内生属性，不是误差**——实测跌落若 ≠ 理论值，反而说明
R_model 不准（跌落测量反过来是 R 辨识器）。

看：Watch `g_smo_diag_e_ratio` ≈ 0.91 ± 0.03；面板 ch10 vs ch13。
（1500rpm 实测中心为 0.98 而非 0.91——分子含谐波/纹波能量，机理与自动判定
窗口的关系见第六节。）

### 判据 2：相位 —— 恒定滞后 = 已知项之和，不漂

`theta_err = atan2(e_β,e_α) − 90°·sign(ω) − θ_编码器`，稳态均值：

```
δ = LPF 滞后 atan(ω_e/ω_c) + 观测极点滞后 atan(ω_e·L/(R+k/φ)) + 电压配对延迟(已修)
```

| 转速 | 预期 δ | 实测 |
|---|---|---|
| 1000rpm | −13° | — |
| 1500rpm | **−17°** | **−17.5°（ch15 均值）✓** |
| 2000rpm | −22° | — |
| 2600rpm | −28° | — |

相位差**抖动的均值**才是判据；抖动幅度本身是诊断量（转速不变时突变 = 噪声/参数恶化）。

### 判据 3：恒定性 —— 投影是平直线

e_hat 投影到编码器转子系（把"看波形"变成"看直流"，绕开串口混叠）：

```
e_on_q = −e_α·sinθ + e_β·cosθ  ≈ |e_hat|·cosδ   （恒定）
e_on_d =  e_α·cosθ + e_β·sinθ  ≈ −|e_hat|·sinδ  （恒定，负值 = 滞后体现）
总误差 |E_hat − E_theory| = √((e_on_q−ωψf)² + e_on_d²) ≈ ωψf·δ(rad)
```

匀速下**必须是与转速对应的常数**；出现电频率纹波 = 波形畸变（死区签名）。

## 五、故障案例存档（避免复发）

### 案例：面板全是乱跳的碎片（ch13=0.004、ch15=±140、ch10=±0.1）

**现象**：ch13 应为 1.32V 却读 0.004；ch15 在 ±100°以上乱跳；ch10 正负乱跳。

**原因**：**mode 45 没有启动成功**（该次上电后未先跑 mode 24，校准标志掉电即失），
`g_smo45_running=0` → 固件回落到 17 通道通用布局帧；而 VOFA 仍按 16 通道解析
→ **帧错位**，解出的浮点全是碎片。

**教训/规程**：
1. 每次上电必须先 `comm_mode=24`（等 "cal-only done"）再 `comm_mode=45`
2. mode 45 启动成功的标志 = RTT 出现 `[SMO45] start rot=... auto=1`
3. 启动后 VOFA 通道数应为 16（wave_mode=1 时为 8）；切换布局后重新确认通道数
4. 本机 CH343 会换 COM 号（COM11→COM16），VOFA 选口前先确认

### 案例：921600 波特率本机不可用

同固件公司电脑 921600 正常、本机"闪烁但无波形"。抓包分析：数据在 921600 下
内容损坏（无帧尾、字节率恒定 ~3KB/s 与接收波特率无关）→ 本机 USB/驱动链路
在高波特率下丢字节（CH343 FIFO/USB 轮询时序问题，逐机表现不同）。
**处置：回到 115200**（帧率 ~170-360Hz，配合投影直流判据完全够用）；
真要高速看波形用 J-Scope（SWD，不经串口）。

## 六、反电动势自动判定（2026-09-22 新增：g_smo_emf_ok）

> "四个直流判据恒定"的代码化。Foc_Smo_Diag 末尾每拍执行，mode 45 每次 Start
> 经 Foc_Smo_Reset 重新判定。定位是**粗筛实质故障**；精密验收（幅值 0.91 精确比、
> 相位均值 −17.5°、α/β 正交 90°）仍靠人看 ch10/ch13/ch15，一条没放。

### 判定规则

前提 + C1 + C2 三项**连续满足 1000ms**（TickTimer ms 时基计时）→ `g_smo_emf_ok=1`；
任一拍破窗立即清零重来（恒定性要求，非粘滞锁存）。

| 项 | 判据 | 窗口默认 | 抓什么故障 |
|---|---|---|---|
| 前提 | 机械转速 ≥ `rpm_min` | ≥1300rpm | 固定 k 信噪比下限；低于=未判定（bit0，不算失败） |
| C1 | 幅值比慢速均值 | [0.85, 1.08] | 模型 R 错 3 倍（ratio≈0.78）、磁链错 2 倍（≈0.49）、obs_gain 砍半 |
| C2 | 相位慢速均值 | [−45°, +5°] | 相位翻转（大正角）、滞后过大（模型/滤波严重不对，如 −60°） |

失败位掩码 `g_smo_jdg_fail`：bit0=0x01 转速未达（爬坡途中正常）、bit1=0x02 幅值越界、
bit2=0x04 相位越界，可叠加；**含 bit0 时其余位无意义**（低速下幅值/相位本来就不可信）。

### 两级滤波：判定取"均值"，不看点值

```
theta_err 原始 → EMA(0.1)  = theta_err_filt（一级，诊断显示用）
                     └→ EMA(0.02) = g_smo_jdg_phase_filt_deg（二级，判定用，C2）
e_ratio      → EMA(0.02) = g_smo_jdg_ratio_filt（判定用，C1）
```

原因：一级滤波后仍有 ±9.5° 马鞍纹波 + 主循环采样混叠拍频驻留，点值进窗口
会来回破窗；"判据恒定"本来就指**均值**恒定。

### 窗口修正记录（教训：不能随意放宽，也不能按错的理论卡死）

| 事件 | 现象 | 根因 | 处置 |
|---|---|---|---|
| FAIL 0x02↔0 横跳 | ratio_filt 0.96~1.0，压着上限 0.98 | 窗口中心 0.91 是纯基波理论预测；实测中心 0.98——分子 \|e_hat\|=sqrt(ea²+eb²) 把 6f 谐波+切换纹波能量计入，分母 ωψf 是纯基波（旁证：ch10 中值 1.15/1.19≈0.97） | 窗口改 [0.85, 1.08]（实测中心 ±10%） |
| FAIL 0x04↔0 横跳 | theta_err_filt 在 −0.x~−17 间摆动驻留 | 上限 −5 是把"理论 −17°"误当验收线；恒定滞后 PLL 会吃掉，不阻碍可用；且一级滤波值带纹波驻留 | C2 改用慢速均值进 [−45, +5]，只抓翻转/过大滞后 |

**放宽的边界（诚实声明）**：窗口放宽到 ±10~15% 后，中等程度误差抓不到
（R_model 偏 50%、滞后 −17→−10 漂移）；当前选择偏"不误报"，灵敏度靠人眼补。
Step 2 PLL 上线后，真正的强验收是 PLL 角度 vs 编码器角度的误差统计（功能性验证）。

### 负测试（证明判据没松死；跑完恢复参数应回到 OK）

| 操作 | 预期 |
|---|---|
| `g_smo_model_r_ohm` 0.1→0.4（跌落 27%） | FAIL 0x02 |
| `g_smo_lpf_alpha` 0.39→0.08（滞后≈−57°） | FAIL 0x04 |
| `g_smo_model_psi_wb` 0.00084→0.00168（理论幅值翻倍） | FAIL 0x02 |

⚠ 注意：**k 单独调歪不会触发 C1**——幅值跌落 = R/(k/φ)，而 k/φ 即 obs_gain
（φ=k/obs_gain），k 只影响信噪比。负测试要动 R_model / psi_wb / obs_gain / lpf_alpha。

### 看什么

- RTT 跳变事件（仅结果翻转时打一行）：
  `SMO EMF judge: OK (ratio=98% phase=-17deg hold=1000ms)` / `SMO EMF judge: FAIL mask=0x02 [ratio]`
- Watch：`g_smo_emf_ok`（结果）、`g_smo_jdg_fail`（原因）、
  `g_smo_jdg_ratio_filt`（≈0.98）、`g_smo_jdg_phase_filt_deg`（≈−17°）
- 到速后 **~1.5-2s** 才判 OK（慢速 EMA 收敛 ~0.5s + hold 1s），嫌慢把
  `g_smo_jdg_filt_alpha` 提到 0.05（纹波免疫度略降但窗口余量够）
