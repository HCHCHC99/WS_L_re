## 零、三个模式的分工与前置

| mode | 测什么 | 方法 | 前置 | 转子 |
|---|---|---|---|---|
| **51** | `R_eff`（环路电阻）+ `V_dead`（死区等效电压） | 静止坐标系直流注入，多电平线性拟合 | **无**（不需要校准） | 静止即可（**不要求夹紧**，但要不动） |
| **52** | `Ld`、`Lq` | d/q 轴方波小信号注入 + 纹波幅值 | **必须先跑 mode 24** | 可自由（方波净力矩为零），编码器监视微动 |
| **53** | `ψf` | 多转速稳态电压方程 `vq = R·iq + ωe·ψf` | **必须先跑 mode 24** | 必须能**自由转动**、空载 |

**共性设计**（沿用项目现有约定）：
- 每个 mode 一个 `g_<name>_running` 标志，供 `foc.c` 的 ISR 分发与 `main.c` 的 VOFA 分发使用；
- 每个 mode 一个自持 VOFA 填充函数 `Foc_<Name>_VofaFill(int32_t *cur)`，返回通道数（≤24，硬上限）；
- 统一状态码：`0 IDLE / 1 RUN / 2 DONE / 3 FAULT_OC / 4 FAULT_TIMEOUT`；
- 统一事件码：每位一个含义（见各节）；
- 每个 mode 一个头文件速览卡（用 `_cardgen` 生成，不手写）；
- 过流一律走 `Foc_Core_OverCurrent(pData)` → `Foc_Core_FaultStop(1)`；
- 单位约定：VOFA 传"毫单位"，`SendScaled` 内部 ×0.001（mA→A、mV→V、µH 传 mH×1000…见各节）。

## 一、mode 51：Rs / R_eff 辨识

### 原理
转子静止 ⇒ 无 BEMF、稳态无 di/dt ⇒ 电压矢量方程退化为纯电阻：

```
|v| = R_eff · |i| + V_dead
```

- **斜率 = R_eff**：环路真正看到的电阻（电机相阻 + 2×Rdson + 采样电阻 + 走线），**这是 PI 设计要用的那个值**；
- **截距 = V_dead**：死区+管压降的等效电压。
  ⚠ **本注入方式（矢量锁 α 轴 → 三相电流符号 `+ − −`）的正确理论值是**
  `V_dead = (4/3)·(Td/Ts)·Vbus = (4/3)×(500ns/50µs)×12V = 160 mV`
  （不是按单相算的 120 mV —— 三相误差矢量合成后 α 分量是单相的 4/3 倍）。
  **实测 160.2 mV，吻合到 0.2%**，反推死区 501 ns（配置 500 ns）。
  > 式中 `Vbus` 现取 PA4 实测值（见文首修订）：指令电压已按实测 Vbus 折算占空比，
  > 故拟合截距与这里的理论值落在同一（真实）电压域，**无需 ×Vbus/12 折算**。

单点测量测不准（160 mV 偏置 vs 2 A 时 0.2 V 信号），**必须多电平拟合**。

### 为什么不需要校准、也不需要夹紧
在**静止 α 轴**注入（`vα = V, vβ = 0`），不涉及 d/q 定义，因此不需要编码器零点。
α 轴注入的电流矢量落在 U 相与 V/W 相之间，会产生力矩（转子可能被推动）——
但转子一旦静止且**没有任何初始运动**，力矩只产生"要把转子转过去"的趋势；
用很小的档位起步 + 用编码器监视位移，若位移 > 8 counts 就标记数据可疑。
（若方便夹紧，夹紧后数据质量更好。）

### 状态机（= 已实现版本）

```
IDLE(0)     : PWM 关
ZERO(1)     : 零矢量采 4000 点（200 ms）求三相零偏，自己扣（不依赖 mode 24）
PRECOND(2)  : 预置注入 0.3 V / 300 ms —— 先让转子与夹具稳定（实测位移 10 -> 2 counts）
PROBE(3)    : 同电压测 i_probe → R_guess = (0.3 - Vdead先验)/i_probe   ← 必须扣死区先验
SCAN(4)     : 目标电流 i_min(1A)..i_max 线性 N 档，电压 = i·R_guess + Vdead先验
              逐档 100 ms 稳定 + 100 ms 平均；稳定期内有电流护栏（比 EMA 滤波值，
              超 i_max×1.15 就按比例降 v_scale 并重测本档）
FIT(5)      : 最小二乘 v = R·i + Vdead，算 R²
DONE(6)     : 关 PWM；VOFA 停在本模式布局便于回看
FAULT_OC(7) : 过流停机
```

**时间预算**：200 + 300 + 200 + 6×200 = **约 1.9 s**；峰值 3 A → 铜损约 1.9 J，绕组几乎不热。

### 三轮实测结果（2026-09-27）

| 轮次 | 点数范围 | R_eff | V_dead | R² | 位移 | 备注 |
|---|---|---|---|---|---|---|
| 1 | 0.5~5.4 A | 99.7 mΩ | 144.5 mV | 0.9896 | 10 | 探测未扣先验 → 电流冲到 5.4 A |
| 2 | 0.5~5.4 A | 98.4 mΩ | 144.7 mV | 0.9896 | 8 | 同上（复现） |
| **3** | **1.0~2.65 A** | **97.9 mΩ** | **160.2 mV** | **0.9983** | **2** | 现行算法（扣先验 + 按电流规划 + 护栏 + 预置） |

**结论**：`R_eff = 0.098 Ω`（商家 0.1 Ω 得到验证，ratio 0.98）；`V_dead` 与理论 160 mV 吻合到 0.2%。
⇒ **"环路电阻 0.15 Ω"的旧反推作废**，连带"L = 260 µH"的推理也失去支撑（详见 mode 52）。

### 判据
- `R² > 0.99`；
- 预期 `R_eff ≈ 0.15 Ω`（手册 0.1 Ω + 桥臂压降）；
- `V_dead` 应在 0.05~0.20 V；若 >0.3 V → 先查电流零偏（跑 mode 24 的零偏窗）；
- `moved_cnts ≤ 8`；
- 若 `V_dead` 为负或 R² 很差 → 检查电流符号一致性（`FOC_CUR_SIGN = -1`）。

### 模式外的手工补充（可选，见配套文档 §5.1b）
要分离出"电机本体 Rs"，需用示波器差分测电机端子线电压 `U−V` → `Rs = V_line/(2i)`；
与 `R_eff` 相减即得桥臂+采样电阻。**模式内测不到这个**（固件只有指令电压）。

### 整理后的原理与公式（2026-09-27 定稿）
原理、全部公式（44 条编号）、数据质量分析、三轮实测的定量解释与未解决问题，
全部整理在 **`md_record/mode51参数Rs辨识讲解.md`**。其中三条值得先记在这里：

1. **R_eff 的组成是"一个桥臂"，不是两个**：按幅值不变 Clarke 约定推导 α 轴等效电路，
   `R_eff = R_phase + Rdson + R_shunt + R_wire`。历史文档里
   `R_eff ≈ 0.1 + 2×(Rdson+采样+走线) ≈ 0.15 Ω` 是按**线电压**视角推的，已被实测 0.098 Ω 否掉。
2. **V_dead = (4/3)·(Td/Ts)·Vbus = 160.0 mV** 的来源：单相死区电压 120 mV，
   三相按 Clarke 合成后的 α 分量是它的 4/3 倍（β 分量归零）。实测 160.2 mV，差 0.2%，
   反推死区 500.6 ns（配置 500 ns）。
   （式中 `Vbus` 现为 PA4 实测值；按 12.0 V 名义值即得 160.0 mV。见文首修订。）
3. **一个待澄清的定义问题**：若手册 0.1 Ω 是"每相"，则 `r = R_eff − ρ = −2 mΩ`（不可能）；
   若手册 0.1 Ω 是"线电阻"（每相 0.05），则桥臂+采样 `r = 48 mΩ`（合理）。用示波器线电压法
   一次判定。⇒ "商家 0.1 Ω 得到验证"应理解为"环路看到的电阻 98 mΩ 与手册值同量级"。

## 二、mode 52：Ld / Lq 辨识

### 原理（直流偏置方波 + 单极性纹波）
把电压矢量锁在 d 轴（`θ = θ_rotor`）或 q 轴（`θ = θ_rotor + 90°`，θ_rotor 来自编码器 + mode 24 零点），
命令**偏置 + 方波**：

```
v(t) = V_bias + sgn(t)·Vsq            V_bias = R·I_bias + V_dead先验
```

每**两个 ISR 周期**翻转一次 `sgn`（电压平台 100 µs = 5 kHz 方波），每个平台内采到 2 点
（平台内 25 µs / 75 µs 处），两点之差就是

```
|di| = Vsq · (1/fs) / L        ->        L = Vsq · (1/fs) / |di|      fs = FOC_ISR_HZ = 20 kHz
```

偏置的作用是让被测轴电流**始终同号**（要求 `|I_bias| > |di|`，即偏置电流大于纹波半幅）。

> **⚠ 为什么必须单极性（本模式最关键的结论，靠仿真定下来的）**
> 若用无偏置的 ±Vsq，电流每周期两次过零，死区等效电压（始终顶住电流方向）在
> **采样窗内变号**，采样差里就混进与死区有关的几何误差。用 10 ns 步长的波形仿真
> （`_cardgen/sim_mode52.mjs`、`sim_mode52_est.mjs`）量化，取 R = 0.098 Ω、V_dead = 0.16 V：
>
> | 方案 | L = 42.3 µH | L = 260 µH | 备注 |
> |---|---|---|---|
> | 无偏置 ±Vsq（0.42 V） | 38.7 µH（**−8.5 %**） | 243.9 µH（−6.2 %） | 随幅值非单调：−12 % ~ −13.5 %，无法用简单修正项补 |
> | 无偏置 + 硬扣 V_dead | 24.1 µH（−43 %） | 228.9 µH（−12 %） | "减去 V_dead"反而更糟 —— 说明误差不是简单压降 |
> | **单极性（+0.7 A 偏置）** | **42.6 µH（+0.6 %）** | **260.0 µH（0.0 %）** | L = 20…260 µH、Vsq = 0.3…2.6 V 全范围残差 < 1 % |
>
> 单极性之所以干净：`V_bias` 里的 `R·I_bias + V_dead` 恰好把平台内的 `R·i` 与死区压降
> 一起抵消掉，剩下 `|di| = Vsq·(1/fs)/L`，与 R、V_dead、I_bias 的具体数值都无关
> （偏置给不准只影响电流落点，不影响 L）。

> **⚠ 半周期为什么必须取 2 个采样周期（第二个坑）**
> 本板 ADC 在三角波**谷点**触发采样，而占空比影子寄存器在**峰点**装载
> （`TMR4_OC_BUF_COND_PEAK`），两者相差 25 µs。若半周期取 1 拍（平台只有 50 µs），
> 采样点恰好落在每个平台的**正中间** —— 也就是电流三角波的中点，采样差退化成约 0，
> 会误报"没有纹波"。

- d 轴注入不产生转矩（id 不产生转矩，且 iq = 0）；
- q 轴注入期间有**与偏置电流成正比的恒定力矩**（≈ kt·0.7 A ≈ 0.009 N·m）⇒ **建议夹紧转子**；
  偏置每 16 个周期翻一次号，让净冲量抵消，未夹紧时也不至于被推着连续转（用 `moved_cnts` 判断）。

### 为什么不用"阶跃法"
阶跃法要求转子完全不动（否则 BEMF 污染），要么夹紧、要么短脉冲；
方波法**可以重复多个周期取平均**，且偏置方案对死区/R 免疫，信噪比与系统误差都更好。

### 自适应幅值
1. 先用 Vsq = 0.5 V 打 10 个周期，测平台内 `|di|` 均值 → `L_guess = 0.5·(1/fs)/|di|`；
2. 要纹波峰峰值 = `di_target`（默认 1.0 A，即半幅 0.5 A），按 `Vsq ∝ |di|` 重定：
   `Vsq = 0.5 · (di_target/2) / |di|`，夹在 [0.3, 3.0] V；
3. 偏置同样自适应：`I_bias ≥ 1.3 × (di_target/2) + 0.05 A`（默认 0.7 A），
   偏置电压 `V_bias = R·I_bias + 0.16 V`（夹在 1.5 V 内）；
4. 正式测量：打 32 个周期（= 2 个偏置子窗，每子窗 16 周期），跳过每子窗前 8 个平台。

L=42.3 µH 时：Vsq ≈ 0.42 V、纹波峰峰值 ≈ 1 A（峰值电流 ±0.5 A）、偏置 0.7 A；
L=260 µH 时：Vsq ≈ 2.6 V、同样 1 A 纹波（偏置要求与 L 无关）；
硬上限 3 V：3 V 加在 42.3 µH 上、100 µs 平台内会摆 7 A，所以 `v_max` 不能放宽。

### 附加输出：由偏置电流反推死区电压
稳态下 v_axis 的平均值既等于 `V_bias − V_dead`，又等于 `R·I_bias`，于是

```
V_dead = V_bias − R × |I_bias|      （|I_bias| 用实测值，R 填 mode 51 的 0.098）
```

可与 mode 51 拟合出的截距（实测 160 mV）互相印证；两者接近说明 R 与死区模型都对上了。
本式的误差主要取决于 R 的准确度（mode 51 单点法误差约 1 %）。

### 采样配对相位：自选，不靠猜
`|di| = Vsq·(1/fs)/L` 成立的前提是"同一平台内的两次采样"。平台上两次采样的差必然与当前平台
极性**同号**（电流顺着平台电压上升/下降），所以实现里同时统计两套配对：

| 配对 | 含义 | 一致性（Δ 与平台极性同号的占比） |
|---|---|---|
| 0 = 组内 | 每 2 拍分组内的第 1、2 点 | 正确时 ~100 % |
| 1 = 跨组 | 上一组第 2 点、本组第 1 点 | 相位错开时反而 ~100 % |

取一致性高的那套（`g_ldlq52_pair_sel` / `g_ldlq52_cons_pct`）。这样就不必事先知道
ADC 触发与占空比装载之间的相位差（本板两者都在 PWM 峰点，但 ISR 延迟未知）。
若两套都低于 85 %，置 `evt = 6 (PAIR_FAIL)` 并且**不更新结果**。

配对相位错半拍时的定量后果：平台 [0,100] µs、采样间隔 50 µs，若配对偏移 δ，
则交替得到 `Δ = 50s` 与 `Δ = (50−2δ)s`（s = Vsq/L）。δ = 25 µs 时一半配对的 Δ 退化成 0 →
**均值只剩一半、L 高估约 2 倍，同时离散度暴涨到 ~50 %**。这与首次上机观察到的
"L 高估 1.8~1.95 倍 + scatter 60 %"完全吻合（见下）。

### 首次上机记录（2026-09-27，转子未夹紧）
```
[LDLQ52] start: d first pp=1000 mA bias=700 mA cycles=32 v=500 mV vbias=228 mV
[LDLQ52] d done: Ld=76uH di=906mA v=688mV bias=1184mA scatter=604/10 n=48
[LDLQ52] done: Ld=76uH Lq=83uH Lq/Ld=1088/1000 vs_vendor=1795/1000
[LDLQ52]   moved=65330cnts t=452ms state=0   [warn] rotor moved 65330 cnts
```
读法与结论：

1. `scatter = 60.4 %`（合格线 5 %）已经说明这批数据不可信 —— 模式自带的判据是对的。
2. `v = 688 / 837 mV` 而不是预期的 ~420 mV：自适应把幅值抬高了，因为探测到的 `|di|` 只有
   模型的一半左右 —— 这与"配对相位错半拍"的预言一致。
3. `moved = 65330` 是 16 位计数器**回绕**后的假数（真实净位移 −206 counts）；净位移不能
   用来判"转子是否在动"，必须看路径累计，故已新增 `g_ldlq52_path_cnts`。
4. 把 `|di|` 按"配对差半拍（δ ≈ 25 µs）"反推（即认为真实 `|di|` 约为测到的 1.8 倍），
   Ld/Lq 落到 **38 / 41 µH**，与手册 42.3 µH 吻合 —— 说明"配对相位"这一个假设就能同时
   解释 1.8 倍偏差和 60 % 离散度。**但这不是证明**：转子若在动（BEMF + 交叉耦合）也会
   造成 `|di|` 偏小、离散度变大、偏置电流偏移（实测 1184 mA vs 预期 690 mA）。
5. 因此新增三条有效性判据把两个嫌疑分开（任一不过就不更新结果，只留过程量）：

| 判据 | 变量 | 含义 |
|---|---|---|
| `cons_pct >= 85 %` | 配对一致性 | 低 ⇒ 配对相位问题（自选机制应已解决，若仍低说明采样链有别的异常） |
| `\|I_bias\| > 纹波半幅` | 单极性 | 电流过零 ⇒ 死区误差不再抵消 |
| `path_cnts <= 64` | 运动路径 | 转子在动 ⇒ BEMF/交叉耦合污染，夹紧后重测 |

**下一次预期**（若配对相位是主因）：`v` 回落到约 420 mV、`di ≈ 1000 mA`、
`cons ≈ 100 %`、`path` 很小、`Ld ≈ 42 µH`。

### 第二轮上机记录（2026-09-27，改完配对自选后）
```
（不捏转子）[LDLQ52] bias not established: i=0mA <= ripple/2=0mA -> data invalid
（捏住转子）[LDLQ52]   cons=678/10 (other=...) -> waveform not clean, data invalid
```
两条都失败，但**失败原因不同、且都是模式自己判出来的**：

1. 那行 `i=0mA <= ripple/2=0mA` 里两个 0 是**未赋值的全局量**（探测分支当时没把过程量落全局），
   不是真实值 —— 真实含义是探测确实测到纹波与一致配对，但**实测偏置电流没有超过纹波半幅**。
2. 捏住转子那次的 `cons = 67.8 %` 既不是正确配对的 ~100 %、也不是配错的 ~50 %：
   说明波形本身不干净，最可能是**电流过了零** —— 默认 `bias = 0.7 A` 只比纹波半幅
   （L≈42 µH 时约 0.59 A）大一点点，实测偏置一旦小于指令值，电流就会穿零，
   死区等效电压在平台内变号，平台内斜率不再一致。
3. 根因归纳：**偏置电流不能靠 R/V_dead 先验"算"出来，必须实测确认**。指令
   `V_bias = R·I_bias + V_dead先验`，先验一偏，偏置就不够，而偏置是本方法的命门。

已改（不再依赖先验）：

- 探测后检查实测 `|I_bias| ≥ 1.5 × 纹波半幅`，不够就把偏置电压抬 `FOC52_VBIAS_STEP_V = 0.1 V`
  重新探测，直到够用或到 1.5 V 上限；偏置不够与方波太小分成两个独立的重试分支。
- 每次探测完成在 `foc_obs` 打一行 `probe#`，含 `v / vbias / ripple/2 / bias / cons / other / n / need_bias`
  —— 四个关键数一眼可见。
- **两套配对的一致性都打印**（`cons` 与 `cons_other`）：两者都低就不是"选错配对"，
  而是波形问题（如电流过零）。
- 修正几何自检行的显示 bug（`platform` 曾按 `2×` 算成 200 µs，实际是 100 µs）。

### 第三轮上机记录（2026-09-27，`do_q=0` 只测 d 轴、未捏转子）
```
[LDLQ52] probe#1 axis=0: v=500mV vbias=238mV ripple/2=437mA bias=1160mA
[LDLQ52]   cons=875/10 n=16 need_bias=656mA
[LDLQ52] done: Ld=59uH Lq=0uH Lq/Ld=0/1000 vs_vendor=1392/1000
[LDLQ52]   vendor=42uH v=570mV di=969mA bias=1107mA vdead=129mV scatter=525/10 cons=946/10 n=56
[LDLQ52]   moved_d=-5 moved_q=0 net=-9 path=1 cnts t=226ms state=0
```
好消息：**转子确实没动**（`path=1`）、偏置够用（实测 1.16 A > need 0.66 A，`vdead=129mV`
与 mode 51 的 160mV 接近）。剩下一个系统性问题：

- `|di|` 只有理论值的 **0.72 倍**（Vsq=570mV、t_s=50µs 时，42.3µH 应对应 674mA，实测 484mA）；
- `scatter = 52.5%`（合格线 5%）。

**根因（用数字锁定）**：把"采样对与平台边界的相位 `a` 不确定"代入三角波模型，
|di| 在 a≤50µs 时 = 50s（两点同在一条斜坡上），a>50µs 时 = |150−2a|·s（跨过顶点、
互相抵消一部分）；对 a 取均匀分布，**均值 = 0.75 × 理想、离散度 ≈ 48 %** —— 与实测的
0.72 / 52 % 吻合。物理来源：翻转是按 **ISR 次数**计的（每 2 拍），一旦某次写入错过峰点
影子装载，采样相位就永久错开一拍，此后每个平台的两对采样里必有一对跨过顶点。

**修法（先仿真后下代码）**：平台长度正好是 2 个采样周期 ⇒ 每个平台内有两对相邻采样，
干净的那一对必然是两者中**较大**的那个 ⇒ **每平台取 max(|di|)**，与相位无关。
10 ns 步长仿真（`_cardgen/sim_mode52_gate.mjs`）：任意相位下**误差 0.00 %、离散度 0.00 %**；
而先试的"用相邻两对斜率差做线性闸门"方案会把顶点两侧的对**全部误杀、有效样本归零**，
已弃用 —— 这一步幸好先跑了仿真，否则又是一轮无效上机。
新增诊断量 `g_ldlq52_phase_ratio`（平台内 max/min ×100）：100 = 相位锁定，>200 = 错开一拍
（错开不影响结果正确性，纯粹是诊断量）。

**把这次的数按 max 规则反推**：59 µH × 0.72 = **42.5 µH**，与手册 42.3 µH 吻合 ——
下一次上机的预期就是直接落在 42 µH 附近、且 `scatter` 收进 5 %。

### 状态机（= 已实现版本）
```

ZERO(1)     : 零矢量 4000 拍（200 ms）采三相零偏（扣零偏用副本送 GetDq）
PROBE(2)    : 当前轴 0.5 V × 10 周期 → |di| → 定正式幅值（不够就升到 v_max 再探一次）
MEAS(3)     : 当前轴 Vsq × g_ldlq52_cycles（含偏置翻号）→ |di| 统计 → L；d 完成且有 do_q 则转 GAP
```

`g_ldlq52_running` 保持 1 以便 VOFA/Watch 回看（切模式时由 Stop 清掉）。

**时间预算**：零偏窗 200 ms + 每轴（9 ms 稳定 + 2 ms 探测 + 9 ms 稳定 + 6.4 ms 测量）
+ 间隔 200 ms ≈ **0.5 s**，热与机械风险极低。每相位开始前跳过的 45 个周期（9 ms）是让
偏置电流与直流分量先稳（260 µH 时 3.4 τ）；每个偏置子窗前 8 个平台也不统计（换号瞬间电流要过零）。

### 判据
- `d_scatter_pct < 5 %` 且 `moved_cnts` 在 ±8 以内，才认结果；
- `|I_bias| > 纹波半幅`（否则 `evt = 4`，本次结果不更新）；
- 两次重复测量（重进模式）结果差 < 5 %；换一个 `di_target`（如 1 A → 2 A）再测，差值即系统误差量级
  （仿真预期 < 2 %，若明显更大说明模型之外的因素在起作用，值得追）；
- **`ratio_vs_vendor ≈ 1`** ⇒ 手册 42.3 µH 成立，且与 mode 40 电流环整定自洽
  （`kp=0.1 / ki=300` ⇒ `ki/kp = 3000` ⇒ `L = R·kp/ki = 0.098/3000 = 33 µH`；
  按 42.3 µH 算的"精确零点抵消"ki 应为 232）；
  **`ratio_vs_vendor ≈ 6`** ⇒ 此前由 R=0.15 Ω 反推的 260 µH 成立，电流环需要重新整定；

- 若 `Ld ≈ Lq`（比值 0.95~1.05）→ SPM，MTPA 无意义（mode 27/41 扫 δ 的实验可以停了，结论就是"id=0 即最优"）；
- 若比值 > 1.15 → IPM，MTPA 有意义，`δ` 的最优点可用 mode 27 扫出来。

### 收敛后的算法与原理文档（2026-09-27 定稿）
最终采用**平台均值法**：`m_k` = 每个平台两点的均值，`ΔE = m_k − m_(k−1)`，
`L = Vsq·T_plt/|ΔE|`（T_plt = 100 µs）；首次上机那套"组内单点差分"（`pair`）降级为**诊断量**，
两套 L 都在 RTT 里打印，互为佐证。原理、公式推导（45 条编号公式）、仿真复核、五轮实测数据与
未解决问题，全部整理在 **`md_record/mode52参数LdLq辨识讲解.md`**。

其中一条重要结论（本次复核才发现，写进了上面那份文档）：按理想 RL 模型仿真，
`pair` 对采样相位几乎不敏感（偏 +0.6%~+7%），而 `env` 在理想模型里**永远偏高 2 倍以上**
（`_cardgen/sim_mode52_env.mjs`）；`env` 之所以在实机上成立，是因为真实采样波形里多了一个
与平台边界同步、且 **∝ Vsq/L** 的"台阶"（三条证据见该文档 §4.5）。也就是说：
`pair` 是理论上直接的估计但怕"错拍"，`env` 是经验成立的间接估计但更稳 —— 两者都要留着。

## 三、mode 53：ψf 辨识

### 原理
稳态、id≈0、diq/dt≈0：

```
vq = R·iq + ωe·ψf          ωe = rpm/60 × 2π × p
```

取多个转速点，用 mode 51 测出的 `R_eff`：

```
ψf_k = (vq_k − R·iq_k) / ωe_k      对 k 取中位数 / 均值
```

同时做二参数最小二乘 `vq = R·iq + ψf·ωe` 作为交叉验证（但注意：空载时 iq 与 ωe 近似共线，
两参数可分性差 —— **R 请以 51 的结果为准，52 只用单参数估计 ψf**）。

### 驱动方式（**待确认，见第五节**）
- **(a) 自带速度环（推荐）**：复制 mode 40 的结构（5 ms 速度 PI + 每拍电流 PI），
  按预设转速序列逐点稳态后取平均。控制好、可重复；代价是约 150 行重复代码。
- **(b) 恒 iq 自然平衡**：只跑电流环，给 4 档固定 iq，电机自己加速到"摩擦力矩 = Kt·iq"的平衡转速。
  代码量小一半，但转速由摩擦决定（可能过高/过低），且 iq 与 ωe 强相关。

### 状态机（按 (a) 设计）
```
IDLE(0)     : PWM 关
CHECK(1)    : Foc_Dcal_GetResult() 校验（无 mode 24 结果 → 拒绝启动 + 日志）
SPINUP(2)   : 速度环爬到第 k 个目标转速
SETTLE(3)   : 判稳态：|filt − ramp| < 15 rpm 且 |Δiq| < 20 mA（连续 300 ms）
AVG(4)      : 200 ms 窗口平均 vq / iq / rpm → 存第 k 个点
             超时 5 s 未稳态 → 跳过该点并置 evt 位
NEXT(5)     : k++ 直到 k = N（默认 4 点）
FIT(6)      : 计算 ψf（每点 + 中位数 + 单参数 LSQ）
DONE(7)     : 目标置 0、关 PWM、停在本模式（数据在 Watch/VOFA）
FAULT_OC(8) / FAULT_OVRPM(9) : 过流 / 超速
```

### 转速序列（Watch 可调）
默认 `{800, 1600, 2400, 3200}` rpm。上限 `FOC53_RPM_MAX = 4000`（超速立即目标置 0）。
为什么不用更高：3200 rpm 时 `vq ≈ R·iq + ωe·ψf ≈ 0.03 + 2.37 = 2.4 V`，离 UMAX 6.2 V 很远，
不会因饱和污染数据；再高就接近电压墙与编码器测速上限（`ENC_DELTA_MAX=36` 对应 ~7000 rpm）。

### 由"验证方法论"这个目标导出的三条设计调整

**1. 直接输出"实测 / 手册"比值**，Watch 里一眼判断思路对不对：

| 观测量 | 含义 |
|---|---|
| `g_rs51_ratio` | `R_eff_meas / FOC_MOTOR_RS_OHM`（**实测 0.98** —— 商家 0.1 Ω 已验证） |
| `g_ldlq52_ratio_vs_vendor` | `Ld_meas / FOC_MOTOR_LS_UH`（**预期 1 或 6 —— 这一条直接判定那个"六倍矛盾"**）；同模式的 `g_ldlq52_ratio` 是 `Lq/Ld`（判 SPM/IPM） |
| `g_flx53_ratio` | `ψf_meas / FOC_MOTOR_FLUX_VS`（预期 ≈0.87~1.0） |

**2. 两个 R 各算一遍 ψf**（量化 R 的敏感度，属于方法验证的一部分）：
mode 53 同时输出 `ψf(用实测 R)` 与 `ψf(用手册 R)` —— mode 51 已把 R 钉在 **0.098 Ω**，两者差值预计 <3 %。

**3. 数据质量指标与结果同等重要**，每个模式都输出：
拟合优度 `R²`、各点离散度、饱和标志、编码器位移、注入次数。
没有这些，"测出一个数"无法判断可信度，也就谈不上验证方法。

## 六、原待确认问题（已由上面覆盖，保留备查）

1. **mode 52 的驱动方式**：(a) 自带速度环（推荐，可重复）还是 (b) 恒 iq 自然平衡（代码少，转速靠摩擦）？
2. **机械条件**：转子**能不能夹紧**？轴上**有没有负载**（联轴器/配重/风叶）？
   - 能夹紧 → mode 51/53 数据质量最好（可选夹紧，不强制）；
   - 轴上有负载 → mode 52 的摩擦电流更大、转速更低，需要调整转速序列；
   - **转子完全不能夹且带大惯量** → mode 53 的 q 轴测量要减小注入幅值。
3. **测量结果怎么落地**：(a) 只放 Watch/VOFA，由你判断后手动改 `motor_config.h`（推荐）；
   (b) 模式下自动写回变量（甚至写 Flash 持久化）—— 有"测歪了把配置写坏"的风险。
4. **安全上限**：mode 51 最大注入电流默认 3 A（硬上限 5 A）、总注入 <1.5 s；
   mode 53 纹波峰值默认 1 A（硬上限 2 A）。这些值可以接受吗？（电机是 3505 云台电机，17 A 峰值规格）
5. **mode 52 结束行为**：测完自动把目标置 0 并**关 PWM 停在本模式**（推荐，避免无人看管时一直转），
   还是保持转动等你手动停？
6. **要不要顺便做"真定子电阻"的示波器流程**（模式外手工，方案里已写），还是这轮只做固件能自动给的 `R_eff`？
