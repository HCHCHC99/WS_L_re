# PWM 频率改为 20 kHz 施工方案

> 记录日期：2026-09-23
> 目的：把 PWM 载波从 10 kHz 提到 20 kHz，消除残余静止噪声（已由 `check_noisy_mode=2` 实验证实噪声来自 PWM 开关本身）
> 状态：**代码改动已完成 + ISR 预算已验证通过**；待办只剩「电流环 kp 恢复」与「回归验证」
> 前置阅读：`md_record/mode40静止噪声_定位与处置.md`（噪声定位过程）

---

## 〇、实测结果（2026-09-23，mode 40 运行中）

### ISR 预算自测：✅ 通过

| 变量 | 实测值 | 判读 |
|---|---|---|
| `g_foc_isr_period_max_us` | **51 µs** | 从不漏拍（超时会冲到 75+ 且不回落） |
| `g_foc_isr_period_min_us` | **51 µs** | 触发干净，无误触发 |
| `g_foc_isr_period_last_us` | **51 µs** | 稳定不跳，无样本被合理性检验丢弃 |

**结论：ISR 在 50 µs 周期内完成，20 kHz 可以放心使用。**

> 关于 51 vs 理论 50：按标称参数应为 50 µs 整（150 ticks ÷ 3 ticks/µs）。
> 差值 2% 的来源二选一，**均无需处理**：
> ① 实际时钟略低于标称（晶振/PLL 差 2% 属正常）——两路定时器同源，
>    测得的 51 µs 即真实时间，理论 50 µs 基于标称值，两边都对；
> ② Timer6 计数器 3 ticks/µs 的整数截断，±0.33 µs 量化误差。
> **验证方式**：示波器量 PWM 实际周期——51 µs 属①，精确 50 µs 属②。
>
> **为何无害**：采样与占空比更新均由 PWM 硬件同步（谷点采样→峰值搬移），
> 与软件定时器无关；速度测量用实测时间而非标称值；PI 积分步长 2% 误差可忽略。

### 测量方法（可复现）

已在 `foc.c` 加入 ISR 预算自测（`g_foc_isr_period_*` 三个 Watch 变量）：

- 用 Timer6 **原始计数器**（PCLK0/64 = 3.125 MHz，0.32 µs 分辨率，21 ms 回绕）
- ⚠️ **不能用 `Timer6_Timebase_GetTimestamp()`**：其累加只在主循环
  `Encoder_Update()` 里推进，更新周期远大于 50 µs，会量化失效
- FOC 未激活时**作废基准**（否则模式切换的间隙会被当成一个 ISR 间隔 →
  `max` 被永久污染成几千 µs 的"假超时"）
- 样本做 ±3% 合理性检验，带外丢弃（同时滤掉计数器回绕与被抢占抖动）
- 测量封装为返回值辅助函数，**绝不 return 掉 ISR 主体**

## 一、结论速览

| 项 | 内容 |
|---|---|
| **改动入口** | **仅一处**：`motor_config.h:14` `MOTOR_PWM_FREQ_HZ` 10000u → 20000u |
| ⚠️ 不是改 `tmr4_pwm.c` | 该文件是**被动**的，从参数算周期。改宏后 `s_u16Period` 自动 5000→2500 |
| **必须先做的验证** | **ISR 执行时间必须在 25 µs 内**（否则新占空比赶不上峰值搬移，延迟跳变致环路失稳） |
| 自动跟随的参数 | 采样率、FOC ISR 频率、速度环窗口拍数、PI 积分步长等（见第三节） |
| **必须手改的参数** | **6 处硬编码滤波系数 + 1 处编码器限幅**（见第四、五节） |
| 建议同时调的 | 电流环 kp 从 0.1 调回 0.5（20 kHz 下相位裕度从 34° 改善到 44°） |
| 不跑 mode 45 可暂缓 | `foc_smo.c` / `foc_pll.c` 的 α 共 4 处 |

### 收益机制（两条独立路径）

```
① 纹波减半：ΔI_pp = V·D·(1−D)/(L·f_sw)  ∝ 1/f_sw
   → 正反馈环路的激励源直接减半

② 移出可听频段：10 kHz 恰在人耳最敏感区间，20 kHz 超出听觉上限
```

## 三、自动跟随的参数（**不要动**）

| 参数 | 位置 | 机制 | 结果 |
|---|---|---|---|
| `SPEED40_SPD_WIN_TICKS` | `foc_speed40.c:23` | `= SPEED40_SPD_WIN_MS × FOC_ISR_HZ/1000` | 50 → 100 拍，**窗口仍是 5 ms** |
| `SPEED40_ISR_DT_US` | `foc_speed40.c:22` | `= 1000000u/FOC_ISR_HZ` | 100 → 50 µs |
| `DRUN29_MEAN_WIN_TICKS` | `foc_drun29.c:25` | 由 `FOC_ISR_HZ` 推导 | 自动保持物理窗口 |
| PI 积分步长（全部模式） | 各模块 `*_ISR_DT_US` | 同 `FOC_ISR_HZ` | 自动 |

### ⚠️ 特别说明：速度环的滤波系数**不要动**

```
SPEED40_SPD_FILT_ALPHA      = 0.25   （foc_speed40.h:91）
SPEED40_SPD_DISP_ALPHA      = 0.05   （foc_speed40.h:93）
```

**理由**：这两个 α 是按**速度环周期 5 ms** 标定的，而 5 ms 窗口由 `SPEED40_SPD_WIN_MS` 固定。

```
α = Ts/(τ + Ts) = 5ms/(20ms + 5ms) = 0.2 ≈ 0.25
```

**采样率翻倍不改变速度环周期**（ISR 频率变了，但抽稀比从 50 变 100，物理窗口不变）→ **α 保持有效，改它反而会破坏滤波时间常数。**

> 常见误解：以为"ISR 快了就得改所有滤波系数"。**只有按 ISR 周期标定的系数才要改**（见第四节）。

## 四、必须手改：硬编码滤波系数（共 4~6 处）

这些系数按 **10 kHz** 标定，采样率翻倍会让它们的**截止频率翻倍**——不是移除噪声，只是把它推到更高频。

| # | 位置 | 当前值 | 10 kHz 下 fc | **20 kHz 应改为** | 影响范围 |
|---|---|---|---|---|---|
| 1 | `foc_smo.c:35` `g_smo_lpf_alpha` | 0.39 | ≈1 kHz | **0.21** | mode 45 |
| 2 | `foc_pll.c:26` `g_pll_wout_lpf_alpha` | 0.0125 | ≈20 Hz | **0.00625** | mode 45 |
| 3 | `foc_pll.c:46` `g_pll_diag_filt_alpha` | 0.1 | — | **0.05**（保持滤波强度） | mode 45 |
| 4 | `I.c:48-55` `BIQUAD_B0/B1/B2/A1/A2` | fc≈40 Hz | 40 Hz | **需重算** → 80 Hz | ⚠️ 仅显示 |
| 5 | `Bemf.c:213` 8 抽头滑动平均 | 首零点 fs/8 | — | 16 抽头（保持时间常数） | 仅观察 |
| 6 | `I.h:78-79` ADC 采样窗 `64 ADCLK` | — | — | **建议不动**（见下） | 采样质量 |

### 关于 #1 的现成答案

`foc_smo.c:35` 的注释**已经写好了**：

```c
volatile float g_smo_lpf_alpha = 0.39f;  /* fc ≈ 1kHz @10kHz ISR（20kHz 时用 0.24）*/
```

注释给的 0.24 来自近似式 `α ≈ 2π·fc/fs`；精确式 `α = 1 − e^(−2π·fc/fs)` 给 **0.21**。
两者差 12%，实际影响很小，**用 0.21**（更准）。

### 关于 #6：ADC 采样窗**建议不动**

```
采样窗 64 ADCLK ≈ 1.28 µs
  10 kHz 下占周期 1.28%
  20 kHz 下占周期 2.56%
```

**相对平均效果反而翻倍**——采样窗内电容的电荷再分配对开关振铃是天然的平均，占比越高越好。**保持 64。**

### 关于 #4：显示 Biquad

```
设计值：fc = 200 Hz @ fs = 50 kHz
实际 fc = 200 × (MOTOR_PWM_FREQ_HZ / 50000)
  10 kHz → 40 Hz
  20 kHz → 80 Hz
```

**只影响 `g_i_*_filt` / `g_scope_*` / `g_i_*_disp` 等显示量，不进控制环。**
若要保持 40 Hz 的显示平滑度，需按 fc=40Hz@fs=20kHz 重算系数（低优先级）。

## 五、必须手改：编码器增量限幅

| 参数 | 位置 | 当前 | **建议改为** |
|---|---|---|---|
| `SPEED40_ENC_DELTA_MAX` | `foc_speed40.h:96` | 72 | **36** |

### 依据

该限幅按"单拍物理最大增量 × 1.35 裕度"设定：

| | 7800 rpm 单拍物理极限 | 限幅值 | 实际裕度 |
|---|---|---|---|
| 10 kHz（100 µs/拍） | 53 counts | 72 | 1.35× |
| 20 kHz（50 µs/拍） | **26.5 counts** | 72 | **2.7×** |

**改到 20 kHz 后限幅不会失效（更宽松），但抗毛刺能力下降**：物理真值只有 26.5，所以 27~72 之间的编码器毛刺会被当成真转速放行。

改 36 = 26.5 × 1.35，**恢复与当前相同的抗毛刺裕度**。

> ⚠️ 同类问题也可能存在于 mode 45 的 `SMO45_ENC_DELTA_MAX`（与 mode 40 同步设的 72），
> 若跑 mode 45 需一并检查。
>
> 另注：`foc_zizeng.c:26` `ZIZENG_DRAGDIR_MIN_CNTS = CPR/50` 是**窗口内**的判据，
> 不随 ISR 频率变化，**不用改**。

## 六、mode 40 建议同时调整：电流环 kp 调回 0.5

| 参数 | 位置 | 当前 | 建议 |
|---|---|---|---|
| `SPEED40_PI_KP` | `foc_speed40.h:90` | 0.1（治噪声临时值） | **0.5**（恢复带宽） |

### 为什么 20 kHz 下可以调回去

20 kHz 带来三个独立改善，都削弱那条正反馈：

| # | 改善 | 机制 |
|---|---|---|
| 1 | 纹波减半 | `ΔI_pp ∝ 1/f_sw` |
| 2 | 采样延迟减半 | 延迟从 100 µs 变 50 µs，相位损失减半 |
| 3 | 环路裕度改善 | 见下表 |

**相位裕度对比**（`PM = 180° − 90° + atan(ωc/wz) − atan(ωc/wp) − ωc·Td`）：

| kp | ωc = kp/L | 10 kHz 下 PM | **20 kHz 下 PM** |
|---|---|---|---|
| 0.1 | 376 rad/s (60 Hz) | ~85° | ~95° |
| 0.3 | 7092 rad/s | ~50° | ~62° |
| **0.5** | 11820 rad/s (1.88 kHz) | **~34°** ⚠️ | **~44°** ✅ |

**串级分离度也随之恢复**：

| | 电流环带宽 | 速度环（kp=2.0 → 36 Hz） | 分离度 |
|---|---|---|---|
| 现在（kp=0.1） | 60 Hz | 36 Hz | 1.7× |
| 20 kHz + kp=0.5 | 300 Hz | 36 Hz | **8.3×** ✅ |

### ⚠️ 操作顺序（不要一步跳到 0.5）

```
1. 改完 20 kHz，先保持 kp=0.1，听噪声 → 应在原基础上进一步下降
2. Watch 逐步加 kp：0.2 → 0.3 → 0.5，每档听噪声 + 看 VOFA ch5
3. 找出"噪声开始回升"的阈值
4. 取阈值的 70% 作为最终值写回宏
```

## 七、⚠️ 最大风险：ISR 时间预算腰斩

### 7.1 机制

```
10 kHz → 谷点采样到峰值搬移 = 50 µs，ISR 有 50 µs 完成计算
20 kHz → 谷点采样到峰值搬移 = 25 µs，ISR 只有 25 µs
```

**只要 ISR 超过 25 µs，新占空比就赶不上本次峰值搬移，要再等一个峰值 → 总延迟从 50 µs 跳到 75 µs**，
环路相位裕度突然恶化，可能直接振起来。

### 7.2 测量方法（施工前置）

在 `foc.c` 的 `Foc_Isr()` 入口与出口各翻转一个空闲 GPIO：

```c
void Foc_Isr(const stc_i_data_t *pData)
{
    GPIO_SET(<PORT>, <PIN>);        /* 入口 */
    ... 原有主体 ...
    GPIO_RESET(<PORT>, <PIN>);      /* 出口 */
}
```
（宏定义见 `Adp/Gpio_io.h:9-11`；Pin 需自行选一个未被占用的）

### 7.3 判据

| 实测 ISR 宽度 | 结论 |
|---|---|
| < 20 µs | ✅ 安全改 20 kHz |
| 20 ~ 25 µs | ⚠️ 勉强，建议折中到 15 kHz |
| > 25 µs | ❌ **先优化 ISR** |

⚠️⚠️ **必须在 mode 40 运行中测量。** mode 0 下 ISR 走的是空分支（`g_foc_active` 检查后直接返回），测不出真实负载。

## 十、可能变差的情形与对策

| 现象 | 可能原因 | 对策 |
|---|---|---|
| 噪声**变大**或换了个音色 | 更快 dV/dt 激发了功率回路寄生谐振 | 降低门极驱动速度（加大门极电阻）；或改 15 kHz 折中 |
| 电流环振铃 | ISR 超时导致延迟跳变 | 回退到 15 kHz，或优化 ISR |
| **低电流**下畸变加重 | 死区占比从 0.5% 翻倍到 1.0% | 这是物理必然；考虑加死区补偿或接受 |
| 速度环出现新振荡 | 抽稀比变了，速度环噪声特性略变 | 若 `SPEED40_SPD_FILT_ALPHA` 需要重调，小幅试 0.2~0.3 |
| DSP 负载过高 | ISR 时间逼近 25 µs | 降到 15 kHz；或优化 ISR（三角函数查表化、减少浮点） |

## 十二、附录：周期寄存器推导核对

```c
/* tmr4_pwm.c:182-184 */
u32TimerClock = CLK_GetBusClockFreq(CLK_BUS_PCLK1);      /* = 100 MHz (Sysclk.h) */
/* Triangle wave: one PWM cycle = 2 * period ticks */
s_u16Period   = (uint16_t)(u32TimerClock / (freq_hz * 2U));

10 kHz:  100e6 / (10000 × 2) = 5000  → 写入 4999
20 kHz:  100e6 / (20000 × 2) = 2500  → 写入 2499
```

两者均整除，**无频率误差**。

```c
/* tmr4_pwm.c:77-81  死区：按绝对时间换算，与载波无关 */
u16Ticks = dead_time_ns × timer_hz / 1e9
500 ns @100MHz = 50 ticks      （10 kHz 与 20 kHz 相同）
```

```c
/* I.h:98-105  采样率推导 */
I_ACTIVE_SAMPLE_RATE_HZ = MOTOR_PWM_FREQ_HZ              (VALLEY/PEAK 单边沿)
FOC_ISR_HZ              = I_ACTIVE_SAMPLE_RATE_HZ
```

### 关于自测代码的保留建议

`foc.c` 里的 ISR 预算自测**建议先保留**，等 kp 恢复与回归验证都做完再删。
理由：kp 从 0.1 恢复到 0.5 会显著增加每拍的浮点运算量，
若临界时序有余量不足，`g_foc_isr_period_last_us` 会立刻开始"卡住不更新"
—— 它是这一阶段最直接的早期告警。
