## 一、待分析的问题（现象描述）

| 项 | 内容 |
|---|---|
| 现象 | mode 40（编码器 FOC 速度/电流双闭环）运行时电机有**嘈杂噪声**；**目标转速 = 0 时依然存在** |
| 当前状态 | 目标 0 时：`iq_ref = 0`、转速 = 0、转子不转，理论上电流环应输出零矢量（占空比 50/50/50） |

| 用户推测 | VCC 抖动 → 传感器基准不准 → 采样识别到三相电流变化 → 程序施加微弱 PWM → 噪声 |
| 待验证 | 上述推测的**因果链未经验证**。详见第六节"已知的分析缺口" |

### 2.2 推导量 `[推导]`

```
Kt = 1.5 × pp × ψf = 1.5 × 10 × 0.00084 = 0.0126 N·m/A
J  = T_max / ω_max = 0.2 / (7800 × 2π/60) ≈ 1.18e-5 kg·m²   [峰值点等效，非实测]
τ_e = L/R = 42.3µH / 0.1Ω = 423 µs
```

⚠️ **J 是由额定点反推的等效值**，不是转动惯量实测值。若需精确值须做加速实验辨识。
⚠️ ψf 与 KV 表面不自洽约 10%（KV 隐含 ψf ≈ 0.000941）。**项目已在
`md_record/电流环PI理论计算.md:185-191` 论证：当 KV 取"线-线峰值"定义时两者自洽，
故 ψf = 0.00084 可信。** 仍非本机实测，若需精确值须测反电动势。

### 2.4 两个单位约定的核实（**重要，会影响带宽计算**）

**① L = 42.3 µH 是相值（每相自感），不是线-线值。**

依据（三重）：
- `md_record/电流环PI理论计算.md:16` 明确标注为"电机相电感（手册）"
- `foc_drun41.c:590-599`（mode 41 dq 解耦前馈）把它直接代入 dq 方程：
  `vd_ff = −ω_e·L·iq`、`vq_ff = ω_e·L·id` + `ω_e·ψf`
  —— **只有相电感才能代入 dq 电压方程**，这是最强的用法证据
- `md_record/电流环PI理论计算.md:94-105` 的推导 `G_ol = kp/(Ls)`、`f_bw = kp/(2πL)`
  同样只在相值下成立

**② ψf = 0.84 mWb 是相峰值。**
依据：`md_record/电流环PI理论计算.md:17` 标注"转子磁链（相峰值）"；
且 `Kt = 1.5·pp·ψf` 与额定转矩自洽（1.5×10×0.00084 = 0.0126 vs T/I = 0.01176，差 7%）。

### 2.5 ⚠️ 但 L 的**真值**高度不确定（这会改变带宽与 PI 结论）

**这是比单位约定严重得多的问题。** 项目自己的文档
`md_record/电流环PI理论计算.md:32-37, 167-181` 用两组独立实测现象反推：

| 量 | 手册值 | 实测反推 | 证据 |
|---|---|---|---|
| R_eff（环路总电阻） | 0.1 Ω | **≈0.15 Ω** | ① P-only 跟踪率 77%：`kp/(kp+R_eff)=0.5/0.65` ② 堵转尖峰 7.2A：`(kp·i_ref+I_TERM)/(kp+R_eff)=(1.5+3.2)/0.65` |
| **L_eff（环路电感）** | 42.3 µH | **42 ~ 260 µH 之间，未定** | kp=0.5 不振铃 ⇒ 真实 L 偏大；260µH 由 ki=300 反推（循环论证，只能当上限） |

文档结论原文：

> **矛盾指向：手册 L=42.3µH 大概率不是环路真实电感**（或为高频小信号值/线间测法差异），真实值偏大数倍。

**两套假设的结论差异（同文档 167-177 行）**：

| 量 | A 套（手册 L=42.3µH） | B 套（反推 L≈260µH） |
|---|---|---|
| 电气极点 `R/(2πL)` | 376 Hz | 92 Hz |
| 带宽 `kp/(2πL)` @kp=0.5 | 1882 Hz（违反 1kHz 约束） | 306 Hz |
| kp 上限（PM45°） | 0.44（**当前 0.5 已超**） | 2.72 |
| ζ（kp=0.5, ki=300） | 2.9 | 1.16 |

⚠️ **接收方计算前必须先选一套假设，或把两套都算给出边界。**
本机尚未做 kp 扫参实验（该文档 §6 给出了判别方法），**A/B 未定**。

**L 是线-线值**这一可能性已被上述证据排除（是相值）；但**相电感的具体数值**
（42.3 还是 ~260 µH）才是真问题。

### 2.3 这台电机的特殊性质（对噪声分析重要）

```
R = 0.1 Ω（极低）
L = 42.3 µH（极小）
```

**含义：几毫伏的线电压失衡即可产生几十毫安电流。** 低阻使得任何占空比量化误差、
死区误差、测量误差都会被放大成可观的电流。

**推导的电流环特性** `[推导]`（⚠️ 依赖 L 的取值，见 2.5）：

```
增益穿越频率 ω_c = kp/L = 0.5/42.3µH = 11820 rad/s ≈ 1.9 kHz   [A 套 L=42.3µH]
PI 零点        = ki/kp = 600 rad/s ≈ 95 Hz
电气极点       = R/L = 2364 rad/s ≈ 376 Hz
```

**环路延迟的真实构成**（已从寄存器语义核实，取代此前估算）：

| 环节 | 依据 | 时间 |
|---|---|---|
| ADC 采样时刻 | `AOS_Connect(AOS_ADC2_0, EVT_SRC_TMR4_3_SCMP2)`，谷点 | t = 0 |
| OCCR 生效时刻 | `tmr4_pwm.c:63` `TMR4_OC_BUF_COND_PEAK`（**峰值搬移**） | t = +50 µs |
| ISR 计算耗时 | 须在 50 µs 内完成，否则拖到下一个峰值 | 被上述 50 µs 吸收 |

→ **理论总延迟 ≈ 半个 PWM 周期 = 50 µs**（三角波峰谷间隔）。

| 延迟假设 | ω_c 处相位损失 | 估算相位裕度 |
|---|---|---|
| **50 µs（理论值，推荐）** | −54° | **≈ 94°** |
| 150 µs（保守估计，**无实测依据**） | −101° | ≈ 47° |

⚠️ **此前文档写的"150 µs"是估算而非实测**，现修正为：理论 50 µs，
实际落在 50~150 µs 之间（取决于 ISR 抖动与是否漏拍）。
**建议接收方按 50 µs 与 150 µs 双向给界**，或实测（在 ISR 里翻转 GPIO，示波器量）。

## 六、已知的分析缺口（**请勿在此之上直接下结论**）

### 缺口 ①：VCC 抖动 → 电流测量误差的因果**未验证**

已确认 ADC 参考 = VDDA = MCU 3.3V（`Adc.h:68` 硬编码），而传感器输出也以自身 VCC 为基准。
若传感器供电与 ADC 参考**同源**，则：

```
测量值 = (VCC_sensor × k) / VCC_VDDA × 常数 = 常数
```

即**比例式（ratiometric）测量会把 VCC 抖动大部分约掉**，读数几乎不变。

**所以"VCC 抖动 ⇒ 电流读数错误"这一步很可能不成立**，除非存在下列某一机制（均未验证）：

| # | 可能机制 | 说明 |
|---|---|---|
| 1 | 传感器供电与 ADC 参考**不同源**（走线阻抗不同） | 部分相关 |
| 2 | 传感器 PSRR 有限 / 内部基准非比例式 | 相关 |
| 3 | ADC 采样瞬间电荷注入/建立不足（塌陷发生在采样窗内） | **同步但非线性** |
| 4 | 三相传感器**增益失配** → 共模扰动经 Clarke 后残留为差模 | 相关 |

### 缺口 ②：电流传感器数据手册缺失

**缺少型号、PSRR、内部基准类型（比例式 or 带隙）、带宽、输出阻抗。**
这直接决定了缺口①中哪条机制成立。

### 缺口 ③：VCC 抖动的**频率成分未知**

用户只报告了幅度范围（3.0~3.5V），**未测频谱**。
是"与 PWM 同步的周期性塌陷"还是"宽带瞬态"，处理方式完全不同。
**这是决定滤波器结构（低通/高通/带通/不滤）的关键输入。**

### 缺口 ④：电流信号本身的频谱未知

尚未测量**电流反馈**中实际存在的频率成分。
**注意：VCC 抖动 ≠ 电流读数抖动**，两者之间的传递函数正是缺口①的四条机制之和。

### 缺口 ⑤：混叠结构分析

因 **采样率 = PWM 频率 = 10 kHz**，采样后：
- 10 kHz 整数倍的干扰 → **全部折到 DC**（数字滤波器对 DC 增益恒为 1，**无法处理**）
- 5 kHz 以上 → 折入 0~5 kHz 带内
- 数字滤波器只能处理 0~5 kHz；**采样前的干扰只能靠模拟 RC 解决**

**[待确认]** 上述结论基于"干扰与 PWM 同步"的假设，需缺口③的实测支持。

## 九、给接收方 agent 的建议提问方式

由于缺口①~⑤未闭合，**建议不要直接问"该用什么滤波器"**，而是分两步：

**第一步（确定要不要滤）**
> 在采样率 = 开关频率 = 10 kHz、且 ADC 参考与传感器供电同为 3.3V 的条件下，
> 开关噪声经过采样后会落在频谱的什么位置？数字滤波器能否处理？需要什么前置测量？

**第二步（确定滤什么）**
> 对于一个"电流环带宽约 1.9 kHz、相位裕度 47°~94°（取决于环路延迟取 150µs 还是 50µs）、
> 且反馈通路无抗混叠"的系统，若要在反馈路径插入滤波，
> 相位代价与噪声抑制如何权衡？截止频率应如何选取？

**⚠️ 但在计算之前，请先选定 L 的假设（见 2.5）：**
> 手册相电感 42.3 µH 与实测反推值（42~260 µH）相差可达 6 倍，
> 电气极点、带宽、kp 上限、阻尼比全部随之变化。
> 请按 A 套（42.3µH）/ B 套（~260µH）**分别给界**，不要只取一套。
