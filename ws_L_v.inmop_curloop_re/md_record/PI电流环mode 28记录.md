## 一、mode 28 是什么

**功角参考电流闭环**：磁场/电流矢量不再"钉电压"，而是 PI 闭环把真实转子系电流钉在指令方向上。

```
参考生成：id_ref = I_ref·cos(δ),  iq_ref = I_ref·I_ref·sin(δ)
闭环：    vd = PID_d(id_ref, id),  vq = PID_q(iq_ref, iq)   （转子坐标系）
输出：    反 Park（转子角） → SVPWM
```

- δ=90° 即 id_ref=0，经典 FOC / MTPA 工况
- 转速是指令力矩与摩擦的平衡结果（恒力矩源特性）
- 与 mode 27（电压版功角闭环）的本质差异：27 钉电压角度、电流漂出来；28 钉电流矢量

## 二、实施三步曲（全部硬件验证）

### Step 1：复刻 mode 27 + foc_calib 零偏窗
- foc_dci.c/h 完整复刻 27（校准序列、δ 爬坡、±32 编码器限幅帧、统计）
- 新增 `DCI_STEP_CALIB`：零矢量 50/50/50 + `Foc_Calib_Feed`（~210ms）锁三相零偏
- 锁定后所有 Clarke/Park 用零偏校正副本 dataCal；OC 保护仍用原始采样
- **验收结果**：δ=90° 时 idMean=69mA（理论 ωLs·iq/R≈69），零偏清除确认 ✓

### Step 2：电压源 → P-only 电流环
- 参考 = (I_ref, δ 爬坡)，vd/vq = PID 输出（i_valid=false 仅 P），反 Park 在转子角
- 复用 dev_pid（pid_config_t 全 volatile，Watch 免编译调参）
- **第一次翻车**：kp=0.05 电机纹丝不动——P 环最大输出 = kp×误差 = 0.017V，
  连铜阻压降 0.05V 都不够。修正：P-only 门槛 kp ≈ (3~7)×R ≈ 0.5~1 V/A
- **kp=0.5 验证**：δ=45°/1A 时 iq 实际 160mA，与公式
  `iq = (kp·iq_ref − ωψf)/(kp+R)` 预测 163mA 分毫不差 ✓

### Step 3：I 启用（当前状态）
- i_valid=true，ki=300 ≈ kp×R/L（L≈0.26mH 由 387Hz 数据反推）
- **250mA 档**：`edMean=0 eqMean=0`，iqMean=249 咬住 250 —— **PI 闭环成立** ✓
- 转速 280Hz 平衡点闭合（恒力矩 2.25mNm = 摩擦）
- **3A 档**：空载跑到饱和天花板 1005Hz（6032rpm），iqMean=385mA，
  eqMean=2701 + [SAT] —— 电压预算耗尽，物理边界而非环失败

## 三、物理结论清单（本项目沉淀的核心认知）

1. **P-only 稳态落差公式**：`e = (R·i_ref + ω·ψf)/(kp + R)` —— 铜阻项 kp 能压，
   BEMF 项随速度增长且受稳定极限（kp ≈ L/1.5Ts）封顶，高速下 P-only 永远到不了目标
2. **空载恒力矩源定律**：稳态电流 ≡ 摩擦电流，指令值只决定"多快冲到饱和天花板"。
   让指令电流成为稳态电流的唯一途径 = 加负载（或堵转验证）
3. **电压预算账本**：`UMAX = BEMF(ω) + R·iq`。UMAX=3.5V 时 3A 可保持至 ~5300rpm；
   ITERM_MAX 必须 > 天花板处 BEMF（否则积分器先饱和）
4. **堵转尖峰公式**：从天花板突捏停，积分器存的电压释放：
   `i_peak = (kp·i_ref + I_frozen)/(kp + R) = (1.5+3.2)/0.65 ≈ 7.2A`，
   与 I_ref 无关（I_frozen 主导），自恢复毫秒~秒级，< OC 9A 安全
5. **校准偏置无关性**：电路方程 `vq = R·iq + ωψf` 是不经过校准的独立法官，
   两次独立闭合（250mA 与 385mA 工况）证明落差是物理的，测量无欺骗

## 七、已知现象（非故障）

1. **堵转尖峰 ~7A**：积分器存压释放，公式见上，自恢复，<OC
2. **eqPP 4~7A 残留**：机械扰动（stick-slip/转速纹波）经有限环路增益泄漏，
   均值不受影响；打磨项非阻塞项
3. **P-only 高速 hunting**（"周期性转过头"噪声）：BEMF↔转速↔电流耦合回路
   阻尼差，开 I 后缓解
4. **spd 显示符号与电角度方向相反**：speed 统计未乘编码器方向（挂起任务）

## 八、待办：校准/闭环拆分（mode 24/29）

- **P 重调方法**（转子捏死 = BEMF=0 纯 R+L 对象）：
