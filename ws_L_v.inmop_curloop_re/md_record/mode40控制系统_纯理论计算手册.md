## 〇、理论计算的固有边界（先读）

纯理论能回答"**给定参数下系统必然如何**"，但有两类输入它拿不到，必须诚实标注：

| 输入 | 为什么理论拿不到 | 处理方式 |
|---|---|---|
| **机械阻尼 B**（摩擦+风阻） | 厂商不提供。它决定机械极点 `B/J` | **做参数敏感性分析**：给出 kfb（=B/Kt，量纲 1/s）取 0.5/2/10/50 时的结果 |
| **环路延迟 Td** | 取决于 ISR 执行时间与影子寄存器时序 | 由代码推出理论值，并给出双界（50µs / 150µs） |
| 电感 L、电阻 R | 手册给了 42.3µH / 0.1Ω | **直接采用**（本手册不做实测反推）；另附 L 敏感性一节说明它的影响 |

**因此本手册给出的不是单一数字，而是"公式 + 边界表"。** 这正是理论计算该有的产物。

## 二、电流环（内环）：对象建模

### 2.1 建模

转子坐标系下（id/iq），捏死转子或低速时 BEMF 与交叉耦合项是**外部扰动**，不进入对象传函：

```
对象：  Gp(s) = 1/(L·s + R)
电气极点 ωp = R/L = 0.1/42.3µ = 2364 rad/s = 376 Hz
时间常数 τe = L/R = 423 µs
```

PI（位置式，输出即电压指令，无额外增益）：

```
Gc(s) = kp·(1 + ki/(kp·s)) = kp·(s + wz)/s,   wz = ki/kp = 600 rad/s = 95 Hz
```

### 2.2 关键结论：PI 零点对消电气极点

```
开环  Gol(s) = kp·(s+wz) / [L·s·(s+wp)]
当 wz = wp（即 ki = kp·R/L = 1182）时对消，退化为纯积分：

Gol(s) = kp/(L·s)      →     闭环  Gcl(s) = 1/(τcl·s + 1),  τcl = L/kp
```

**★ 增益穿越频率（精确值）：**
```
ωc = kp/L
```

> 这是本手册最有用的一个公式：**带宽只由 kp 和 L 决定**，与 ki 无关。

**当前参数（kp=0.5, L=42.3µH）：**
```
ωc = 0.5/42.3µ = 11820 rad/s = 1.88 kHz
```

### 2.3 相位裕度（含延迟）

```
PM = 180° − 90°（积分器）+ atan(ωc/wz)（PI 零点）− atan(ωc/wp)（电气极点）− ωc·Td（总延迟）
```

| 延迟 Td | ωc·Td（弧度） | 延迟相位 | PM |
|---|---|---|---|
| **50 µs**（理论值，见 2.4） | 0.591 | −33.9° | **64.5°** ✅ |
| 150 µs（保守界） | 1.773 | −101.6° | **−3.2°** ⚠️ **临界/发散** |

**这是本次分析最重要的发现：**

> 若真实延迟接近 150 µs，电流环在 kp=0.5 下**相位裕度归零**，系统处于临界振荡。
> 但现场能稳定运行 → **反证真实延迟显著小于 150 µs**（或真实 L 更大，二者可区分，见第五节）。
>
> **⇒ 50 µs 这个理论值不是"乐观估计"，而是被"系统能稳定运行"这一事实所要求的。**

### 2.4 延迟 Td 的理论推导（不靠实测）

| 环节 | 时刻 | 依据 |
|---|---|---|
| ADC 采样 | t = 0（三角波**谷点**） | `I.c:270` `AOS_Connect(AOS_ADC2_0, EVT_SRC_TMR4_3_SCMP2)` |
| PI 计算 → 写 OCCR | 0 < t < 50 µs（须完成） | ISR 执行时间 |
| **OCCR 生效** | **t = 50 µs（三角波峰值）** | `tmr4_pwm.c:63` `TMR4_OC_BUF_COND_PEAK` |

```
PWM 周期 100 µs，谷点与峰值间隔 = 50 µs
⇒ Td = 50 µs（计算耗时被这半个周期吸收）
```

**⚠️ 该结论有前提**：ISR 执行时间 < 50 µs。若超出，新占空比要再等一个峰值 → Td 跳到 150 µs。

> **验证 2**：ISR 入口翻一个空闲 GPIO，出口再翻一次，示波器量高电平宽度。
> **预期**：< 50 µs（典型 FOC ISR 在 200MHz M4 上是 10~25 µs）。
> **若接近或超过 50 µs**：电流环相位裕度会突然恶化，必须优化 ISR（减少浮点、查表化三角函数）。

## 三、电流环：数字实现的影响

### 3.1 离散化（零阶保持 + 位置式 PI）

```
采样周期 Ts = 100 µs (10 kHz)

对象离散极点：  z_p = e^(−R·Ts/L) = e^(−0.2364) = 0.7895
PI 离散零点：   z_z = 1 − (ki/kp)·Ts = 1 − 600×1e-4 = 0.9400
```

**零点未能严格对消极点**（0.94 vs 0.79），因为 `ki=300` 小于对消值 1182（`wz/wp = 0.254`）。
但 `ωc/wz = 19.7`，即穿越频率远高于 PI 零点 → 在穿越频率处 PI 已近似纯积分，**相位上仍接近 −90°，结论 2.2 不受影响**。

### 3.2 闭环极点配置

I 开启后闭环特征方程：
```
L·s² + (R + kp)·s + ki = 0
ωn = √(ki/L) = √(300/42.3µ) = 2663 rad/s
ζ  = (R + kp)/(2·√(ki·L)) = 0.6/(2×0.1127) = 2.66
```
**ζ = 2.66 ≫ 1 → 过阻尼，无超调**（理论上）

> **验证 3**：mode 29 捏死转子做电流阶跃（`g_dci_dlt_init=targ=90`, `tr=0`），VOFA 看 iq 上升。
> **预期**：单调上升，无过冲。
> **若出现过冲/振铃**：说明 ζ 实际 < 1，即 `(R+kp)² < 4·ki·L` → 真实 L 比手册值大（见第五节）。

### 3.3 kp / ki 的理论天花板

| 约束 | 公式 | 代入值得 |
|---|---|---|
| 带宽 ≤ fs/10（工程惯例，保守） | kp ≤ 2πL·(fs/10) = 2πL·1000 | **0.266** ⚠️ 当前 0.5 **已超** |
| 相位裕度 ≥ 45°（取 Td=50µs） | 数值解 | **≈ 0.85 V/A** |
| 无超调（ζ ≥ 1） | ki ≤ (R+kp)²/(4L) | **2497** ✅ 当前 300 远低于 |
| 零极点对消（收敛最快） | ki = kp·R/L | **1182**（当前 300，偏小） |

> **注意**："带宽 ≤ fs/10" 这条惯例在此处与"PM≥45°"给出的上限差 3 倍。
> 惯例值是**保守经验**，不是硬约束；本系统真正硬的是相位裕度那条（0.85）。
> **不要在函数式结论中混用两者。**

## 四、速度环（外环）：二级建模

速度环是**一阶对象 + 反馈滤波 + PI** 的 II 型系统，比电流环复杂，必须逐步建。

### 4.1 各环节

| 环节 | 传函 | 数值 |
|---|---|---|
| 电流环（内环，理想化） | ≈ 1 | 带宽 1.88 kHz ≫ 速度环，误差 <1% |
| 机电对象 | `Kg/(J·s + B)` | Kg = 491.4 rpm/s per A |
| 机械极点 | `ω_mech = B/J` | **未知**（见 4.4 敏感性） |
| 测速窗口（5ms 计数） | ≈ 一阶，τ_w ≈ 2.5 ms | 均值滤波的等效延迟 |
| 反馈 EMA（α=0.25 @5ms） | 一阶，τ = Ts/α = 20 ms | ω_EMA = 50 rad/s = **8.0 Hz** |
| PI | `kp·(s + wi)/s` | wi = ki/kp = 0.45/4 = **0.1125 rad/s** |

### 4.2 关键结构发现：wg ≪ wc ≪ w_EMA

代入 kp=4（以 kfb=2、即 ω_mech=103 rad/s 为例）：

```
PI 零点   wi   = 0.1125 rad/s  = 0.018 Hz
穿越频率  wc   = 289 rad/s     = 46 Hz
机械极点  w_mech = 103 rad/s   = 16 Hz
EMA 极点  w_EMA = 50 rad/s     = 8 Hz
```

**⇒ PI 零点比穿越频率低 3 个数量级。** 这意味着：

> 在穿越频率附近，积分项贡献 ≈ 0，**环路动态几乎完全由 kp 决定**。
> ki 只影响**极低频（< 0.1 rad/s）的稳态精度**，不影响响应速度与稳定性。

这解释了一个常见困惑：**"调 ki 想改响应快慢"是无效的**——它改的是稳态误差的消除速度，不是带宽。

### 4.3 带宽与 kp 的定量关系

由幅值穿越条件（忽略延迟）解得：

| kp (mA/rpm) | 环路增益 Kh (1/s) | ωc (rad/s) | **f_c (Hz)** | PM (Td=50µs) |
|---|---|---|---|---|
| 1.8（旧值） | 0.885 | 110 | **17.5** | 67.1° |
| **4.0（当前）** | 1.966 | 289 | **46.0** | 28.6° |
| 8.0 | 3.93 | 594 | 94.6° → 94.6 | 12.9° ⚠️ |
| 16.0 | 7.86 | 1197 | 190 | 3.9° ⚠️ |

**⇒ 带宽与 kp 近似线性**：`ωc ≈ 72.2 × kp`（在 kfb=2 下）。

**⚠️ 但 kp=4 已经逼近采样极限**：

```
速度环采样率 200 Hz → Nyquist = 100 Hz
当前穿越频率 46 Hz = 0.46 × Nyquist = 4.3 倍采样间隔
```

工程上通常要求穿越频率 ≤ fs/10 = 20 Hz。**当前 kp=4 已超出该惯例 2.3 倍。**

### 4.4 参数敏感性：机械阻尼决定一切

`ω_mech = B/J` 未知，它是速度环分析的最大不确定源。扫描 kfb（=B/Kt）：

**kp=4 时：**

| kfb (1/s) | τ_mech | ω_mech | ωc | f_c | PM(50µs) | 评价 |
|---|---|---|---|---|---|---|
| 0.5 | 39 ms | 25.7 | 145 | 23 Hz | **28.7°** | 偏薄 |
| 2 | 9.7 ms | 103 | 289 | 46 Hz | **28.6°** | 偏薄 |
| 10 | 1.9 ms | 515 | 579 | 92 Hz | **44.9°** | 可接受 |
| 50 | 0.4 ms | 2573 | 830 | 132 Hz | **73.2°** | 好 |

**★ 关键洞察：PM 几乎与 kfb 无关（28.7° vs 28.6° @ kfb=0.5/2），但 ωc 强烈相关。**
原因：穿越频率总落在 `ω_mech` 与 `ω_EMA` 之间，两个极点在穿越频率处的相位贡献此消彼长，**近似互补**。

> **⇒ 结论：速度环的相位裕度由 kp 和 EMA 滤波主导，与机械阻尼关系不大。**
> **⇒ 而带宽（响应速度）则强烈依赖机械阻尼——阻尼越大，同样的 kp 能跑到更高带宽。**

### 4.5 ki 的作用：稳态精度

从 `L(s) = Kh·(1+s/wi)/(s·(1+s/ω_mech)(1+s/ω_EMA))` 的**低频增益**看：

```
低频（s → 0）：L(s) ≈ Kh·wi/s = (kp·Kg/1000)·(ki/kp)/s = ki·Kg/(1000·s)
⇒ 低频增益只由 ki 决定，与 kp 无关
```

**积分器建立电流所需时间**（把积分项推到 100 mA，即克服典型摩擦的量级）：

| ki | err=10 rpm | err=50 rpm | err=100 rpm |
|---|---|---|---|
| 0.2（旧值） | 50 s | 10 s | 5 s |
| **0.45（当前）** | **22 s** | **4.4 s** | **2.2 s** |
| 1.0 | 10 s | 2.0 s | 1.0 s |
| 2.0 | 5 s | 1.0 s | 0.5 s |

**PM 随 ki 的变化（kp=4, kfb=2, Td=50µs）：**

| ki | wi (rad/s) | ωc (rad/s) | PM |
|---|---|---|---|
| 0.05 | 0.0125 | 896 | **7.2°** ⚠️ |
| 0.2 | 0.05 | 443 | 18.3° |
| **0.45** | 0.1125 | 289 | **28.6°** |
| 1.0 | 0.25 | 185 | 43.7° |
| 2.0 | 0.50 | 119 | 63.2° |

**★ 反直觉但重要：增大 ki 反而提高相位裕度。**

机理：ki 越大 → PI 零点 wi 越高 → 零点离穿越频率越近 → 提供的相位超前越多，
同时穿越频率被拉低。**所以 ki 小不但稳态慢，稳定性也更差。**

> **验证 4**：把 ki 从 0.45 逐步加到 1.0、2.0，观察 VOFA ch17（PI 反馈）追 ch13（斜坡给定）。
> **预期**：稳态差收敛更快，且**振铃减少**（PM 提高）。
> **若振铃反而增加**：说明我的相位模型漏了某个环节（最可能是速度环采样延迟未计入），需重估。

### 4.6 速度环采样延迟（4.5 未计入的一项）

速度 PI 每 5 ms 才更新一次输出，相当于额外延迟 Td_s ∈ [0, 5] ms（平均 2.5 ms）：

```
在 ωc = 289 rad/s 处：  289 × 2.5e-3 = 0.72 rad = 41.4°
```

考虑这项后，PM 从 28.6° 降至约 **19°**（kfb=2）。

> **这意味着 kp=4 在 200 Hz 采样率下已相当激进。**
> 若实测出现持续振铃，**首选降低 kp**（而非 ki），或把 `SPEED40_SPD_WIN_MS` 从 5 降到 3（提高采样率）。
> ⚠️ 降低 `SPEED40_SPD_FILT_ALPHA`（减轻 EMA 滞后）也能提高 PM，但会放进更多编码器量化噪声。

## 五、L 的敏感性（不做实测反推，纯理论上看它如何影响结论）

手册给 L = 42.3 µH。**理论上**若真实 L 不同，结论如何变？

| L | ωp = R/L | ωc = kp/L | f_c | PM(Td=50µs) | PM(Td=150µs) | ζ（电流环） |
|---|---|---|---|---|---|---|
| **42.3 µH**（手册） | 2364 | 11820 | **1.88 kHz** | **64.5°** | **−3.2°** ⚠️ | 2.66 |
| 100 µH | 1000 | 5000 | 796 Hz | 79.2° | 51.6° | 1.73 |
| 260 µH | 577 | 1923 | 306 Hz | 83.9° | 72.8° | 1.09 |

**★ 这张表能反过来定 L：**

| 若实测到… | 则 L 约为… | 因为 |
|---|---|---|
| 电流阶跃**有轻微过冲**（ζ<1） | > 270 µH | ζ=1 对应 L=(R+kp)²/(4ki)=270µH |
| 电流阶跃**单调无过冲** | < 270 µH | ζ>1 |
| 电流环在 kp 增大时**很晚才振铃** | 偏大 | 振铃阈值 ∝ L |
| 当前 kp=0.5 下系统**稳定** | 若 Td=50µs 则任意 L 都稳；若 Td 接近 150µs 则 L 必须 > 100µH | 见 2.3 |

> **验证 5（用理论反推参数）**：mode 29 捏死转子，kp 从 0.5 逐步加到 0.8、1.0、1.5、2.0，
> 记录**首次出现持续振铃的 kp 值** kp_ring。
> **预期关系**：`kp_ring ≈ 10472·L`（由 PM=45° 反解）
> → 若 kp_ring ≈ 0.44，则 L ≈ 42 µH；若 kp_ring ≈ 1.0，则 L ≈ 95 µH；若 ≈ 2.7，则 L ≈ 260 µH。

## 六、混叠分析（滤波器该不该加、加在哪）

### 6.1 核心事实

```
采样率 fs = 10 kHz      （I.h:67, 98-105）
开关频率 fsw = 10 kHz   （motor_config.h:14）
⇒ fs = fsw
```

### 6.2 折叠规律

以 fs = 10 kHz 采样时，频率 f 的干扰折叠到 `|f mod fs|`（超出 fs/2 则镜像）：

| 干扰频率 | 折叠到 | 落在哪 |
|---|---|---|
| 10 kHz（开关基频） | **0 Hz（DC）** | **直流** |
| 20 kHz（2 次） | **0 Hz** | **直流** |
| 30 kHz（3 次） | **0 Hz** | **直流** |
| 15 kHz | 5 kHz → 镜像 5 kHz | Nyquist 点 |
| 12 kHz | 2 kHz | 4~5 kHz 区间 |

### 6.3 ★ 结论：数字滤波器对"与 PWM 同步的干扰"原理上无效

```
开关基频及其所有整数倍谐波  →  采样后全部落在 DC
数字滤波器对 DC 的增益恒为 1（低通）/ 0（高通）
⇒ 无法在数字域把它们与真实信号分离
```

**唯一能在采样前动手的是模拟滤波。**

### 6.4 数字滤波器能处理什么

只有 **0 ~ 5 kHz 带内**、且**不与 fs 整数倍重合**的干扰。例如：
- 传感器宽带噪声（白噪声，全频段）
- 与 PWM 不同步的机械/电磁干扰

### 6.5 滤波器方案与相位代价（数字侧）

若加数字低通（用于压制带内宽带噪声）：

| fc | 电流环 ωc 处相位损失 | 内环 PM（原 64.5°） | 3kHz 衰减 |
|---|---|---|---|
| 2 kHz | −8.5° | 56.0° | −11.4 dB |

## 七、验证方法总表

> 每一条都是**可证伪**的：若现象与预期不符，右列给出该怀疑什么。

| # | 理论预测 | 预期现象 | 验证手段 | 若不成立 → 说明 |
|---|---|---|---|---|
| 1 | Kt 两算式差 <10% | 0.0126 vs 0.01176 | 纯计算 | 铭牌参数有错，力矩换算全废 |

| 8 | 速度环带宽 ∝ kp | ωc ≈ 72·kp（kfb=2） | 改 kp 看 ch17 响应速度 | 非线性 ⇒ 机械阻尼非常数（含静摩擦） |
| 9 | 速度环 PM 与机械阻尼弱相关 | 不同负载下振铃程度相近 | 加载/空载对比 | 强相关 ⇒ 有其他主导极点 |

### 关键验证的操作步骤（VOFA 判据）

```
通道：ch13 = 斜坡给定(真实参考)  ch14 = 目标  ch17 = PI 反馈
      ch7 = iq_ref  ch9 = vq

判据一（振荡/发散）：ch17 是否持续等幅或增幅振荡
判据二（带宽）：      ch13 阶跃后 ch17 到 63% 的时间 ≈ 1/ωc
判据三（超调）：      ch17 越过 ch13 的百分比 → 反推 ζ = |ln(Mp)|/√(π²+ln²(Mp))
判据四（稳态）：      稳态时 ch13 − ch17 = 维持电流/kp（可直接反推摩擦电流）
```

## 八、理论计算给出的边界值汇总

| 量 | 边界值 | 约束来源 | 置信度 |
|---|---|---|---|
| **电流环带宽上限** | 1.9 kHz @kp=0.5（手册 L） | kp/L，纯代数 | 高（依赖 L） |
| **电流环 kp 上限** | 0.85 V/A | PM ≥ 45°，Td=50µs | **中**（依赖 Td） |
| **电流环 ki 范围** | 300 ~ 2497 | 下限：收敛速度；上限：ζ≥1 | 高 |
| **速度环带宽上限** | ~46 Hz @kp=4 | 实测前的理论值 | **低**（依赖机械阻尼 kfb） |
| **速度环 kp 建议** | 2 ~ 4 | PM ≥ 20°（含 5ms 采样延迟） | 中 |
| **速度环 ki 建议** | **1.0 ~ 2.0** | 稳态收敛 <1s 且 PM ≥ 45° | **中高**（当前 0.45 偏小） |
| **数字低通 fc** | ≥ 1.5 kHz | PM ≥ 50% × 原值 | 高 |
| **模拟 RC fc** | ~1.6 kHz | 压 fs 同步分量且不伤 PM | 中 |
| **环路延迟 Td** | 50 µs（理论）/ 150 µs（保守） | OCCR 峰值搬移 | 需实测确认 |

### 三条最值得立刻行动的结论

1. **ki 从 0.45 提到 1.0 左右** —— 同时改善稳态收敛（4.4s→2.0s）**和**相位裕度（28.6°→43.7°），是双赢调整。
2. **kp=4 已接近 200 Hz 采样率的极限**（46 Hz vs Nyquist 100 Hz）。若出现振铃，**先降 kp，不要降 ki**。
3. **若噪声与 PWM 同步，数字滤波无效** —— 必须走模拟 RC 或改善电源去耦。这是第六节的硬结论。

## 九、本手册未覆盖的部分

- ❌ 未包含 VCC 抖动对传感器的影响（属噪声溯源问题，见 `电流反馈抗混叠.md`）
- ❌ 速度环采样延迟用的是平均 2.5 ms 的粗略模型，未做精确的采样-保持分析
