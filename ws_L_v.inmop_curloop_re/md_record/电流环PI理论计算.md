# 电流环 PI 理论计算 —— 从电机参数到 Kp/Ki

> 记录日期：2026-09-14
> 适用：mode 28/29 电流环（foc_dci.c，转子坐标系，捏死转子 = 纯 R+L 对象）
> 当前实际值：`DCI_PI_KP=0.5`、`DCI_PI_KI=300`（foc_dci.h），本文回答"理论值应该是多少、为什么"

## 一、参数盘点：已知 vs 待求

### 1.1 已知量（motor_config.h，直接查表）

| 符号 | 值 | 宏 | 备注 |
|---|---|---|---|
| R | 0.1 Ω | `FOC_MOTOR_RS_OHM` | 电机相电阻（手册） |
| L | 42.3 µH | `FOC_MOTOR_LS_UH` | 电机相电感（手册，**存疑，见 §5**） |
| ψf | 0.84 mWb | `FOC_MOTOR_FLUX_VS` | 转子磁链（相峰值） |
| p | 10 | `FOC_POLE_PAIRS` | 极对数 |
| Ts | 50 µs | `FOC_ISR_HZ=20000` | 电流环采样周期 |
| f_pwm | 10 kHz | `MOTOR_PWM_FREQ_HZ` | PWM 频率（ISR 的 2 倍过采样） |
| VBUS | 12 V | `FOC_VBUS_V` | 母线电压 |

### 1.2 已知约束（foc_dci.h + 硬件安全）

| 约束 | 值 | 来源 |
|---|---|---|
| PI 输出限幅 UMAX | ±3.5 V | `DCI_PI_UMAX_V`（远小于 SVPWM 线性区上限 VBUS/√3=6.93V，留余量） |
| 积分限幅 | 3.2 V | `DCI_ITERM_MAX_V`（必须 > 工作转速 BEMF） |
| 闭环带宽上限 | ≤ 1 kHz = f_pwm/10 | 硬约束（工程惯例：内环带宽 ≤ PWM/10） |
| 过流保护 | 9 A | `FOC_OC_LIMIT_A`（传感器 ±10A 的 90%） |

### 1.3 实测反推的修正量（关键！手册值 ≠ 环路真实值）

| 量 | 手册/理论 | 实测反推 | 证据 |
|---|---|---|---|
| R_eff（环路总电阻） | 0.1 Ω | **≈0.15 Ω** | ① P-only 跟踪率 77%：kp/(kp+R_eff)=0.5/0.65 ✓ ② 堵转尖峰 7.2A：(kp·i_ref+I_TERM)/(kp+R_eff)=(1.5+3.2)/0.65 ✓ 两处独立吻合 |
| L_eff（环路电感） | 42.3 µH | **42µH ~ 260µH 之间，未定** | 260µH 由 ki=300 反推（隐含循环论证，只能当上限参考）；kp=0.5 不振铃说明真实 L 偏大。**待 kp 扫参判别（§6）** |

R_eff = R_电机 + 2×(Rdson + 采样电阻 + PCB 走线)。电流流经两相桥臂，两项串联叠加。

### 1.4 待求量

| 待求 | 由什么决定 |
|---|---|
| kp | 带宽需求（快） vs 数字延迟稳定上限（稳）的折中 |
| ki | 零极点对消点（快收敛） vs 无超调条件（不振铃）的折中 |

## 二、被控对象建模（时域）

捏死转子（mode 29 工况，ω=0，BEMF=0），q 轴电压方程退化为一阶 ODE：

```
v = R·i + L·di/dt        →        di/dt = −(R/L)·i + (1/L)·v
```

一阶系统三个特征量：

| 特征量 | 公式 | A 套（手册 R=0.1, L=42.3µH） | B 套（反推 R=0.15, L=260µH） |
|---|---|---|---|
| 电气时间常数 τ_e | L/R | **423 µs** | **1.73 ms** |
| 对象极点频率 f_p | R/(2πL) | **376 Hz** | **92 Hz** |
| 直流增益 | 1/R | 10 A/V | 6.7 A/V |

**数字可行性检查**：τ_e ≥ 423µs ≫ Ts=50µs（一个时间常数内有 ≥8 个采样点）
→ 离散化近似连续系统成立，可以用连续域公式设计。

**BEMF 的位置**：ω·ψf 项是加在输出端的**扰动**，不进入 R+L 传递函数。
捏死时 =0；旋转时由积分器顶（这正是 P-only 高速落差巨大、I 必须开的原因）。

## 三、频域设计：零极点对消法

### 3.1 两个传递函数

```
对象（一阶）：  G_p(s) = 1/(Ls + R)                  极点 ω_p = R/L
PI（积分+零点）：G_c(s) = kp + ki/s = kp(s + ω_z)/s   零点 ω_z = ki/kp
```

### 3.2 对消条件 —— ki 的理论值

令 PI 零点正好抵消对象极点：

```
ω_z = ω_p   →   ki/kp = R/L   →   ★ ki = kp·R/L ★
```

对消后开环变成**纯积分器**：

```
G_ol(s) = kp/(L·s)        （幅频 −20dB/dec 全程，相位恒 −90°）
```

### 3.3 kp 的理论值 —— 带宽就是 kp

闭环 = 一阶低通：

```
G_cl(s) = 1/(τ_cl·s + 1),    τ_cl = L/kp,    ★ f_bw = kp/(2πL) ★
```

物理直觉：**PI 把"电气时间常数 L/R 的对象"改造成"时间常数 L/kp 的对象"**。
kp 想多大就多快——直到被数字延迟和带宽约束拦住（§4）。

### 3.4 kp 选取流程

```
kp = 2π·L·f_bw_target
   ↓ 校验①：f_bw ≤ 1 kHz（PWM/10 硬约束）
   ↓ 校验②：相位裕度 PM = 90° − 1.5Ts·ω_c ≥ 45°
        （总延迟 τ_d ≈ 1.5Ts = 75µs：一拍计算 + PWM 保持半拍）
   ↓ 校验③：饱和检查——阶跃时 PI 瞬时输出 kp·e ≤ UMAX，否则 sat=1 数据作废
```

由校验②反推的 kp 上限（PM=45°，ω_c ≤ (π/4)/1.5Ts = 10472 rad/s）：

```
kp_max = 10472·L     →  A 套：0.44 V/A    B 套：2.72 V/A
```

由校验①反推（f_bw ≤ 1kHz）：

```
kp_max = 2πL·1000    →  A 套：0.27 V/A    B 套：1.63 V/A
```

**两套约束里带宽（①）都是更紧的那条。**

## 四、含 I 的完整闭环：二阶系统与无超调条件

I 开启后闭环分母是二阶（特征方程 Ls² + (R+kp)s + ki = 0）：

```
ω_n = √(ki/L)                    无阻尼自然频率
ζ = (R + kp) / (2·√(ki·L))       阻尼比
```

**用户判据"快速接近目标且不超过"= ζ ≥ 1（临界阻尼）**，反解出 ki 上限：

```
★ ki ≤ (R + kp)² / (4·L) ★

A 套：ki ≤ 0.65²/(4×42.3µH) = 2497    B 套：ki ≤ 0.65²/(4×260µH) = 406
```

三个 ki 公式的分工：

| 公式 | 回答什么 | 数值（kp=0.5） |
|---|---|---|
| ki = kp·R/L | 零极点对消点（最优收敛形态） | A: 1182 / B: 288 |
| ki ≤ (R+kp)²/(4L) | 不超调的天花板 | A: 2497 / B: 406 |
| ω_n = √(ki/L) | 收敛速度，ki 越大越快 | — |

**当前 ki=300 的解读**：在 B 套参数下 ζ=1.16（轻微过阻尼，无超调、较快）✓；
在 A 套参数下 ζ=2.9（严重过阻尼，收敛慢但绝不振铃）。两种情况都解释得通，
这正是 L 真值需要实验判别的原因。

## 五、代入数字：两套参数并行对照表

| 量 | 公式 | A 套（手册 R=0.1, L=42.3µH） | B 套（反推 R=0.15, L=260µH） |
|---|---|---|---|
| τ_e | L/R | 423 µs | 1.73 ms |
| 对象极点 f_p | R/(2πL) | 376 Hz | 92 Hz |
| ki 对消值（kp=0.5） | kp·R/L | **1182** | **288 ≈ 当前 300 ✓** |
| f_bw（kp=0.5） | kp/(2πL) | 1882 Hz（**违反 1kHz 约束**） | 306 Hz ✓ |
| τ_cl（kp=0.5） | L/kp | 84.6 µs | 520 µs |
| kp 上限（带宽 1kHz） | 2πL·1000 | 0.27（**当前 0.5 已超**） | 1.63 ✓ |
| kp 上限（PM 45°） | 10472·L | 0.44（**当前 0.5 已超**） | 2.72 ✓ |
| ki 上限（无超调） | (R+kp)²/4L | 2497 | 406 ✓ |
| ζ（kp=0.5, ki=300） | (R+kp)/(2√(ki·L)) | 2.9 | 1.16 |

**结论**：A 套（纯手册值）预言 kp=0.5 必然振铃且带宽超标——但实验没振铃；
B 套（R_eff 反推 + L 偏大）与全部实验现象吻合。**矛盾指向：手册 L=42.3µH
大概率不是环路真实电感**（或为高频小信号值/线间测法差异），真实值偏大数倍。

### 参数自洽性交叉校验（ψf 用处之一）

BEMF 相峰值 e = ω_e·ψf = 2π·p·n/60 · ψf。n=7800rpm（=KV×VBUS 恰好是铭牌最高速）：

```
e_peak = 2π×10×7800/60 × 0.00084 = 8168 × 0.00084 = 6.86 V ≈ VBUS/√3 = 6.93 V ✓
```

ψf 与 KV、VBUS、7800rpm 极限自洽（KV 定义取线-线峰值解释），ψf 可信。
ψf 不进 kp/ki 公式，但决定 UMAX/ITERM 设计和转速天花板。

## 六、可证伪预测（用实验把 L 钉死）

| 实验 | 若 A 套成立（L≈42µH） | 若 B 套成立（L≈260µH） |
|---|---|---|
| kp=1.0（捏死转子） | 明显振铃（超 PM 上限 2.3 倍） | 干净，f_bw=612Hz |
| kp=2.0 | 剧烈振铃/失稳（带宽 7.5kHz 近 Nyquist） | 轻微振铃（带宽 1.2kHz 略超 1kHz） |
| ki 上扫（300→600→1200） | 逼近 1182 才达最优收敛 | 越过 ~406 开始超调 |

mode 29 捏死转子扫 kp（0.5→1.0→2.0）就是在做这个判别实验——
**扫完 kp 振铃出现的位置，L 真值就知道了**，ki 的对消点随之确定。

---

## 七、实操流程总结（Watch 调参顺序）

```
1. kp 从 0.5 起步（=R_eff 量级，两套理论下都安全）
2. 捏死转子，i_ref 阶跃（tr=0, δ=90° 已配好），观察：
   - 平台高度 = kp/(kp+R_eff)·i_ref → 顺手验证 R_eff
   - 平台上方振铃 → 已过 kp 上限，回退
3. kp 扫到振铃临界 → 回退一档 = kp 终值；振铃位置反推 L 真值
4. ki = kp·R/L_true 起步，上扫至 (R+kp)²/4L 天花板之内
5. 开 I 后看 eq_mean → 0±50mA 且无超调（ζ≥1）
6. 最后全量程堵转验证（500/1000/3000mA）
```
