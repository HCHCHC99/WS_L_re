## 一、结论速览

| 项 | 内容 |
|---|---|
| 现象 | mode 40 全程有噪声，**目标 rpm = 0 时依旧存在**（此时 iq_ref=0、转速=0、电机不转） |
| 主因 | **电流环把开关噪声放大成了真实的占空比抖动**。反馈路径上**没有任何抗混叠**，PI 每一拍都在追噪声 |
| 关键证据 | `I.c` 里那个 Biquad 的注释自己写着 "display only"——**它没进 PI**；PI 吃的是 ADC 原始瞬时值 |
| 次要放大因素 | 电机 L=42.3µH / R=0.1Ω（`motor_config.h`），**几毫伏的线电压失衡 = 几十毫安电流**，占空比的一个量化台阶就是几十毫安级 |
| 推荐方案 | **数字 2 极点 Butterworth @ fc=2kHz（fs=10kHz）+ 可选模拟 RC ~1.6kHz** |
| 推荐代价 | 穿越频率相位损失 −10.6°（内环相位裕度 47° → 36°），3kHz 处衰减 −11.4dB |
| 不适用场景 | 若噪声来自共模耦合（关 PWM 输出即消失），本方案**无效**，见第八节 |

## 二、先固化前提：当前真实的反馈路径

### 2.1 采样配置（与文档记载不符，以代码为准）

```
MOTOR_PWM_FREQ_HZ   = 10000   (motor_config.h:14)
I_SAMPLE_MODE       = I_SAMPLE_ADC2_PWM_VALLEY   (I.h:67)
→ AOS_Connect(AOS_ADC2_0, EVT_SRC_TMR4_3_SCMP2)  (I.c:270)  仅谷点单边沿
→ I.c:283 自证打印 "VALLEY only, effective rate = PWM frequency"
→ FOC_ISR_HZ = 10000 Hz   (I.h:105)
```

⚠️ `foc.c:6-9` 与 `I.h:101-102` 写着 20kHz，那是 `I_INMOP_STYLE`（PEAK+VALLEY）分支的结论；当前 `I_INMOP_STYLE = 0`，**实际是 10kHz**。

### 2.2 反馈链逐段

| 段 | 位置 | 现状 | 是否进 PI |
|---|---|---|---|
| ADC 采样 | ADC2 SEQ_A，谷点触发，采样窗 64 ADCLK ≈ **1.07µs** | 单点瞬时采样 | — |
| 原始转换 | `I.c:518-520` `I_ADC_TO_MA_REF()` | raw → mA（int16） | ✅ |
| **2 阶 Biquad** | `I.c:537-551` | 设计 fc=200Hz@fs=50k，实际 fs=10k → **实际 fc=40Hz** | ❌ **display only** |
| 结构体 | `I.c:557-564` `s_stcIData.*_mA = 原始值` | 未滤波 | ✅ |
| FOC 回调 | `I.c:592-594` → `foc.c:57` `Foc_Isr()` | mode 40 分发到 `Foc_Speed40_Step()` | ✅ |
| Park | `foc_core.c:260-274` `Foc_Core_GetDq()` | `ia = pData->i16IU_mA * 0.001f * sign` | ✅ |
| 电流 PI | `foc_speed40.c:410-413` | `PID_UpdateUs(&s_pid_iq, iq_ref, iq, 100µs)` | ✅ |

**结论：从 ADC 到 PI，通路上一个低通都没有。** 那个 40Hz Biquad 只喂了 `g_i_iu_filt` / `g_scope_*` / `g_i_*_disp`，全在显示侧。

### 2.3 为什么"目标 0"也安静不了

我按代码推过一遍静止工况，理论输出应该是干净的：

- `target_rpm = 0` → 斜坡输出 0 → 转子静止 → `s_speed_acc_cnt = 0` → `filt_rpm ≈ 0` → 速度环输出 **0**
- 速度环是**纯 P（无积分器）**，不可能自己"憋"出直流偏置 → 排除速度环
- `id_ref = iq_ref = 0` + 静止 → `id = iq ≈ 0`
- `Foc_Svpwm(0,0,...)`（`foc_math.c:215-217`）→ `ta=tb=tc=0` → **du = dv = dw = 50.000%**

即：零矢量下三相占空比精确相等 → **相间电压为 0 → 相电流纹波理论上为 0**。

**那噪声只能是"被脏反馈顶开的"**：PI 为了把测量值拉回 0，每拍都在输出不为 0 的 vd/vq，于是占空比不再精确 50/50/50，真实的线电压开始出现，真实的电流开始流动，电机就响了。

而反馈有多脏？三个来源叠加：

| 来源 | 量级 | 说明 |
|---|---|---|
| 谷点单点采样 + 无抗混叠 | 开关次谐波直接混叠进基带 | 每周期采 1 点，采在 1.07µs 窗内，纹波相位抖动 = 直接误差 |
| 开关耦合 / 振铃 | 与 PWM 边沿相关 | `ADC2_PWM_PEAK采样问题记录.md` 记录了此路径的历史问题 |
| 占空比量化 | 1 count / ~6000 counts = 0.017% | 在 R=0.1Ω 上 ≈ 20mA 级电流台阶 |

## 三、抗混叠要解决什么

采样定理：只有把 **fs/2 = 5kHz 以上**的内容在采样前压下去，混叠才不会折叠进控制带宽。

现在的状况等于是**全带宽采样**（唯一的一阶限制是 1.07µs 的采样窗）。PI 的输入因此含有大量 5k~50kHz 的能量，其中：

- **混叠段**：5k~15kHz → 折叠进 0~5kHz（覆盖整个电流环带宽 300Hz，也覆盖可听声主要能量区）
- **共模/开关段**：10kHz 及其谐波经寄生电容耦合，属于结构噪声

PI 拿到这些之后，`kp=0.5 V/A` 把 μA 级噪声放大成 mV 级指令 → 占空比抖 → 电流抖 → 听得见。

**抗混叠的目标不是"把电流测得更好看"，而是"让 PI 不再追噪声"。**

## 四、方案：两级低通

### 4.1 数字级（主方案，只改软件）

在 `ws/I.c` 的 mA 转换之后、写回 `s_stcIData` **之前**插一级 2 极点 Butterworth，专门供控制路径使用；显示路径保持现状不动（互不影响）。

**设计参数（fs = 10 kHz）**

| 项 | 取值 | 理由 |
|---|---|---|
| 类型 | 2 极点 Butterworth（最大平坦，无峰值） | 不引入谐振，避免把某个开关谐波顶起来 |
| 采样率 | 10000 Hz | = `FOC_ISR_HZ` |
| **推荐 fc** | **2000 Hz** | 电流环增益穿越 1881 rad/s = 300Hz，fc 高出 6.7 倍；带宽内几乎无损失 |
| 状态变量 | 3 组（U/V/W）延续现有写法 | 与已有 Biquad 风格一致 |

**响应（数值验证结果）**

| fc | 1kHz | 3kHz | 5kHz | 相位@300Hz | 等效噪声带宽 |
|---|---|---|---|---|---|
| 800 Hz | −5.5dB | −29.2dB | — | −31.1° | 866 Hz |
| 1000 Hz | −3.0dB | −25.1dB | — | −24.2° | 1071 Hz |
| 1500 Hz | −0.7dB | −17.3dB | — | −15.2° | 1565 Hz |
| **2000 Hz** | **−0.2dB** | **−11.4dB** | — | **−10.6°** | **2038 Hz** |
| 3000 Hz | −0.0dB | −3.0dB | — | −5.6° | 2962 Hz |

> 5kHz 恰好是 Nyquist，闭式解在那里是数学上的 0（点采样意义），无实际意义，故留空。

**系数表（fs = 10 kHz，双线性变换 + 预畸变）**

差分方程（沿用 `I.c:537-538` 的现有形式）：

```
y[n] = b0*x[n] + b1*x[n-1] + b2*x[n-2] - a1_code*y[n-1] - a2_code*y[n-2]
```

| fc (Hz) | b0 | b1 | b2 | a1_code | a2_code |
|---|---|---|---|---|---|
| 800 | 0.0461318021 | 0.0922636042 | 0.0461318021 | −1.3072850288 | 0.4918122372 |
| 1000 | 0.0674552739 | 0.1349105478 | 0.0674552739 | −1.1429805025 | 0.4128015981 |
| 1500 | 0.1311064399 | 0.2622128798 | 0.1311064399 | −0.7477891783 | 0.2722149379 |
| **2000** | **0.2065720838** | **0.4131441677** | **0.2065720838** | **−0.3695273774** | **0.1958157127** |
| 3000 | 0.3913357725 | 0.7826715450 | 0.3913357725 | 0.3695273774 | 0.1958157127 |

生成公式（可自行验算任意 fc）：

```
w  = tan(pi * fc / fs)
n  = 1 / (1 + sqrt(2)*w + w^2)
b0 = n*w^2          b1 = 2*n*w^2        b2 = n*w^2
a1_code = 2*n*(w^2 - 1)                 a2_code = n*(1 - sqrt(2)*w + w^2)
```

**数值验证记录（本方案的可信度依据）**

| 检验项 | 期望 | 实测 |
|---|---|---|
| 3dB 点 | fc=2000 处 −3.0103dB | **−3.0103 dB** ✓ |
| DC 增益 | 0.000000dB | **0.000000 dB** ✓ |
| 闭式解 vs 差分方程逐点幅频 | 一致 | 5000 点最大偏差 **0** ✓ |
| 闭式解 vs 差分方程逐点相频 | 一致 | 4000 点最大偏差 **0.00e+0** ✓ |
| 等效噪声带宽 / fc | 2 阶 Butterworth ≈ 1.11 | 2038/2000 = **1.019**（数字域预畸变结果） ✓ |

闭式解（用于复核，与差分方程等价）：

```
|H(f)|^2 = 1 / (1 + (tan(pi*f/fs) / tan(pi*fc/fs))^4)
```

### 4.2 模拟级（可选，但更治本）

数字滤波在**采样之后**，压不住已经混叠的分量。真正的前置防线是 ADC 引脚前的 RC：

```
电流传感器输出 ──[ R 1kΩ ]──┬── PA5/PA6/PA7 (ADC 输入)
                            │
                        [ C 100nF ]
                            │
                           GND
```

- fc = 1/(2πRC) = 1/(2π × 1k × 100n) ≈ **1.59 kHz**
- 附带好处：采样窗 1.07µs 内 C 的电荷再分配本身构成一次平均，对 kHz 以上是**二阶**衰减
- 采样窗核算：64 ADCLK @ ADC 时钟（需实测确认，若 60MHz 则 ≈1.07µs），源阻抗 1kΩ × C_sample 的建立误差需实机确认
- 三个通道各一套，共 3×R + 3×C

**建议：先只做数字级验证现象，若压不住再加模拟级。** 理由——数字级零硬件改动、可回退、能直接证伪本方案的假设。

## 七、代价与风险

| 风险 | 评估 |
|---|---|
| 相位裕度下降 | 内环原相位裕度 ≈47°（延迟 150µs 项 −101°、电气极点 −38°、零点 +18°）；fc=2000 再吃 −10.6° → **≈36°，仍可用但余量变薄** |
| 若 fc 取过低（≤1kHz） | 相位损失 −24° 以上，裕度跌破 25°，**可能引入振荡**，不建议 |
| 内环带宽损失 | fc=2000 时 300Hz 处仅 −0.2dB，可忽略 |
| 编码器量化噪声 | 与本方案无关（速度环路径），不要混为一谈 |
| int16 截断误差 | 滤波后仍在 mA 量程内，无额外风险 |

## 八、本方案**无效**的情形（重要）

若噪声主因是**共模耦合**而非混叠，加抗混叠不会有任何改善。判别方法：

| 检验 | 结果 | 结论 |
|---|---|---|
| `check_noisy_mode = 2`（`main.c:62`，只关 PWM 输出、保留 ADC 与计数） | 噪声**消失** | 源头是 PWM 开关本身 → 抗混叠无效，见下 |
| 同上 | 噪声**仍在** | 源头在采样/传感器/信号链 → **本方案对症** |
| 切 mode 0 听同一位置 | 一样响 | 是 50/50/50 零矢量的固有共模噪声，与 mode 40 无关 |
| 目标 0 时 ch7（iq_ref）/ ch9（vq） | **平** | PI 没在乱动 → 抗混叠收益有限 |
| 同上 | **在抖** | PI 在追噪声 → **本方案收益最大** |

**共模噪声的处置**（本方案覆盖不到，另案）：
- 降低 `MOTOR_PWM_FREQ_HZ`，10kHz 正好落在人耳敏感区
- 调整死区（当前 `FOC_DEADTIME_NS = 500u`）
- 硬件层：共模电感、Y 电容、门极驱动斜率调整
- 软件层：改用不连续调制（DPWM）减少共模跳变次数
